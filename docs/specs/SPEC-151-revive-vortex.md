# SPEC-151 — 復活の演出 v2（渦・マインちゃん全身・吸い込み・上から降って姿に）、 レッスンの声の重なり

- **Status**: Done（設計も演出も本 SPEC で決めた。 §6 に作者に見てほしいところ）
- **関連**: SPEC-150（復活 v1）・SPEC-147（EASY）・SPEC-085（ボイス）・SPEC-116（倒れたらスキルツリーへ）

## 1. 作者の依頼（2026-10-21）

1. EASY のチュートリアルで、 「ここは node ホレリス〜」の声と「新しいステージ〜」のレッスンの声が重なる。
2. 死亡時にネガティブな感情をむやみに出したくない。 `lose.mp3` は流さず、 **ダメージの SE をスローで**鳴らして粒子化する。
3. 粒子化したあと、 **暗い画面の中心で粒子が円柱状に回転**（上から流れて画面を上下する、 紡錘型に滞留）。
4. そこに**マインちゃんが全身絵で登場**し、 復活してくれる旨のセリフ（**懐中時計の Legendary アート**も表示）。
5. セリフのあとマインは掃け、 粒子が待っている画面に**半透明のウィンドウ**で GUM の結果などを重ねる（ボタンは不透明）。
6. 「復活する」でウィンドウが消え、 **粒子が下に吸い込まれ**、 ステージ画面へ。
7. **ステージの中央に上から粒子が流れ込んでヒーローの姿が形成**される。

## 2. 流れ（`js/battle/revive-fx.js` の状態機械と `js/battle/gameover.js`）

```
HP 0   ダメージの SE をゆっくり (= 1_single_damage.mp3 を 0.45 倍速)。 lose.mp3 は鳴らさない。 BGM は止める
 ├ dissolve 1.4 秒  ヒーローが消え、 その場所から粒子が舞い上がる。 画面がだんだん暗く (60%)
 ├ flow     0.9 秒  粒子が画面の真ん中の紡錘へ流れこむ (= easeInOut)
 ├ vortex   ずっと  紡錘 (= 高さ 画面の 50%・最大半径 短辺の 22%・上下で細く真ん中で太い) の中を回りながら上から下へ流れ、 下へ抜けたら上から
 │          マインちゃんが全身 (= タイトルと同じ大きさ・結果の画面より上) で左下に出て、 右に王妃の黄金時計 (= 5111) が浮かぶ
 │          「めげないで！この「王妃の黄金時計」のチカラで復活させてあげる！チカラを引き継げるようにスキルツリーで強化しよう！」
 │          言い終えて 1.4 秒 (= 押せば すぐ) → マインちゃんと時計が引っこみ、 半透明の結果の画面 (= 札 52%・内訳の箱 22%。 ボタンは不透明) が渦の上に重なる
 │          下の帯のマインちゃんは 2 行目だけ (= SPEC-116 の入口 / SPEC-148 のおすすめ。 全身でもう言ったので「復活させてあげる」は繰り返さない)
 ├ 「復活する」
 ├ sink     0.8 秒  結果の画面が消え、 渦が速く回って細くなりながら画面の下へ吸い込まれる。 暗さも晴れる
 ├ 戦闘を始める (= ステージ 1 の帯)。 ヒーローはまだ描かない。 時間は止めておく
 ├ rain     1.0 秒  画面の上 (= 真ん中の幅 35% に散らして) から粒子が降りこみ、 自分の画素の位置に収まってヒーローの姿になる (= 少しずつ降る)
 └ flash    0.5 秒  閃光と輪と「REVIVE!」と 3_heal_resurrection.mp3。 ヒーローを描き始め、 時間を動かす (= Ready → Go! は出さない)
```

- 動きを減らす設定・絵が読めないときは、 粒子を出さずに結果の画面をすぐ出し、 下の帯でマインちゃんが「復活させてあげる」から言う（= SPEC-150 のまま）。
- EASY のステージ 3 で倒れたときも同じ。 結果の画面が出たらレッスン「惜しい！…「スキルツリーへ」を押して！」（= SPEC-147 のまま）。
- RTA でも全身のセリフは出す（復活はできる）。 2 行目 (= 木の話) は出さない。

## 3. レッスンの声の重なり（`js/lesson.js` + `js/voice.js`）

- `isVoicePlaying()` を足し、 **時刻で出すレッスンは、 ボイスが鳴っているあいだは待つ**（= ステージの始まりの「ここは node ホレリス」が終わってから「新しいステージ！」）。
- レッスンを出すときは `stopVoice()` で前のボイスを切ってから読み上げる（= 出来事で出るレッスン（レア・ギフト・ミッション）が告げ声と重ならない）。

## 4. 見た目の値（`REVIVE`）

| | 値 |
|---|---|
| 粒 | 32×32（2×2 をまとめる）。 1 粒は画面の絵の 2 倍（最小 2.5 px）。 手前の粒は明るく大きく、 奥は暗く小さく（`depth = sin θ`） |
| 回る速さ | 0.8〜1.4 rad/s（粒ごと） |
| 流れる速さ | 1 秒に紡錘の 10〜18%（粒ごと。 上から下へ） |
| 吸い込み | 落下 1600 px/s²・回転 ×4 まで・半径 30% まで細く |
| 降りこみ | 出発は画面の上 20〜200 px・遅れ 0〜0.25 秒・easeOutCubic。 降りながら金色が抜ける |

## 5. 確かめ方

- `node --test tests/revive.test.mjs`（粒・散る・渦・ease・配線・文言・声の重なり）。
- ブラウザ（NORMAL・390px）の実測: 倒れる → +0.7 秒 粒子が舞い上がる（画面が暗く）→ +2.2 秒 渦 → +3.6 秒 マインちゃん全身（`data-place="revive"`）と時計の絵 → +7.1 秒 半透明の結果の画面（下の帯は SPEC-148 のおすすめ）→ 「復活する」→ +0.6 秒 吸い込み → 戦闘が始まり +0.5 秒 上から降りこむ（`heroDissolved` のまま・時間は止まっている）→ +1.3 秒 「REVIVE!」・`heroDissolved` false・`pauseFlags` 0。 pageerror なし。

## 6. 作者に見てほしいところ

1. マインちゃんのセリフのあと結果の画面が出るまでの間（1.4 秒）。 押せばすぐ出る。
2. 渦のあいだの暗さ（60%）と、 札の透けかた（52%）。
3. 吸い込みのあと戦闘を始めてから降りこむので、 ステージの帯と「REVIVE!」が同時に出る（SPEC-150 と同じ）。
4. ダメージの SE の遅さ（0.45 倍速）。
