# SPEC-145 — エクステ別の目利き・仕込みを、 極意の先にまっすぐ

- **Status**: Done
- **関連**: SPEC-131（極意・強化の目利き）・SPEC-133（マス目）・SPEC-139（仕込み・武器の目利き）

## 1. 作者の依頼（2026-10-21）

エクステ別の「強化コストを ◯% 下げる」「初期のレベルを上げる」が実装漏れしていそう。 各種「◯◯の極意」に延長する形で配置したい。

確かめた結果：SPEC-139 で入っていたが、 **別の場所**（仕込みは成長の「先手」から左上・武器の目利きは強化の目利きの右）にあり、 極意から辿れなかった。

## 2. 変えたこと（`js/skill-data.js`）

- どの極意・目利きからも、 その先に **まっすぐ** 伸ばす（`EXT_TOOTH` の向き）。
  - 武器：**◯◯の極意 → ◯◯の目利き（−6%）→ ◯◯の仕込み（Lv ＋1）**
  - 強化：**◯◯の目利き（−6%）→ ◯◯の仕込み（Lv ＋1）**
- 武器の極意：本作のヒーローの 6 つを横一列（y −3。 ブレード → … → レーザーガン）、 目利き・仕込みは下へ。 ほかのタイトルの 4 つ（ブック・ホーキ・マレット・パロット）はその上の列で、 ブレード・リボルバーから分岐し、 目利き・仕込みは上へ。
- 強化の目利き：U の字（y 3 を右へ、 y 4 を左へ）。 仕込みは U の外側へ。
- **入口が 1 段先に**：武器の極意は攻撃の 2 段目「長い腕」から、 強化の目利きは財宝の 2 段目「早い宝箱」から。 1 段目のまわりには、 まっすぐ伸ばす隙間がないため（配置を機械で探して確かめた）。
- 道の「仕込み」は無くし、 武器の側は「武器の極意」、 強化の側は「強化の目利き」の色にした。
- 取ってある節はそのまま（SPEC-133：条件が変わっても上げられる）。
