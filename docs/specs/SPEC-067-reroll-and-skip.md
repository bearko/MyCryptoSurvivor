# SPEC-067 — レベルアップ：リロールで同じものを続けて出さない・スキップ

- **Status**: Done
- **関連**: SPEC-008（レベルアップ）・SPEC-013（候補の選び方）・SPEC-023（リロール）・SPEC-057（配るカード）

## 1. 背景

作者の依頼（2026-10-17）：

- リロールしたとき、リロール前のエクステンションが続けて表示されないようにしたい
- どれも取得したくない場合もあるので、「スキップ（取得しない）」も選べるようにしたい

いまのリロールは候補を引き直すだけで、前に出たものがまた出ることがある。必ず 1 つ選ばないと閉じない。

## 2. 仕様（`js/battle/levelup.js`・`index.html`・`css/components.css`）

### 2.1 リロール

- そのレベルアップで**一度出したもの**は、候補が足りるかぎり出さない（`pickFromPool` の `exclude`）
- 足りないとき（強化しきって候補が少ない後半など）だけ、前に出したものから埋める。**直前に出ていたもの**は最後に回す（`last`）
- 武器を 1 枠優先する（SPEC-013）のは、避けるものの外から。表示の順はばらす（いままでどおり）

### 2.2 スキップ

- リロールの隣に「スキップ（取得しない）」。押すと、どれも取らずに閉じる（何ももらえない。次のレベルアップがあれば続けて開く）
- 選んだカードが光っているあいだは押せない（二度押しで 2 つ動かない）。最初の武器を選ぶとき（`pendingPickIsStarter`）は出さない
- 2 つのボタンは横に並べ、角を切った枠のボタンにする（文字は 1 行）

### 2.3 遊び方

- 「強くなる」の行に「前に出たものは続けて出ない」「どれも要らなければスキップ」を足す

## 3. 非ゴール

- リロールの回数（1 ステージ 3 回）・候補の数（3 つ）は変えない
- スキップに代わりのもの（回復・経験値など）は付けない（作者の依頼どおり「取得しない」）

## 4. 受け入れ基準

- [x] リロールすると、前の 3 つとは別の 3 つが出る（2 回続けても）
- [x] スキップで何も取らずに閉じ、ゲームが再開する（一時停止の数が 0 に戻る）

## 5. テスト

- `node --test tests/levelup-picks.test.mjs`：武器を 1 つ入れて重ならない 3 つ、リロールで出したものを続けて出さない（50 回）、足りないときだけ前のものを混ぜて直前のものは最後、候補が少ないときはあるだけ
- ヘッドレスの Chromium：レベルアップを開いて 2 回リロール（3 回とも重なりなし）→ スキップで閉じ、一時停止の数 1 → 0・持ち物は増えない。390×844・360×640 で撮った
