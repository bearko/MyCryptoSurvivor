# SPEC-150 — 「やり直し」ではなく「復活」（粒子になって舞い、 強くなって集まる）

- **Status**: Done（設計も演出も本 SPEC で決めた。 §7 に作者に見てほしいところ）
- **関連**: SPEC-009（ゲームオーバー）・SPEC-058（テロップ）・SPEC-116（倒れたらスキルツリーへ）・SPEC-146（もう一度挑む）・SPEC-148（負けた理由の分析）

## 1. 作者の依頼（2026-10-21）

ユーザーから「死んで、 やり直し」は UX としてやる気になれないという声。 「やり直し」ではなく **「復活」** という建付けにし、 死んでから復活するまでをスタイリッシュに。

1. 死ぬときにヒーローが 64×64 の粒子になる（風に舞うように宙に舞い上がる）
2. 粒子が舞っている状態で、 マインちゃんが「めげないで！この「王妃の黄金時計」のチカラで復活させてあげる！チカラを引き継げるようにスキルツリーで強化しよう！」
3. スキルツリーで強化する猶予を与えつつ、 「リトライ」ではなく「復活する」
4. 復活を選んだら、 フィールド上で粒子がまたヒーローの姿に集まってリスタート

## 2. 流れ

```
HP 0
 ├ 戦闘の絵からヒーローが消え、 その場所から 64×64 の粒子が舞い上がる（1.6 秒。 lose のテロップは出さない）
 ├ 粒子は画面の上のほうで風に揺れながら漂い続ける（結果の画面のあいだずっと）
 ├ 結果の画面が半透明で重なる（後ろで粒子が見える）。 見出しは「力尽きた……」/ REVIVE
 │   マインちゃん（下の帯）: ①「めげないで！この「王妃の黄金時計」のチカラで復活させてあげる！…」
 │                           ② SPEC-116 の入口の案内 か SPEC-148 のおすすめ（吹き出しを押すと ②）
 │   ボタン: [スキルツリーへ]  [🕰 復活する ▶]（王妃の黄金時計の絵つき）
 ├ 「復活する」
 │   結果の画面が消え、 粒子がフィールドの真ん中へ吸い寄せられて集まる（1.1 秒）
 │   集まりきった瞬間に金色の閃光と輪、 「REVIVE!」、 SE（3_heal_resurrection.mp3）
 └ ステージ 1 から再開（= 今までの「もう一度挑む」と同じ。 ステージの帯が出る）
```

- **再開はステージ 1 から**（SPEC-146 と同じ）。 RTA・レギュレーション・総合スコアの意味を変えないため。 「復活」は言い方と演出で、 進行の仕組みは変えない。
- EASY のステージ 3 で倒れたときも同じ演出。 文言は SPEC-147 のレッスン「惜しい！…」のまま（レッスンが先に出て、 帯の①は出さない）。
- RTA: 木が効かないので ② は出さない。 ① は出す（復活はできる）。

## 3. 粒子（`js/battle/revive-fx.js`）

- **絵の元**: `state.battle.playerSprite.img`（64×64・`crossOrigin: anonymous` なので `getImageData` が通る）。 **2×2 を 1 粒にまとめて 32×32 = 最大 1,024 粒**（透明なところは粒にしない。 1 粒は画面上 2〜3 px なので 64×64 のままだと見えない）。
- **散る**（`dissolve`）: 粒はヒーローの描かれていた位置（画面座標）から、 上向き 60〜170 px/s ＋ 風（`sin` で左右に 40 px/s ほど揺れる）で舞い上がる。 1.6 秒かけて上のほうへ広がったあとは、 **ゆっくり上へ漂い続け、 画面の上から出たら下から戻る**（結果の画面のあいだ、 後ろで舞い続ける）。 明るさは 0.55〜1.0 で粒ごとに脈打つ。
- **集まる**（`gather`）: それぞれの粒が、 いまいる場所から**自分の元の画素の位置**（フィールドの真ん中 = 再開後のヒーローの位置）へ 1.1 秒で戻る（`easeInCubic`。 最初はゆっくり、 最後に一気に）。 戻る途中で金色が混じる。 集まりきったら閃光（白 → 金）と輪（半径 0 → 90 px・0.5 秒）、 「REVIVE!」の文字、 SE。 閃光が立ってから（0.36 秒後）ステージ 1 の帯。
- **画面**: `#reviveFx`（`position: fixed`・`z-index: var(--z-modal-top) ＋ 1`・`pointer-events: none`）。 結果の画面（`--z-modal-top`）の**上**に重ねる（= 半透明の札の上を粒が舞う。 マインちゃんの帯 ＋5 とボタンの操作は妨げない）。 結果の画面は復活のあいだだけ半透明（背景 rgba 0.62・札 0.84）。 1 粒は画面の絵の 2 倍（最小 2.5 px）。
- 戦闘の絵からヒーローを消すのは `state.battle.heroDissolved`（`render.js` が見る。 HP バーも出さない）。 `startBattle` が消す。
- `prefers-reduced-motion`: 粒子は出さず、 結果の画面をすぐ出す。 復活もすぐ再開。

## 7. 作者に見てほしいところ（決めてある。 変えたければ言ってほしい）

1. 見出し「力尽きた……」/ REVIVE。 「ゲームオーバー」の文字は出さない。
2. 復活はステージ 1 から（SPEC-146 と同じ）。 「倒れたところから続き」は RTA と総合スコアの意味が変わるので入れていない。
3. RTA と ABSOLUTE も「復活する」の言い方（「今のレギュレーションで復活する」）。
4. 粒子は 32×32（2×2 をまとめる）。 64×64 のままだと 1 粒が 1 px 未満で見えない。
5. lose のテロップ（SIGNAL LOST / 通信が途切れた……）は出さない。 粒子の 1.6 秒がその代わり。
