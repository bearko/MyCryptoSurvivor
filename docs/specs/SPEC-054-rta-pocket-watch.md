# SPEC-054 — RTA の懐中時計（10 秒間ゲーム全体が 2 倍速）

- **Status**: Done
- **関連**:
  - SPEC-040・SPEC-048（RTA）・SPEC-053（宝箱）
  - bearko/MyCryptoPortfolio の SPEC-001 6.15（懐中時計ありのレギュレーション `survivor-normal-v2`・`survivor-absolute-2x-v2`。#43）

## 1. 背景（作者の要望・決定 2026-10-17）

- ボスがゲーム内の 4 分に必ず出るので、RTA のタイムに差がつきにくい
- RTA のときだけ、ゲーム内の時間を速める「懐中時計」をお助けアイテムとして落としたい
- 効果は **10 秒間ゲーム全体が 2 倍速**（作者の決定。ステージの時計だけを進める案ではなく、敵も自分も弾も速くなる）

## 2. 仕様

### 2.1 出るところ

- **RTA で始めたときだけ**（`state.rtaMode`）、宝箱から出る。宝箱の中身は 懐中時計 50% ／ パンケーキ 25% ／ 棒磁石 25%（RTA でないときは パンケーキ 50% ／ 棒磁石 50% のまま）
- 壺からは出ない
- 宝箱は 1 ステージ 4 つ（SPEC-053）なので、懐中時計は 1 ステージ最大 4 つ

### 2.2 効果

- 拾うと、**実時間 10 秒**、ゲーム全体が 2 倍速になる。1 コマで戦闘の更新（`_step`）を 2 回呼ぶ
  - 対象：敵・自分・弾・武器の間隔・敵の出現・ステージの時計（ボスの出現・5 分耐久）
  - 武器の間隔や敵の出現は `now` で数えているので、2 回目の更新には、余分に進めたゲームの時間（`_ffOffsetMs`）を足した `now` を渡す
- 続けて拾うと 10 秒ずつ延びる
- 一時停止・レベルアップの選択中は、残り時間も止まる
- ステージが変わると消える（`startBattle` で 0 に戻す）
- 画面の右上に「⏩ ×2 7.3s」と残り時間を出す
- 絵は MCH の懐中時計（1111）。拾った音は強化の音

### 2.3 RTA の計測

- 計るレギュレーションを、懐中時計ありの `survivor-normal-v2`・`survivor-absolute-2x-v2` に切り替える（`rtaRegulationFor`）
- モード選択の RTA の card のランキングへのリンクも、v2 にする
- 懐中時計なし（`survivor-normal`・`survivor-absolute-2x`）の記録は、共通基盤に過去の記録として残る（このあと共通基盤で deprecated にする）
- 最短時間の根拠（SPEC-001 6.15）：2 倍速の実時間 T でゲーム内は 2T 進むので、実時間が T 縮む。1 ステージ最大 4 つ × 10 秒 ＝ 40 秒。そのため、ボスが出るのは実時間 3 分 20 秒より前にならない。最短時間は 3:15 / 6:30 / 9:45

### 2.4 スコア

- 活動レポートのスコアの「速さの点」は IGT（ゲーム内の時間）で数えるので、懐中時計では変わらない
- 総合スコアも変わらない

## 3. ほかの案（採らなかったもの）

- ステージの時計だけを 30 秒進める（戦いの速さは変わらない）：計算はしやすいが、作者は「ゲーム全体が速くなる」ほうを選んだ
- 撃破ノルマでボスを早く呼ぶ（PR #72 の下書き。閉じた）

## 4. 受け入れ基準

- [x] RTA で始めると、宝箱から懐中時計が出る。RTA でないときは出ない
- [x] 拾うと、10 秒間ゲーム全体が 2 倍速になり、右上に残り時間が出る
- [x] RTA の計測は `survivor-normal-v2`（ABSOLUTE ×2.0 なら `survivor-absolute-2x-v2`）で始まる
- [ ] 本番：懐中時計ありで全 3 ステージを走り、`https://bearko.games/rta/?regulation=survivor-normal-v2` に載る（作者が確認）
