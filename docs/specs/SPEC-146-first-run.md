分かったこと：
1. **SPEC-107** で、 初めての人はステージ 1 の 1 分半で T1 に入り、 終わりには T4（精鋭）まで上がる。 クリアが 67% → 0%。 SPEC-107 の「NORMAL のクリア 60%」は、 初めての人の数字ではない（初めての人は 0%）。
2. **SPEC-117（ショップを既定で ON）** で、 初めての人が強くなる数がレベルアップより大きく減る（倒れたときの Lv 28 → 8.5）。 店は 40 秒ごとに 4 枚までなので、 CE を倍にしても値段を半分にしても、 買える数はあまり増えない（倒れる秒が 157 → 182 ほど）。
3. 両方を初回だけ外すと、 前の版と同じくらい（63%）に戻る。

## 3. 直したこと

### 3.1 初めての人の最初の挑戦（`state.run.firstRun`）

- 挑戦の始め（ステージ 1）に、 `getMeta().runs === 0`（まだ 1 回も挑戦を終えていない）なら `state.run.firstRun = true`。 RTA は初回には選べないが、 念のため外す。 `runs` は挑戦の終わり（`grantRunRewards`）で増えるので、 2 回目からは今までどおり。
- **脅威の段階を上げない**（`runThreatTier`。 T0 のまま。 知らせも型も出ない）。
- **ショップを出さない**（レベルアップで強くなる。 SPEC-117 より前の作り）。 ショップ・ミッションは 2 回目から（最初の店の説明・サービスの 1 品も 2 回目の最初の店で出る）。

2 回目以降の難しさ・RTA・レギュレーション・総合スコアに効くものは変えない。 アチーブメントの ID と付く条件・`js/platform.js` の送り方も変えない。

### 3.2 倒れたあとの流れ（SPEC-116 の続き）

前は、 倒れる → スキルツリー → 戻る → 結果の画面の一番下の「今のレギュレーションで再走」を探す、 という流れで、 ひと区切りついた感じになっていた。

- 結果の画面：**「もう一度挑む ▶」をスキルツリーのすぐ下**に（ランキングとタイトルに戻るより上）。 NORMAL は「もう一度挑む ▶」、 RTA と ABSOLUTE は今までどおり「今のレギュレーションで再走」。
- 倒れたあとに開いたスキルツリー：**左下に金色の「もう一度挑む ▶」**（強くして、 そのままステージ 1 から）。
- スキルツリーから結果の画面に戻ったとき：マインちゃんが「強くなったね！ さっきより楽に戦えるはず。さっそく『もう一度挑む』！」（何も取らなかったら「GUM は挑むたびに貯まるよ。まずは『もう一度挑む』で稼ごう！」）と言い、 ボタンが脈打つ。 2 回目のほうが楽になることを伝える。
