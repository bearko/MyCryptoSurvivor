# SPEC-132 — ステージクリアのたびにスキルツリーへ

- **Status**: Done
- **関連**: SPEC-090（スキルツリー）・SPEC-131（GUM を稼ぎやすく）

## 1. 作者の依頼（2026-10-20）

- ステージクリアのたびにスキルツリーへ行って強化する導線を作りたい
- ステージクリアのとき、ゴールドダストだけでなく GUM も得られるように
- ステージクリアの画面にスキルツリーへのボタン
- スキルツリーからはタイトルにしか戻れない → 元の画面に戻るように。左上はスマホで押しにくいので、木の描画エリアの右下に

## 2. 変えたこと

### ステージクリアの GUM

- **50 × ステージの番号 ＋ そのステージの撃破 15 体ごとに 1**（「金勘定」「金運」の倍率も掛ける）
  - 例：ステージ 1 で 1,500 体 → 50 ＋ 100 = **150**
- ステージクリアの画面に「GUM ＋150」「ゴールドダスト ＋1」と並ぶ
- 挑戦が終わったときの撃破数の GUM（SPEC-131）は、ステージクリアでもらったステージのぶんを数えない（二重にしない）。結果の画面の GUM は、ステージクリア・ミッションでもらったぶんも足して出す

### ステージクリアの画面に「スキルツリーへ」

- 解放できる数の札つき（9 を超えたら 9+）
- 押すとクリアの画面を隠して木を開き、閉じるとクリアの画面に戻る。そのまま「次のステージへ」
- 挑戦の途中では、効果の欄の注意書きが「次のステージから効く」になる（スキルツリーの効果はステージの始まりに読み直す）

### スキルツリーの「戻る」

- 左上の ← をやめ、**木の右下に「◀ 戻る」**（縮める・広げる・中心へ と同じ高さ。広い画面では右の列の手前）
- 開いた元の画面に戻る：タイトル → タイトル、ステージクリア → ステージクリア、ゲームオーバー・全クリアの結果 → その結果の画面（前はタイトルに戻していた）

## 3. 確かめたこと

- ブラウザ（390×740）で：ステージ 1 を 1,500 体でクリア → 「GUM ＋150・ゴールドダスト ＋1」、保存された GUM 150。「スキルツリーへ」→ 木が開き、注意書きは「次のステージから効く」。右下の「◀ 戻る」でクリアの画面に戻り、「次のステージへ」でステージ 2 が始まる
- ゲームオーバーの画面から開いても、戻るとゲームオーバーの画面に戻る
- `node --test tests/*.test.mjs`：324 件すべて通る
