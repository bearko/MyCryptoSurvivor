# SPEC-101 — 初期武器の LL ランクアップ（壊れ性能）

- **Status**: Draft（作者の確認待ち：7 章）
- **関連**: SPEC-087（ランクアップの札）・SPEC-097（ヒーローと武器）・SPEC-100（固有スキル）

## 1. 背景（作者の依頼 2026-10-19）

各ヒーローが最初から持っているエクステンション（初期武器）は、**LL エクステにランクアップ** できるようにしたい。LL にしたら **壊れ性能** に。

## 2. 決まり

- いまの武器は Lv.1〜5（5 段目が Legendary。`EXT_MAX_LEVEL = 5`）。**そのヒーローの初期武器だけ**、Lv.5 のあとに **LL（6 段目）** がある
- 初期武器が Lv.5 になったあとの最初のレベルアップで、選択肢の 1 枚目に **「LL ランクアップ」の札**（虹色の縁・専用の効果音）が必ず出る。選ぶかどうかは自由（選ばなければ次のレベルアップでまた出る）
- ほかの武器（レベルアップで拾ったもの）は Lv.5 まで。**「自分のヒーローの武器を育てきる」ことが、やり込みの目印** になる
- LL は 1 回の挑戦の中だけ（ステージをまたいでも持ち越す。いまの装備と同じ）

## 3. LL の品と壊れ性能（案）

LL の品は資産リポジトリの LL エクステ（id 5501 以上）から、その系列の最終段の「真」版を使う。無い系列は、意味の合う LL の品を当てる。

| 系列 | Lv.5（いま） | LL（案） | 壊れ性能（案） |
|---|---|---|---|
| ブレード | MCHブレード | **真・MCHブレード**（5501）「天の一撃」 | 回る刃が 2 倍の数・2 倍の大きさ。数秒ごとに画面全体への一撃 |
| ライフル | モデル１ | **モデル２**（5529）「せんたくいたし申候」 | 8 方向に同時に撃ち、弾が敵を貫き続ける |
| 手裏剣 | 赤目四十八滝 | **真・赤目四十八滝**（5624）「真・ワレヲシルヘシ」 | 投げた手裏剣が分身して 3 倍、敵に当たると跳ね返り続ける |
| レーザーガン | メギド | **真・メギド**（5630）「神炎」 | 光線が画面を横切る太さになり、回転しながら薙ぎ払う |
| ナイフ | アゾット | **真・アゾット**（5548）「パラケルススの使役せし悪魔」 | 投げたナイフが悪魔になって敵を追い続ける |
| ブック | アトランティコ手稿 | **レスター手稿**（5508）「空はなぜ青いのか」 | 回る本が 2 重の輪に。触れた敵の弾を消す |
| アックス | バイキングアックス | **真・ミョルニル**（5573）「雷霆万鈞」※ | 投げた斧（槌）が戻ってくるまでに雷を落とし続ける |
| モアイ | 財宝ゴールデンモアイ | **真・絶対零度ゴールデンスノーマン**（5626）「真・黄金氷河期」※ | 落ちた場所が凍り、敵の動きが止まる |
| ピエロ | ジョーカー | **悪魔金魚**（5561）「悪魔だからな」※ | 置いた爆弾が連鎖して大爆発 |
| パンジャンドラム | クリプトパンジャンドラム | **真・バリスタ**（5535）「滅亡の一撃」※ | 巨大な輪が画面の端で跳ね返り続ける |

※ その系列に「真」版が無いもの。意味の合う LL の品を当てた案

- 壊れ性能でも、遊びが止まらないこと（敵の数・弾の数に上限）と、`prefers-reduced-motion` で激しい光を抑えることは守る
- ランキング・総合スコアへの効き方は自動プレイで確かめ、目安から大きく外れるなら係数を見直す（共通基盤 SPEC-002）

## 4. 画面

- レベルアップの札：「**LL ランクアップ**」の帯、品の絵と名前、ひとこと（例「回る刃が 2 倍に」）
- 選んだ瞬間：画面がひと呼吸止まり、LL の品の絵が大きく出る（0.8 秒・タップで飛ばせる）
- ヒーローの選択画面：初期武器の欄に「LL：真・MCHブレード」と、まだ見ていなければ「？？？」（SPEC-099）

## 5. テスト

- LL の札が出る条件（初期武器が Lv.5・まだ LL でない）・ほかの武器には出ない
- LL の各系列の数値（純関数）
