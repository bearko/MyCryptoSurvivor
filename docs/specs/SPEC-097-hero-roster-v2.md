# SPEC-097 — ヒーローの顔ぶれを武器に合わせて組み直す（v1.5 の土台）

- **Status**: Draft（作者の確認待ち：9 章）
- **関連**: SPEC-013（初期武器）・SPEC-014（ステータスから HP と速さ）・SPEC-083（ヒーローと武器のプレビュー）・SPEC-096（アチーブメント）
- **v1.5 の束**: SPEC-097（顔ぶれ）→ SPEC-098（解放）→ SPEC-099（レーダーチャート）→ SPEC-100（固有スキル）→ SPEC-101（LL ランクアップ）／ SPEC-102（CE の吸い込み）は独立

## 1. 背景（作者の依頼 2026-10-19）

初めての人の目線で「遊び方・目標・やり込み・面白さ」が分かりやすくなるよう見直す。あわせて bearko.games のほかのタイトルとの横のつながりを、アチーブメントで強める。

- いきなり全ヒーローが選べるのは選択肢が多すぎる（→ SPEC-098）
- **ヒーローとエクステンション（武器）の関連が弱い**。ヒーローがその武器を使っているイメージが湧かない（例：ブレードは MCHウォーリアー、ライフルはビリー・ザ・キッド、アックスは金太郎）
- 同じステージでも、ヒーローによって「別ゲーム」になるようにしたい（→ SPEC-100・SPEC-101）

いまの 10 人（コナン・ドイル＝リボルバー、甲斐姫＝ブレード、シートン＝モアイ…）は、武器との結び付きが弱い組み合わせが多い。さらに戦闘で効いているステータスは HP と AGI だけで、PHY と INT は何もしていない（SPEC-014）。

## 3. PHY と INT を効かせる

ヒーローの差を数字の上でも出すため、いま使っていない PHY と INT に役割を持たせる（HP と AGI はいまのまま。SPEC-014）。

| ステータス | 効き目 | 式（案） | 10 人の幅 |
|---|---|---|---|
| HP | HP の上限 | いまのまま `80 + hp × 0.20` | 112〜178 |
| AGI | 移動の速さ | いまのまま `140 + agi × 0.6` | 168〜228 px/秒 |
| **PHY** | **武器の与えるダメージ** | `× (1 + (phy − 80) / 400)` | ×0.92〜×1.13 |
| **INT** | **武器の間隔（クールダウン）** | `× (1 − (int − 70) / 500)` | ×1.10〜×0.90 |

- 幅は ±1 割ほどに抑える。違いを決めるのは主に武器と固有スキル（SPEC-100）で、ステータスは「同じ武器でも、こっちのほうが痛い／速い」と分かる程度
- 数字は `tools/sim` の自動プレイで、全員が NORMAL を目標の割合（クリア 60%）の近くでクリアできることを確かめて決める（BALANCE_LOOP.md）

## 4. 画面

- ヒーローの選択画面の札は、いまの絵・名前・属性に加えて、**初期武器のアイコンと名前**を札の上に出す（「このヒーロー＝この武器」がひと目で分かる）
- 詳しい性能の見せ方は SPEC-099（レーダーチャート）

## 5. 移行

- 前の版で最後に選んでいたヒーローが外れた人は、MCHウォーリアーを選んでいる状態にする
- RTA の記録・総合スコア・スキルツリーはそのまま

- `HERO_STARTING_WEAPON` が 10 人すべてにあり、10 系列が重ならない
- PHY / INT の倍率が式どおり（境界の値）
- `data/heroes.json` の値が資産リポジトリと一致する（`tools/` の照らし合わせ）
