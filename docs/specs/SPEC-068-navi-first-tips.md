# SPEC-068 — マインちゃんの「初めて」のひとこと

- **Status**: Done
- **関連**: SPEC-053（お助けアイテム）・SPEC-056（マインちゃん）・SPEC-062（撃ってくる敵）・SPEC-063（雷鼓）・SPEC-064（ステージの仕掛け）

## 1. 背景

作者の依頼（2026-10-17）：

- 初めて獲得したアイテムや、ステージのギミックの初発動時は、画面上部でマインちゃんがひとこと補足を入れてほしい

作者の決定（同日）：**その端末で初めてのときだけ**話す。見たものは端末に覚えておき、次の挑戦からは黙る。設定に「マインちゃんの補足をもう一度」を置く。

v1.2 でアイテム（雷鼓）・仕掛け（そろばんの珠・パンチカード・トロイの木馬）・撃ってくる敵が増えた。遊び方には書いてあるが、遊んでいる最中に初めて出会ったときには何が起きたのか分からない。

## 2. 仕様

### 2.1 話す場面（`js/navi-tips.js` の `TIP_KEYS`）

| 場面 | きっかけ | どこで |
|---|---|---|
| パンケーキ・棒磁石・懐中時計・雷鼓 | 初めて拾った | `field.js` の `applyItem` |
| マジックカード | 初めて拾った | `magic-cards.js` |
| そろばんの珠（ステージ 1） | 最初の列が出た（予告の線） | `gimmicks.js` |
| パンチカード（ステージ 2） | 最初の印が打たれた | `gimmicks.js` |
| トロイの木馬（ステージ 3） | 最初の木馬が出た | `gimmicks.js` |
| 撃ってくる敵 | 初めて狙われた（狙いの線） | `enemy-shots.js` |

撃ってくる敵は依頼に入っていないが、v1.2 で入った「初めて出会うもの」なので一緒に入れた。

### 2.2 出し方

- 戦闘の通信窓（画面の上、HUD の下。RTA なら時計のさらに下）。SPEC-056 と同じ場所・同じ見た目で、押せない
- 言い終えて 2.4 秒で引っこむ。ゲームは止めない（`pauseTime` に触らない）
- **話すのは、戦闘中で、止まっておらず、マインちゃんがほかのことを話していないときだけ**（`canSpeakTip`）。それまでは順番を待つ
  - レベルアップ・メニュー・設定の裏では話さない（マジックカードは、レベルアップを選び終えてから話す）
  - ステージの始まり・ボスの知らせを消さない（言い終えて引っこんでから話す）
  - 続けて起きたら、順番に話す
- ボスの知らせはひとことの途中でも割りこむ（ボスのほうが大事）。割りこまれたひとことは、もう一度は言わない
- 戦闘をやめたら（ゲームオーバー・タイトルへ）、話す予定のひとことは捨てる

### 2.3 覚えておく（端末ごと）

- 見たものは `localStorage` の `mcs.naviTips`（場面のキーの配列）。話す順番に入れた時点で覚える
- 読めない・書けない・壊れている環境では、毎回話す側に倒れる（落ちない。DEVELOPMENT_CHARTER の try/catch）
- 毎回の判定で `localStorage` は読まない（はじめに 1 回だけ読む。撃ってくる敵は何度も通るため）

### 2.4 設定（`index.html`・`js/settings-ui.js`）

- 「💬 マインちゃんの補足」の行（説明「初めてのアイテムや仕掛けで、ひとこと話す」）に「もう一度聞く」
- 押すと見たものを忘れ、「また話すね！」になって押せなくなる。まだ何も見ていないときも押せない
- 押したあとは、また初めてのときに話す（いまの挑戦の続きからでも）

## 3. 非ゴール

- 見た目の新しい置き場所は作らない（SPEC-056 の通信窓を使う）
- ひとことを押して読み進める・止める操作は入れない（戦闘の通信窓は押せない。SPEC-056）
- 遊び方（ヘルプ）の文は変えない

## 4. 受け入れ基準

- [x] 初めてパンケーキを拾うと、画面の上でマインちゃんがひとこと言う。ステージの始まりのセリフの途中なら、言い終えてから話す
- [x] マジックカードを拾ったときは、レベルアップの画面の裏では話さず、選び終えてから話す
- [x] そろばんの珠の最初の列で話す
- [x] 読み込み直して、もう一度拾っても話さない
- [x] 設定の「もう一度聞く」のあとは、また話す
