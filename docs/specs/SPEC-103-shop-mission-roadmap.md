# SPEC-103 — v1.6「ショップとミッション」：設計とロードマップ

- **Status**: Accepted（作者の決定 2026-10-20 は 8 章。9 章の順に 1 PR 1 SPEC で作る）
- **関連**: SPEC-007（CE と経験値）・SPEC-030（装備はステージごと）・SPEC-072（レベルアップのスキップとリロール）・SPEC-081（ボス戦の宝箱・マジックカード）・SPEC-087（ランクアップの札）・SPEC-090（スキルツリー）・SPEC-097（10 人と 10 系列）・SPEC-100（固有スキル）・SPEC-101（LL ランクアップ）・SPEC-102（CE の吸い込み）
- **参考**: Genome Guardian 2（ウェーブごとのショップ・追放とロック・トレードオフの品・不意に差し込まれるミッション）

## 1. 背景（作者の依頼 2026-10-20）

参考作の、プレイヤーの「選択と裁量」を増やす作りを取り入れる。

1. レベルアップをやめ、**一定時間ごと（ウェーブごと）にショップ**が開く。貯めた **CE でスキルを買う**
   - 店主は **商人系のシャドーヒーロー**（マルコ・ポーロ・マゼラン・平賀源内など）
   - ランクアップは **レアリティが高いほど高い**
   - 足りないときのために **取り置き（ロック）** と **お断り（追放）**
2. **CE のドロップを増やすエクステンション**（クラウンシリーズ）
3. ショップに **パッシブスキル（固有スキル）の強化** を常設。強化はその挑戦のあいだ **ステージ 1〜3 をまたいで効く**（敗北して再走したら最初から）
4. **LL エクステの解放条件** を「そのヒーローで 3 ステージをクリアしたことがあるか」に（強さは今のまま）
5. **ミッション**：プレイ中に不定期で、シャドーヒーローがミッションを持ちかける。受けるかは選べる。ヒーローの特徴に合わせた内容（シャドー呂布「敵の数 10 倍」、シャドージャックザリッパー「濃霧」など）
6. **敵の種類を増やす**：撃破数が多いほど強い敵（大きい・弾が多い・速い・直線で横切る）。強い敵ほど CE が多い
7. **撃破数の節目の演出**（100・500・1,000 体…）：流れを止めず、画面の上に派手な通知。節目ごとに敵が強くなる

## 2. いまの作り（設計の前提）

| 項目 | いま | この SPEC で変わるか |
|---|---|---|
| CE | 敵が落とし、拾うと経験値（SPEC-007・102）。雑魚 1〜7、撃つ敵 4〜5、レア 20〜35、ボス 60〜150（`ENEMY_SPECS.xpValue`。雑魚はステージで ×1/×2/×3） | **通貨になる**（4 章） |
| レベルアップ | 経験値が貯まるたびに 3 枚から 1 枚を選ぶ。リロール（ステージごと 3 回＋スキルツリー）・スキップ | **ショップに置き換え** |
| 装備 | ステージの始めに空に戻る（初期武器だけ Lv.1 で持つ。SPEC-030） | 変えない（8 章 Q1） |
| 固有スキル | 10 人それぞれ（SPEC-100）。クリプトスラッシュ・テトラクテュスは「レベルアップ」に、毒霧・テスラコイルなどのダメージは「レベル」にひもづく | **ショップの強化段（Lv）にひもづけ直す** |
| LL | 初期武器が Lv.5 になると、次のレベルアップで 1 枚目に LL の札（SPEC-101） | **解放条件が付く**（6 章） |
| ヒーローごとのクリアの記録 | 無い（`mcs.played` は「1 回遊び終えた」だけ） | **足す**（6 章） |
| 撃破数 | `state.killCount`（ステージごと）・`run.totalKills`（通算） | 節目の演出と敵の段階に使う |
| 敵の段階 | 時間（1 分ごとの `WAVE_TABLE`・密度・群れ）だけ | **撃破数の段階を足す** |

## 3. ゲームの流れ（v1.6）

```
ステージ 1：開始 → 0:10 に最初のショップ（初期武器だけの状態から方向を決める）
ステージ 2・3：開始の前にショップ（前のステージで稼いで残った CE で強化する）
  └ そのあと 40 秒ごとにショップ（時間は止まる。敵はそのまま）
      ステージ 1：0:10 / 0:50 / 1:30 / 2:10 / 2:50 / 3:30
      ステージ 2・3：開始前 / 0:40 / 1:20 / 2:00 / 2:40 / 3:20
  └ 中断する画面（ショップ・ミッション・レベルアップ・メニュー）を閉じたら、3 秒数えてから再開（SPEC-104）
  └ ウェーブの途中：ミッションが不意に持ちかけられる（時間を止めて 受ける / 断る）
  └ 撃破数の節目：画面の上に通知（止めない）。ステージの撃破数で敵の段階が上がる
  └ 3:50 ボスの予告 → 4:00 ボス → 撃破でステージクリア
```

- ショップは 1 ステージ 6 回（いまのレベルアップは 1 ステージ 15〜25 回）。**1 回の店で 2〜4 品買える額** に CE と値段を合わせる（買う回数の合計は、いまのレベルアップの回数と同じくらい）
- ボスの直前の店は置かない（作者の決定：40 秒ごと。ステージ 1 は 0:10 から、ステージ 2・3 は開始前から）
- 数値（間隔・値段・CE の量）はすべて `js/constants.js` の先頭にまとめ、自動プレイ（`tools/sim`）で決める

## 4. ショップ（要件 1）

### 4.1 店主（商人のシャドーヒーロー）

ショップのたびに 1 人が店番をする（絵は資産リポジトリの `Image/Enemies/<id>.png`。シャドーの姿）。店主ごとに **1 つだけ癖** を持たせて、店ごとの違いを作る（参考作のセールにあたる）。

| 店主 | 絵 | 店の癖（案） |
|---|---|---|
| マルコ・ポーロ | 480 | 東方見聞録：**セール** 1 品が半額 |
| マゼラン | 821 | 世界一周：品が 1 枚多い（5 枚） |
| 平賀源内 | 553 | エレキテル：強化（buff）の品が出やすい |
| コロンブス | 815 | 新大陸：まだ持っていない系列が出やすい |
| ヴァスコ・ダ・ガマ | 1165 | 香辛料の道：リロールが 1 回ただ |
| 黒髭 | 506 | 海賊の取引：ランクアップが 2 割引、ただし新しい品は 2 割増し |

- 店主は乱数で選ぶ（同じ店主が続けて来ない）。ステージ 2・3 の開始前の店は **固定**（案：マルコ・ポーロ。「次の地へ向かう前に」）
- 店主のひとことは、マインちゃんの通信窓と同じ形で店の上に出す（店主の顔の小窓）

### 4.2 品

- 品は **4 枚**（店主で増減）。中身はいまのレベルアップの候補と同じ考え方：持っていない系列は Lv.1 で「新しく」、持っている系列は「ランクアップ（次の段）」。武器・強化の枠の上限もいまのまま（スキルツリーの「大きな鞄」で ＋1）
- **値段はレアリティ（行き先の段）で上がる**

| 行き先 | Lv.1（Common） | Lv.2（Uncommon） | Lv.3（Rare） | Lv.4（Epic） | Lv.5（Legendary） | LL |
|---|---|---|---|---|---|---|
| 値段（案。ステージ 1） | 15 | 25 | 40 | 60 | 90 | 150 |

- ステージ 2・3 は雑魚の CE が ×2・×3 なので、**値段も ×1.8・×2.6**（案）。どのステージでも「1 店で 2〜4 品」に近づける
- 品の札：いまの札（SPEC-087）に **値段の札**（CE のアイコンと数。足りなければ赤）を足す

### 4.3 取り置き（ロック）とお断り（追放）とリロール

| 操作 | 決まり（案） |
|---|---|
| **取り置き** | 札の 🔒 を押すと、次の店にもその札が同じ値段で残る。いくつでも。買うか外すまで残る（ステージが変わると外れる。装備がステージごとなので） |
| **お断り** | 札の ✕ を押すと、その系列は **この挑戦のあいだ二度と出ない**。**1 挑戦 3 回まで**（スキルツリーで増やせる）。初期武器は断れない |
| **リロール** | 取り置き以外を引き直す。**CE を払う**（1 回目 5 → 10 → 15…。店ごとに戻る）。スキルツリーの「引き直し」は **ただのリロール** の回数になる |
| **出る** | 「次のウェーブへ」。残った CE は持ち越す |

- お断りした系列は、店の下の「お断りした品」に小さく並べる（戻せない）
- 参考作の「ロック」は買えないけれど欲しい品を残すもの、「追放」はビルドの方向を固めるもの。どちらも **運の悪さを自分の判断で減らす道具**

### 4.4 いまのレベルアップにひもづくものの行き先

| いま | v1.6 |
|---|---|
| 経験値・レベル・`xpToNext` | **無くす**（CE の残高だけ）。HUD の経験値の帯は「CE の残高」と「次の店まで」の帯に |
| マジックカード（レア敵・ボス戦の宝箱。拾うと即レベルアップ） | **ギフト券**：次の店で 1 品ただ（行き先 Lv.4 まで） |
| リロール（ステージごと 3 回） | ただのリロールの回数（ステージごと 1 回＋スキルツリー） |
| スキップ | 「何も買わずに出る」（いつでもできる） |
| スキルツリー「学びの速さ」（経験値 ＋4%） | **CE ＋4%**（段ごと） |
| スキルツリー「先手」（開始時にレベルアップ） | **開始時の CE ＋20**（段ごと） |
| スキルツリー「見送りの礼」（スキップで HP 回復） | **何も買わずに出ると HP 10% 回復** |
| スキルツリー「天才」（開始レベル ＋2・リロール ＋2） | 開始時の CE ＋40・ただのリロール ＋2 |
| 固有スキル：クリプトスラッシュ（レベルアップのたびに一撃） | **店を出るたびに** 周りをなぎ払う |
| 固有スキル：テトラクテュス（4 回目のレベルアップで 2 段） | **4 品目を買うたびに** その品が 2 段上がる |
| 固有スキル：毒霧・テスラコイル・スラッシュのダメージ（レベルで伸びる） | **固有スキルの強化段**（5 章）で伸びる |
| 活動レポートのスコア「最高 Lv × 500」 | 「**買った品の数** × 300」（スコアの式の版を上げる） |

- スキルツリーの節は **id も費用もそのまま**、効き目だけを読み替える（払った GUM はそのまま効く）
- RTA のレギュレーション（Survivor の NORMAL・ABSOLUTE）は **新しい版** にする（遊びが変わるので記録を分ける）。総合スコアの係数は共通基盤 SPEC-002 で見直す

## 5. 固有スキルの強化（要件 3）

- ショップの右（狭い画面は上）に **常設の札**：ヒーローの顔・固有スキルの名前（MCH のパッシブスキル名）・いまの段 `Lv 1 / 5`・次の段で何が伸びるか・値段
- 段は **Lv.1（はじめから）〜 Lv.5**。値段（案）：Lv.2 40 → Lv.3 70 → Lv.4 110 → Lv.5 160（ステージの倍率は掛けない。持ち越すので早く買うほど得）
- **挑戦のあいだ、ステージ 1〜3 をまたいで残る**（装備はステージごとに空に戻るので、ここが「ラン全体のビルド」の背骨になる）。ゲームオーバー・再走・タイトルに戻る で Lv.1 に戻る。メニューの「ステージをはじめからやり直す」では、そのステージに入ったときの段に戻す
- 段で伸びるもの（案。各 Lv で同じ割合ずつ）

| ヒーロー | 固有スキル | 段で伸びるもの（Lv.1 → Lv.5） |
|---|---|---|
| MCHウォーリアー | クリプトスラッシュ | 一撃のダメージ 1 倍 → 3 倍・半径 150 → 230 |
| ビリー・ザ・キッド | ワンホールショット | 最大の倍率 ×2 → ×3 |
| 霧隠才蔵 | 忍術・毒霧 | 霧のダメージ 1 倍 → 3 倍・残る時間 2.4 → 4 秒 |
| ジャックザリッパー | ランゲルライン | 最大の倍率 ×1.8 → ×2.6・届く距離 160 → 220 |
| ニコラ・テスラ | テスラコイル | 連鎖 3 → 7 体・間隔 2.2 → 1.4 秒 |
| ピタゴラス | テトラクテュス | Lv.3 から 3 品目ごと、Lv.5 で「2 段」が「3 段」 |
| 許褚 | 虎痴 | 最大の倍率 ×1.5 → ×2.2 |
| フランシス・ドレーク | 女王直属海賊 | 速くなる時間 1.5 → 3 秒・CE の拾える範囲 ×1.5 → ×2.2 |
| アナスタシア | 幻の生存者 | 耐える回数 1 → 2（Lv.4 から）・消える時間 3 → 5 秒 |
| 大長今 | 李氏朝鮮、宮廷医女 | 毎秒の回復 0.8 → 2・回復アイテム ×2 → ×3 |

## 6. LL の解放条件（要件 4）

- LL の札（SPEC-101）は、**そのヒーローで 3 ステージをクリアしたことがある** ときだけ出る（強さは今のまま）。v1.6 では、ショップの品として「LL ランクアップ」（150 CE。初期武器が Lv.5 のとき 1 枚目に必ず並ぶ）
- 記録：`mcs.meta.v1` に `heroClears: { <heroId>: 回数 }` を足す。全ステージをクリアした（活動レポートに進んだ）ときに 1 足す。モード（NORMAL・ABSOLUTE・RTA）は問わない
- いままでのクリアは、ヒーローごとに残っていないので数えない（ヒーローの顔ぶれも 2026-10-19 に変わったばかり）
- ヒーローの選択画面：まだなら「LL：このヒーローで全ステージをクリアすると解放（真・MCHブレード）」、解放ずみなら今の虹色の表示。解放した瞬間は活動レポートで「LL 解放！」と知らせる

## 7. 敵・撃破数・クラウン・ミッション

### 7.1 撃破数の節目の演出（要件 7）

- 節目（通算の撃破数。ステージをまたいで数える）：**100・250・500・1,000・1,500・2,000・3,000・5,000・7,500・10,000**、その先は 5,000 ごと
- 画面の上（HUD の下・ボスの予告と重ならない段）に、**大きな数字の通知**：「**1,000 KILLS!**」。数字が弾けて出る・金の光の筋・効果音・1.6 秒で上へ抜ける。**遊びは止めない**（時間を止めない・操作を奪わない）
- 敵の段階が上がる節目では、通知の下に小さく「敵が強くなった：巨大な個体が出る」
- 動きを減らす設定では、光と弾ける動きを止め、文字だけ 1.2 秒

### 7.2 敵の段階と新しい型（要件 6）

- **脅威の段階 T**：そのステージの撃破数で上がる（案：0 / 150 / 400 / 800 / 1,500 体で T0〜T4）。ステージが変わると T0 に戻る（ステージの強さはいままでどおりステージの倍率が持つ）
  - 演出の節目（通算）と段階（ステージごと）を分けるのは、ステージ 3 の頭からいきなり最強の敵が出ないようにするため（8 章 Q4）
- 段階が上がるたびに、次の型が出始める（出る割合は段階で増える）。**強い型ほど CE が多い**

| 型 | 出始め | 見た目と動き | 強さ（雑魚の何倍） | CE |
|---|---|---|---|---|
| **巨大** | T1 | 1.6 倍の大きさ・少し遅い | HP ×4・接触 ×1.5 | ×4 |
| **疾走** | T1 | 速い（×1.8）。まっすぐ追ってくる | HP ×1.2 | ×2 |
| **連射** | T2 | 撃つ敵の強化版：3 方向 → 5 方向・間隔が短い | HP ×2 | ×4 |
| **横断** | T3 | プレイヤーを追わず、画面の端から反対の端へ **一直線に高速で横切る**（3〜5 体の列）。予告の線を 0.6 秒見せる | HP ×1.5・接触 ×2 | ×5 |
| **精鋭** | T4 | 巨大＋疾走（大きく速い）。金の縁 | HP ×8 | ×10 |

- 絵：資産リポジトリの同じ系統の上位の姿を使う（例：クリーパー ショート → トール → グランデ → ヴェンティ → マキアート → フラペチーノ → ドッピオ。名前の並びがそのまま強さの梯子になる）
- 同時に出せる数の上限（`maxEnemies`）は変えない。強い型は雑魚の枠を置き換えて出す（重くしない）

### 7.3 クラウンシリーズ（要件 2）

- 強化（buff）に **クラウン** を足す（11 種目）。資産リポジトリの品をそのまま使う

| 段 | 品（id） | スキル名（MCH） | 効き目（案） |
|---|---|---|---|
| Lv.1 | クラウン（1036） | マジェスティ | 敵の CE ＋15% |
| Lv.2 | エリートクラウン（2036） | エリートマジェスティ | ＋30% |
| Lv.3 | ウィズダムクラウン（3036） | ウィズダムマジェスティ | ＋50% |
| Lv.4 | 宝冠（4036） | 奉神礼 | ＋75% |
| Lv.5 | 冕冠（5036） | 皇帝の威光 | ＋100%。宝箱・壺の CE も ×2 |

- 「先に投資して、あとで多く買う」品。ショップで早く買うほど得をする（参考作の経済系の品にあたる）
- LL（真・冕冠 5536）は使わない（LL は初期武器だけ。SPEC-101）

### 7.4 ミッション（要件 5）

- **いつ**：ウェーブの途中（ウェーブの 10〜30 秒目）に、1 ウェーブで最大 1 回、出る確率 40%（案）。ボス戦・ボスの予告中・ショップの直前 10 秒は出さない。1 ステージで最大 3 回
- **出し方**：画面の上に **シャドーヒーローのカットイン**（顔の小窓・名前・ミッションの文・報酬）。**時間を止めて**「受ける」「断る」を選ぶ（キーボードは Y / N）。参考作やトロピコ・Civ の「使者が来る」場面にあたる。断っても何も起きない
- **受けたら**：その条件が一定時間（20〜40 秒）かかる。最後まで **生き残れば達成**（ミッションによっては追加の条件：「その間に 150 体倒す」「被弾しない」など）。HUD の上に残り時間と達成条件
- **報酬**（案。ミッションの重さで決める）：CE の大袋（＋40〜150）／ギフト券（次の店で 1 品ただ）／固有スキル ＋1 段（いちばん重いものだけ）／お断りの回数 ＋1
- 失敗（条件を満たせない・時間内に倒れる）でも罰は無い（その厳しい時間そのものが賭け）

|---|---|---|---|---|---|
| シャドー呂布 | 481 | **人中に呂布あり** | 敵の湧きが 10 倍（同時の上限まで） | 25 秒 | 重 |
| シャドージャックザリッパー | 767 | **霧の夜** | 画面が濃い霧（自分のまわり半径 180px しか見えない） | 30 秒 | 中 |
