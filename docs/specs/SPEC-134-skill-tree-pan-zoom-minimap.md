# SPEC-134 — スキルツリーの動かし方（Workshop の作り）

- **Status**: Done
- **Issue**: #170
- **関連**: SPEC-133（マス目の配置）・SPEC-094（操作 UI）。続き：SPEC-135（画面の分け方）

## 1. 作者の依頼（2026-10-20）

MyCryptoWorkshop のスキルツリーの仕組み 3「動かし方（パン・ズーム・ミニマップ）」を持ち込む。

## 2. 変えたこと

- **盤面**は 1 つの div に入れ、`translate(x, y) scale(z)` だけで動かす（いままでどおり）
- **ドラッグ**：pointerdown は表示領域、pointermove と pointerup は window で受ける（表示の外へ出ても続く）。新しい 1 本目の指が来たら、取りこぼした古い指の記録を消す。動いた量が 6px（縦と横の和）を超えたら、そのあとのタップでノードを選ばない
- **ピンチ**：指の中点の下にある盤面の点が、拡大縮小しても指の下に残る。2 本目の指は、ミニマップやボタンの上に置いてもピンチに加わる。ピンチのあと 1 本だけ残ったら、そこからドラッグを続ける
- **ホイール**：カーソルの位置を軸に（×1.1 ずつ）
- **ズームの範囲**：上限 1.6。下限は「木全体が余白 1.5 マスつきで収まる倍率」で、0.35 を超えない
- **ミニマップ**（canvas）：見えているノードを点で（取ったものは塗り、まだのものは輪。いま取れないものは薄く）。いま見えている範囲を白い枠で。押す・なぞるとその場所へ（1 本目の指だけ）。PC は左下のボタンの上（150×110）、狭い画面は右下の「戻る」の上（90×66）
- **道のタブ**：その道のいま取れるノードの平均の位置へ。無ければ見えているノード、それも無ければ道全体
- **ボタン**：− / ＋ / 中心へ / **全体**（いちばん引いて木の真ん中へ）
- 木を閉じたとき・組み直したときは、window の受け口を外す（AbortController）
