# SPEC-168 — サブの武器は別の枠・店の 3 列で強化・サブの速さはメインと同じ

- **Status**: Approved（作者の依頼 2026-10-24）
- **関連**: SPEC-166（チーム編成。 §6 Q1 の A → B に改める）・SPEC-110 / 128（固有スキルの強化の札）・SPEC-162（装備の引き継ぎ・15 段）・SPEC-167（店の枠）

## 1. 作者の依頼（2026-10-24）

1. サブの動きが少し機敏すぎる。 メインと同じ速さになっているか
2. **サブの武器とメインの武器は枠を分けたい。** 手裏剣を持つサブがいても、 メインの装備の枠に手裏剣は入らない。 店で手裏剣を買えば、 メインも手裏剣を撃てる
3. **武器以外のエクステ（リンゴ・ホースなど）の効果は、 メインとサブで共有したい**
4. 店の固有スキルを強化する欄を **3 列** にし、 **メインの固有スキル・サブ 1 の武器・サブ 2 の武器** をそれぞれ強化できるようにしたい
5. 狙い: 終盤は CE が余りがち。 枠を分けて使い道を増やす

## 2. 速さ（直す前と後）

| | 直す前 | 直した後 |
|---|---|---|
| ついてこい！ | 立ち位置へ指数で寄る（速さの上限なし）。 メインが向きを変えると、 左後ろ・右後ろの立ち位置が一瞬で入れ替わり、 サブが反対側へ飛んでいた | **メインのいまの速さ**（ホースの強化も入る）で歩く。 立ち位置から離れたぶんだけ最大 +35% で追いつく（50px から 300px で上がる）。 **隊列の向きは 1 秒に 4 ラジアンまで回る**（向きを変えてもサブはゆっくり回りこむ） |
| ザコを狩れ！・強敵を狙え！ | メインの 1.05 倍 | メインと同じ |
| 動き回れ！ | メインの 0.85 倍 | そのまま（メインのいまの速さの 0.85 倍） |
| 離れすぎたとき（380px） | 1.4 倍 | 追いつきの上乗せ（最大 +35%） |

## 3. サブの武器

- **メインの装備の枠（武器 5・強化 5）に入れない。** 店の品・レベルアップの札・枠の数え方はメインの装備だけを見る
- サブの武器は **持ち主つきの別の武器** として撃つ（`weapon.owner = 0 / 1`）。 メインが同じ系列を店で買えば、 メインとサブが別々に撃つ（撃つ時刻・ブレードの刃・レーザーも別）
- 本作の 10 人はいつも自分の初期武器（以前はメインと同じなら別の系列へずらしていた）。 10 人以外はアトリビュートから（SPEC-166 §4.7 のまま）
- **段は Lv.1 から始まり、 店の 3 列で 1 段ずつ上げる。 Lv.15 で止まる（LL はメインの初期武器だけ）。** 段は挑戦のあいだ残る（ステージをまたぐ。 同じステージのやり直しでは入ったときの段に戻す。 `state.run.subLv`）
- **強化エクステ（リンゴ・ホース・本の数など）とヒーローのステータスの倍率、 JIN の補正は全員の武器に効く**（いままでどおり、 武器の計算は同じ倍率を掛ける）

## 4. 店の 3 列

- チームで出ているときだけ、 固有スキルの札を **3 列** にする: 1 列目がメインの固有スキル（いままでの札）、 2・3 列目がサブの武器（顔・武器の絵・系列の名前・段・威力と数の伸び・ランクアップの印・上げるボタン）
- **値段は、 店でその武器の次の段を買うときと同じ**（行き先の段の値段 × ステージの倍率。 黒髭の 2 割引も効く）。 Lv.2 が 20、 Lv.4 が 50 … Lv.15 は 3,300（ステージ 3 は ×2.6）
- **店の枠（SPEC-167）には数えない**（何段でも、 CE があれば）
- スマホでも PC でも、 品の上に横いっぱいの 3 列。 ソロのときはいままでの札のまま

## 5. 変えないもの

- サブは当たり判定なし・倒れない。 HP・固有スキル・LL はメインだけ
- ストーリーと RTA はソロ。 チームはテスト用（`?test=1` とテスト用のサイト）だけ

## 6. 実装

- `js/team.js`: `subSpeed`・`turnDir`・`CATCHUP_*`・`TEAM_TURN_RATE`。 `SUB_SPEED_MUL` は 1
- `js/battle/team-battle.js`: サブの武器を `ownedExtensions` に入れない。 `weaponKey`・`weaponOrigin(武器 か 鍵)`・`levelUpSub`。 速さの計算
- `js/battle/extensions-as-weapons.js`: `rebuildWeaponsFromOwned` がサブの武器を持ち主つきで足す（撃つ時刻は持ち主ごとに残す）
- `js/battle/archetypes.js`: 撃つ位置は武器から。 ブレードの刃とレーザーは `weaponKey` で持ち主を覚える
- `js/battle/index.js`: `carryOwnedExtensions` がサブの段も引き継ぐ
- `js/battle/shop.js` + `css/shop.css`: 3 列（`_subCell`・`subUpPrice`・`buySubUp`）
- `js/main.js`: 編成の帯のサブの武器も同じ決め方に

## 7. 確かめたこと

- テスト: 速さ（同じ・追いつきの上限・向きの回り方）、 メインとサブが同じ手裏剣でも別の武器・持ち主の位置から・段の引き継ぎ・Lv.15 で止まる
- ブラウザ（`?test=1`・412×915 と 1280×800）: メインは手裏剣 1 本だけを装備の枠に持ち、 サブのナイフとホーキは別に撃つ。 右へ走るとメイン 194・サブ 194 / 194 px/秒。 反対へ向きを変えた直後の 0.3 秒はサブ 103 / 196 px/秒（メインより速くならない）。 店の 3 列でサブ 1 のナイフを 2 段上げて Lv.3（CE 3,000 → 2,950）
