# SPEC-079 — ボス戦の場：敵が消え、枠が 1/4 に縮み、ボスは真ん中に出る

- **Status**: Done
- **関連**: SPEC-045（ボスの予告）・SPEC-061（カウントダウン）・SPEC-071（10 秒前）・SPEC-078（敵の密度）

## 1. 背景

作者の依頼（2026-10-17）：

- ボスが出現したら他のエネミーは消滅して、ステージを 1/4 に縮小（ステージ内に枠ができる感じ）して、緊張感を持たせたい
- ボスが出現する場所はエリアの中央にして、出現予定場所を赤い丸で示してほしい
- ボスが出現したらエネミーは消滅するようにしたい（CE はドロップしない。ドロップ済の CE は残る）

いまは、ボスは自分の上から現れ、ほかの敵も湧き続けていた。

## 2. 仕様

### 2.1 出る場所と予告（`js/battle/arena.js`・`js/battle/arena-render.js`）

- ボスは **ステージの真ん中**（`BOSS_SPAWN_POS` = (0, 0)）に出る
- 予告のあいだ（4:00 の 10 秒前から）、その場所に **赤い丸**（ボスの大きさ）を描く
  - 中が脈打ち、外の点線の輪が回り、照準の十字と「BOSS」の文字
  - これから閉じる枠を点線で示す
  - 画面の外なら、画面の縁に赤い矢印

### 2.2 ほかの敵が消える（`js/battle/enemies.js` の `clearForBoss`）

- ボスが出る瞬間に、ボス以外の敵（撃ってくる敵・木馬も）を消す
  - 撃破に数えず、CE も落とさない
  - 画面の中の敵は、煙のように消える（粒）
- 落ちている CE・お助けアイテム・マジックカード・壺・宝箱は残る。枠が閉じるとき中へ寄る
- 敵の弾も消す
- ボス戦のあいだは、敵（ふつう・群れ・密度の補充・レア・撃ってくる敵）が湧かない。置いていった敵の寄せ直し（SPEC-078）もしない

### 2.3 枠（`js/battle/arena.js`・`js/battle/player.js`・`js/battle/gimmicks.js`）

- ボスが出たら、ステージの真ん中に **1/4 の広さの枠**（幅 500 × 高さ 750。ステージの幅も高さも半分）が、1.4 秒かけて世界の縁から閉じてくる
- 自分・ボス・壺・宝箱は枠の外へ出られない（外にいたら壁に押されて入る）
- カメラは枠の中を映す（枠のほうが画面より小さい向きは、枠を真ん中に）
- 枠の外は暗くし、枠の縁は赤く脈打つ太い線・内側の細い線・角の括弧で示す
- 仕掛け（そろばんの珠の列・パンチの印）も枠の中に収める
- 次のステージの始まりに枠を外す

### 2.4 文言

- マインちゃん（ボスが来たとき）：「ボスが来た！ 敵は消えたよ。枠の中で決着をつけよう！」
- 遊び方：「4 分でボスがステージの真ん中に出る（10 秒前から赤い丸で知らせる）。出るとほかの敵は消え、真ん中の枠の中で戦う。倒すか、5 分耐えるとクリア」

## 3. 非ゴール

- ボスの出る時刻（4:00）・ステージの長さ（5:00）は変えない
- ボスの強さは SPEC-080、ボス戦の宝箱は SPEC-081

## 4. 受け入れ基準

- [x] 予告のあいだ、ステージの真ん中に赤い丸が出る
- [x] ボスが出ると、ほかの敵が消え（撃破数・CE は増えない）、落ちている CE は残る
- [x] 枠が閉じ、外にいた自分は中へ押し込まれる
- [x] ボス戦のあいだ敵が湧かない
