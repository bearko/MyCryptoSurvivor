# SPEC-094 — スキルツリーの詳しい欄と操作：Workshop の作りに寄せる

- **Status**: Done
- **関連**: SPEC-090（スキルツリー）・SPEC-093（いまの効果の欄・初回の案内）
- **参考**: MyCryptoWorkshop のツリー（`src/style.css` の `.detail-*`・`.btn-primary`・`.btn-buy`・`.tree-zoom`）、10 buy year! のツリー

## 1. 背景

作者の依頼（2026-10-18）：

- 「作り直す」はめったに使わないのに、押しやすい右下にあるのは違和感がある
- 10 buy year! や Workshop を参考に、ボタンを強調するグラデーションなど、スキルの詳しい表示をはじめとした操作・参照の UI をよくしたい

## 2. 仕様

### 2.1 詳しい欄（節を選んだとき）

- 頭：大きなアイコン（60px・道の色の枠。取った節は白い枠）、道と種類の札、名前、強化の節は**段の目盛り**（`Lv 3 / 5` と金の目盛り）
- 説明のあとに**条件の一覧**：親の節・奥義の「この道の節を 4 つ」・GUM・ゴールドダスト。満たしたものは ✓ で薄く、まだのものは ✗ と「あと n」
- **変化の一覧**：その節を取ると変わる値を `最大 HP  ＋12% → ＋16%`（SPEC-093 の `perkRows`）
- ボタンは立体のグラデーション（下に影、押すと沈む）：解放は**金**、強化（2 段目から）は**緑**、取り終えたものは落ち着いた色、取れないものは灰色。費用はボタンの中に

### 2.2 置き場所

- **幅 900px 以上**：Workshop と同じく右の列（320px）。上に詳しい欄、下に「いまの効果」
- **それより狭い画面**：今までどおり下の欄（詳しい欄）と、木の右上の「いまの効果」の札
- 何も選んでいないときの下の欄は「▶ 解放できます」の近道だけ（狭い画面で木を広く見せる）
- **「中心へ」は木の左下へ**。縮める（−）・広げる（＋）のボタンと並べる
- **「作り直す」は「いまの効果」の欄のいちばん下に小さな文字のリンク**（「ツリーを作り直す（全額戻る）」）。押すと確かめる（戻す／やめる）。狭い画面では札を開くと見える

## 3. 非ゴール

- 節の費用・効果・並びは変えない
