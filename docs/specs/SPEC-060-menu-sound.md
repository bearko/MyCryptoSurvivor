# SPEC-060 — メニューの BGM とボタンの音

- **Status**: Done
- **関連**:
  - SPEC-017（BGM と SE）・SPEC-025（音のパス）・SPEC-044（音量の設定・タブを離れたら止める）
  - SPEC-058（結果のテロップとジングル）

## 1. 背景

作者の依頼（2026-10-17）：ゲーム画面（戦闘）以外にも BGM と SE がほしい。ボタンのクリックの音は `crash.mp3` がよさそう。

いまは戦闘の BGM（`pvp.mp3`）と戦闘の中の SE だけで、タイトル・モード選択・ヒーロー選択・結果の画面は無音。

## 2. 仕様（`js/ui-sound.js` 新規）

### 2.1 ボタンの音

- ボタン（`button`・`.btn`・`[role="button"]`）とスイッチ（`input[type="checkbox"]`）を押すと `Audio/SE/Actions/crash.mp3`（`SFX.UI_CLICK`・音量 0.45・60ms の連打よけ）
- 文書全体の `click` を 1 か所で見る（ボタンごとに書かない。あとから足したボタンも鳴る）
- 自分の音を持つものは鳴らさない：レベルアップのカード（武器・強化・回復の音）、冒険を始める（`tooldev.mp3`）。ほかに鳴らしたくないものは `data-se="off"` を付ける
- 押せないボタン（`disabled`）は鳴らさない

### 2.2 メニューの BGM

- 曲は `Audio/BGM/land.mp3`（`BGM_MENU`・音量 0.26。戦闘の BGM 0.32 より少し小さく）
- 流すところ：タイトル・モード選択・ヒーロー選択（戦闘に入ると戦闘の BGM に替わる）
- ブラウザは操作の前に音を出せないので、タイトルでは**最初に触ったとき**（押す・キー）に始める。読み込んだだけでは鳴らない
- タイトルに戻ったとき（メニューから・ゲームオーバーから・活動レポートから）にまた流す
- すでに流れていれば頭から流し直さない（モード選択とヒーロー選択の行き来）
- ゲームオーバー・活動レポート：ジングル（勝ち 3.5 秒・負け 5.3 秒）が鳴り終わってから流す（勝ち 3.8 秒・負け 5.6 秒あと）。そのときもう別の画面（リトライ・タイトル）にいれば何もしない
- ステージクリア（次のステージへ）は、いままでどおり戦闘の BGM のまま

### 2.3 変えないもの

- 音量は設定（BGM・効果音）に従う。0 なら鳴らさない・読み込まない（SPEC-044）
- タブを離れたら止め、戻ったら再開する（SPEC-044）
- 音は演出だけで、ゲームの中身・スコア・RTA の時間には関わらない

## 3. 非ゴール

- 画面の切り替え（ワイプ）・モーダルを開く音は足さない（ボタンの音と重なるため）
- 戦闘の中の SE は変えない

## 4. 受け入れ基準

- [x] タイトルを最初に触るとメニューの BGM が始まる。読み込んだだけでは鳴らない
- [x] タイトル・モード選択・ヒーロー選択・メニュー・設定のボタンとスイッチで `crash.mp3` が鳴る。冒険を始めるは `tooldev.mp3` だけ
- [x] 戦闘に入るとメニューの BGM が止まり、戦闘の BGM になる
- [x] メニューからタイトルに戻ると、戦闘の BGM が止まりメニューの BGM になる
- [x] ゲームオーバーでジングルのあとメニューの BGM、リトライで戦闘の BGM

## 5. テスト

- `node --test tests/ui-sound.test.mjs`：ボタンなら鳴らす・ボタンでない／押せない／自分の音を持つものは鳴らさない、クリックの音は crash.mp3、メニューの BGM は戦闘の BGM と別の曲で音量は控えめ、ジングルの長さより後に BGM を流す
- ヘッドレスの Chromium で `HTMLMediaElement.play` を見張り、操作ごとに鳴った音を記録した：

| 操作 | 鳴った音 |
|---|---|
| 読み込んだだけ | （なし） |
| タイトルを最初に触る | land.mp3（ループ） |
| Press to Start・NORMAL・ヒーローのタイル | crash.mp3 |
| 冒険を始める | tooldev.mp3 → land.mp3 を止めて pvp.mp3（ループ） |
| メニュー → タイトルに戻る | crash.mp3 → pvp.mp3 を止めて land.mp3（ループ） |
| 設定・演出を減らすのスイッチ | crash.mp3 × 2 |
| ゲームオーバー | pvp.mp3 を止めて lose.mp3 → 6 秒後に land.mp3（ループ） |
| リトライ | crash.mp3 → land.mp3 を止めて pvp.mp3（ループ） |
