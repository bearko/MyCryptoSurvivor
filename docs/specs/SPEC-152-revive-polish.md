# SPEC-152 — 復活の仕上げ（黒画面のまま吸い込む・木は半透明にしない）、 EASY の開幕の店をやめる（開幕の店は節「先行オープン」に）、 止まっているあいだの揺れ

- **Status**: Done
- **関連**: SPEC-151（復活 v2）・SPEC-147（EASY）・SPEC-103（店の時刻）・SPEC-090（スキルツリー）

## 1. 作者の報告（2026-10-21）

1. ステージ 1 で、 マインちゃんのセリフ（レッスン）を出したあとなどに、 背景を覆う半透明の黒い層が**少しずれて**表示されることが度々ある。
2. ステージ 2 に進むと開幕すぐに店が開くが、 CE はステージ 1 で固有スキルに注ぎこまれていて何も選べない。 CE を持ち越さない仕様になったので開幕の店の必要が無い。 ギフト券や先手（スキルツリーの初期 CE）と組み合わせれば意味があるので、 **開幕の店はスキルツリーの強化要素として解放**したい。 少なくとも EASY では開幕に店を開かない。
3. スキルツリー画面全体が半透明になっている（= 渦の暗い層が木の上に乗っていた）。
4. 「復活する」を押すと、 真っ暗な画面から一瞬前のステージが映りこんで次のステージへ遷移する。 粒子が下へ吸い込まれ終わるまで黒画面のままにしたい。

## 2. 直したこと

| | 原因 | 直し |
|---|---|---|
| 黒い層のずれ | 被弾の揺れは `tickFx` で減るが、 レッスン・店で止まっているあいだは減らない。 `shakeOffset()` は揺れが残っているかぎり毎コマ乱数でずらすので、 止まった瞬間の揺れが残って画面を覆う暗い層（= 背景の塗りや縁）がずれたまま見えていた | `shakeOffset()` は **止まっているあいだ（`pauseFlags > 0`）と倒れたあとは 0**（`js/battle/fx.js`） |
| EASY の開幕の店 | `EASY_STAGES` の `shopTimesMs` に 0 があった | ステージ 2 は `[15000]`、 ステージ 3 は `[15000, 30000]`（`js/easy.js`） |
| 開幕の店を節に | `SHOP_FIRST_MS = [10000, 0, 0]`（ステージ 2・3 は開始の前） | 節 **「先行オープン」**（`trs_open`・強化の目利きの道・誘い（`trs_rare`）の先・(1, 4)・150 GUM・perk `shopAtStart`）。 **無ければステージ 2・3 もステージ 1 と同じ 0:10 から**（`shopTimesMs(idx, { atStart })`）。 **RTA は節が効かないが、 レギュレーションを変えないので今までどおり開幕に開く**（`perks.shopAtStart()` は `state.rtaMode` で true）。 ミッションの時刻の計算も同じ時刻を使う |
| 木が半透明 | 渦の canvas（`z-index: --z-modal-top − 1 = 329`）が木（260）より上で、 暗い層ごと木に重なっていた | 木を開いているあいだは渦の canvas を隠す（`.revive-fx--hold`。 閉じたら戻す） |
| 復活で前のステージが映る | 吸い込み（sink）で暗さを晴らし、 終わったら canvas を消していたので、 戦闘が始まるまでの一瞬に前のステージが見えていた | sink のあいだに**真っ暗まで暗くし**、 終わったら **hold**（真っ暗）で待ち、 降りこみ（rain）のあいだに**降りこみながら晴れる** |

- 先行オープンは「先手」（ステージの始めに CE）やギフト券と組み合わせてはじめて意味がある、 と説明文に書いた。
- `NO_PERKS` に `shopAtStart: 0`、 木の「発動中の効果」に「先行オープン」。

## 3. 確かめ方

- `node --test tests/*.test.mjs`（店の時刻 `atStart` の有無・EASY の店の時刻・節の数と総額・配線・揺れ）。
- ブラウザ: 倒れる → 復活する → 吸い込みのあいだも暗いまま → 戦闘が始まっても暗いまま → 降りこみながら明るくなる。 スキルツリーを開くと渦の canvas が消え、 閉じると戻る。
