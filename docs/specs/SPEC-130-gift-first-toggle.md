# SPEC-130 — ギフト券で払うか CE で払うかを選べるように

- **Status**: Done
- **関連**: SPEC-109（ギフト券）・SPEC-127（枚数の傾斜）

## 1. 作者の依頼（2026-10-20）

- ギフト券で買うか、GUM（ショップでは CE）で買うかを自由に選べるように
- 基本はギフト券を優先。持っている券で買える品は、券で買う表示に
- 券を貯めるために CE で払いたいとき用に「ギフト券支払いを優先」のチェックボックス。オフにしたら CE 払いに切り替える
- オン・オフは次に開いたときも覚えておく

## 2. 変えたこと

- **優先がオン（既定）**：持っている券の枚数で買える品は、**どれも**「🎟 ギフト券 ×n」で出る（前は、いちばん高い 1 品だけだった）。1 品買うたびに残りの枚数で見直す（3 枚持っていて Rare（2 枚）を買えば、残り 1 枚で買える品だけが券のまま）
- **優先がオフ**：どの品も CE の値段で出る。券は使わず貯まる
- チェックボックスは手持ちの欄（◆CE・🎟×n の下）。券を 1 枚以上持っているときだけ出る
- 覚えておく：`localStorage` の `mcs.shopGiftFirst`（"0" でオフ。無ければオン）。保存できない環境でも、その店の中では効く
- 最初の店のサービス（1 品無料）はいままでどおり、券より先

## 3. 確かめたこと

- ブラウザ（390×740）で：券 3 枚・オンで品が「🎟 ギフト券 ×1」→ 1 品買うと券 2 枚・CE はそのまま。オフにすると「◆ 15」になり、買うと CE が減って券は 2 枚のまま。次の店でもオフのまま
- ショップは 1 画面に収まる
- `node --test tests/*.test.mjs`：317 件すべて通る
