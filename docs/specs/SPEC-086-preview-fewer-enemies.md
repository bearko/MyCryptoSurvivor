# SPEC-086 — ヒーロー選択のプレビュー：敵を減らす（2 秒ごとに 1 / 2 / 3 体）

- **Status**: Done
- **関連**: SPEC-083（ヒーロー選択の武器のプレビュー）

## 1. 背景

作者の依頼（2026-10-17）：

- ヒーロー選択画面のプレビューで出現する敵の数が多すぎる
- Common のときは一番弱い敵が 1 体ずつ、 Uncommon のときは 2 体ずつ、 Rare のときは 3 体ずつ、 2 秒ごとに出現するくらいのペースにしてほしい

いままでは、 雑魚 2 種を 9 体、 いつも保っていた（倒しても画面の外からすぐ補う）。 武器の動きより敵の群れのほうが目立っていた。

## 2. 仕様（`js/hero-preview.js`）

- 出す敵は **いちばん弱い雑魚**（101。 HP・速さはゲームと同じ）
- 段が替わったらすぐ 1 回目、 そのあと **2 秒ごと**に、 段の数だけ出す

| 段 | 1 回に出す数 | 3 秒のうちに出る数 |
|---|---|---|
| Common | 1 | 2 |
| Uncommon | 2 | 4 |
| Rare | 3 | 6 |

- 見えている縁のあたりから出て、 自分のほうへ歩いてくる（当たっても痛くない。 いままでどおり）
- 倒しても補わない

## 3. 非ゴール

- 流れ（1 秒・3 秒ずつ・戻って 3 秒）と札は変えない（SPEC-083）

## 4. 受け入れ基準

- [x] 画面に出ている敵が、 Common で 1 体前後、 Rare でも数体
- [x] 敵はいちばん弱い雑魚だけ

## 5. テスト

- `node --test tests/hero-preview.test.mjs`：出す敵はいちばん弱い雑魚・2 秒ごと・段の数だけ（3 秒で 2 / 4 / 6 体）
- ヘッドレス Chromium（390×844）：コナン・ドイルとピタゴラスの Common・Uncommon・Rare を撮った（画面の敵は 0〜3 体。 撃破数は 0 のまま。 ページのエラーなし）
