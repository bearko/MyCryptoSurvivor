# SPEC-077 — キャラを大きく・当たりの円を薄く

- **Status**: Done
- **関連**: SPEC-010（絵）・SPEC-034（レアは大きめ）・SPEC-065（円の切り抜きの使い回し）

## 1. 背景

作者の依頼（2026-10-17）：

- キャラの大きさをもう少し大きくしたい。視界が広いのは素晴らしいが、いまはヒーローやエネミーが小さすぎて、キャラクターを動かしている感覚が少し薄れている
- キャラの周りの太い黒丸が格好悪いので、薄い背景に変えるなどして、当たり判定は分かるけど目立ちすぎないようにしてほしい

いまは、絵を当たりの円（自分 14px・雑魚 12〜19px）で切り抜き、黒い縁を引いていた。

## 2. 仕様

### 2.1 大きさ（`js/constants.js`・`js/battle/index.js`・`js/battle/enemies.js`）

- 自分・雑魚・レア・撃ってくる敵は **1.4 倍**（`CHAR_SCALE`）。自分の当たりは 14 → 20px
- ボスは 1.2 倍（`BOSS_CHAR_SCALE`。もともと大きい）
- 絵と当たりの両方を大きくする（見た目と当たりがずれない）。視界（カメラ）はそのまま

### 2.2 描き方（`js/battle/sprites.js`・`js/battle/render.js`）

- 絵は円で切り抜かず、当たりの半径の 2.3 倍（`CHAR_SPRITE_RATIO`）の正方形で描く（絵の縁は透明）
- 足もとに **当たりの目安の薄い円**（`drawHitDisc`。中から外へ薄くなる色と、細い縁。種類と半径ごとに 1 度だけ作って使い回す）
  - 自分：シアン
  - 雑魚：白くごく薄く
  - レア：金
  - 撃ってくる敵：赤い縁（SPEC-062 の見分けを残す）
  - ボス：赤
- 黒い縁はやめた
- 動いている感じ（見た目だけ）
  - 自分：横に動く向きへ少し傾け（足もとを軸に）、歩くあいだ弾ませる。止まっているときはゆっくり息をする
  - 雑魚：少し上下に弾ませる（ボスは弾ませない）
- MCH の絵は向きがそろっていない（正面・左・右）ので、左右の反転はしない

## 3. 非ゴール

- 視界（カメラの倍率）は変えない
- 武器・弾・CE・アイテムの大きさは変えない

## 4. 受け入れ基準

- [x] 自分と敵が大きく見える
- [x] 黒い太い縁がなく、薄い円で当たりの大きさが分かる
- [x] 撃ってくる敵は赤い縁で見分けられる

## 5. テスト

  - 当たりの円が薄いこと（面の濃さ・縁の太さ・黒い縁でない）
  - 自分と敵を円で切り抜かないこと
