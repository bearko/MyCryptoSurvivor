# SPEC-133 — スキルツリーをマス目に置く（Workshop の仕組み）

- **Status**: Done
- **Issue**: #168
- **関連**: SPEC-090（スキルツリー）・SPEC-131（エクステ別のパネル）・SPEC-098（ヒーローの解放）。続き：SPEC-134（動かし方）・SPEC-135（画面の分け方）

## 1. 作者の依頼（2026-10-20）

- 中心からの分岐が多すぎて、どことどこがつながっているのか分かりにくい
- MyCryptoWorkshop のスキルツリーの配置の仕組みを持ち込む（コードを写すのではなく、仕組みを本作の作法で）
- 決めたこと：
  1. 道の向きは下の配置案のとおり
  2. エクステ別は案 A（数珠つなぎ）をもとに、**武器は「そのヒーローを仲間にしていること」を条件にし、そろったら 1 段目は無料**。本作で仲間になるヒーローは数珠つなぎ、ほかのタイトルのアチーブメントで仲間になるヒーローは分岐（先に仲間にすることがあるため）
  3. 奥義は、たどり着くまで見せない

## 2. 盤面

- 座標は整数のマス目（1 マス = 108px）。根「サバイバーの覚醒」が (0, 0)
- 道は方向ごと：攻撃は上・機動は右・財宝は下・成長は左。ボスは攻撃の左隣、生存は財宝の左隣（Workshop の「下」と「左下」の並べ方）
- 各道は 2 列の帯。1 段目 → 2 段目 → 3 段目 → 奥義を軸に沿って一直線に、脇の列にもう 1 本（2 段目・3 段目）
- 道の節は `parent`・`depth`・`lane` で書き、`ROUTES` の `d1`・`axis`・`side` でマス目に写す（座標を手で書かない）
- 道の名前の見出しは道ごとに手で決めた位置（`label`）

持ち主のヒーローがいないので、案 A のまま財宝の 1 段目「金勘定」から数珠つなぎ：ギョク → カエルの標本 → クラウン → グンバイ → りんご → オリフラム → ホース → ブーツ → アーマー → シールド → ラーメン。

## 3. 開き方と見せ方（Workshop の isAvailable / isVisible）

- `requires`：どれか 1 つを取っていれば開く。奥義は 3 段目の 2 つのどちらか ＋ その道の節 4 つ（いままでどおり）
- `hero`：そのヒーローを仲間にしていることも要る（画面が使えるヒーローを渡す）
- 見せるのは「いま取れる節」と「親がいま取れる節」。後者は鍵のかかった姿で、名前は「？？？」。それ以外は隠す
  - 根を取るまでは根だけ（いままでどおり）
  - 奥義は 3 段目に届くまで出ない（前は最初から「？」で見えていた）
- 取ってある節は、条件が変わっても上げられる（前の版で根から取った極意など）
- 線は、見えている親から見えている子へまっすぐ：
  - off：親をまだ取っていない（点線）
  - open：親は取った、子はまだ（道の色を薄く）
  - on：両方取った（道の色で光る）
- 鍵の節の詳しい欄に、条件（「「霧隠才蔵」を仲間にする」「「ピタゴラス」を仲間にする（MyCryptoEducation で）」）を出す

## 4. 保存

- 節の id は変えていないので、取った節はそのまま残る
