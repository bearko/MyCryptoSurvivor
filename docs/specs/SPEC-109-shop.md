# SPEC-109 — ショップ（CE で品を買う。作りかけのあいだは `?shop=1`）

- **Status**: Done（フラグつき。SPEC-111 でフラグを外して本番の遊びにする）
- **関連**: SPEC-103（設計とロードマップ。4 章・8 章）・SPEC-104（閉じたら 3 秒数える）・SPEC-087（札）・SPEC-090c（スキルツリー）・SPEC-100（固有スキル）・SPEC-101（LL）・SPEC-108（クラウン）

## 1. 何をするか

レベルアップの代わりに、一定時間ごとにショップが開く。拾った CE を通貨にして品を買う（SPEC-103 4 章）。

- **フラグ**：`?shop=1` か localStorage の `mcs.shop = "1"` のときだけ。ふだんの遊び（レベルアップ）は変えない
- **時刻**（SPEC-103 Q2）：ステージ 1 は 0:10・0:50・1:30・2:10・2:50・3:30、ステージ 2・3 は開始の前・0:40・1:20・2:00・2:40・3:20。ボスが出たあとは開かない。開いているあいだ時間は止まり、閉じたら 3 秒数えてから再開（SPEC-104）
- **財布**：拾った CE は経験値にならず財布に入る（`state.shop.ce`。学びの速さ・クラウンはそのまま効く）。**挑戦のあいだステージをまたいで残る**。装備はステージごとに空に戻る（Q1）。メニューの「ステージをはじめからやり直す」では、そのステージに入ったときの財布に戻す

## 2. 店主（商人のシャドーヒーロー）

| 店主 | 絵 | 癖 |
|---|---|---|
| マルコ・ポーロ | 480 | 1 品が半額（LL は外す） |
| マゼラン | 821 | 品が 5 枚 |

| コロンブス | 815 | まだ持っていない系列が出やすい |

同じ人は続けて来ない。ステージ 2・3 の開始の前はマルコ・ポーロ。

## 3. 品と値段

- 4 枚（マゼランは 5 枚）。中身はレベルアップの候補と同じ（新しい品は Lv.1、持っている品は次の段。枠の上限・LL の札もそのまま）
- 値段：行き先 Lv.1〜5 で 15 / 25 / 40 / 60 / 90、LL は 150。ステージ 2・3 は ×1.8・×2.6。5 の倍数に丸める
- 足りない札は値段が赤く、押しても買えない
- 買った札は「お買い上げ」で残る（その店では空き）

## 4. 取り置き・お断り・リロール

| 操作 | 決まり |
|---|---|
| 取り置き（🔓） | 次の店にもその札が残る。ステージが変わると外れる。買う・外すまで残る |
| お断り（✕） | その系列はこの挑戦のあいだ出ない。1 挑戦 3 回。初期武器と LL は断れない。断った品は店の下に並ぶ |
| リロール | 取り置きと売れた札のほかを引き直す。ただの回数（ステージごと 1 回＋スキルツリーの引き直し、ガマは店ごとに＋1）を使い切ったら CE を払う（5 → 10 → 15…、店ごとに戻る） |
| 出る | 「次のウェーブへ」。残った CE は持ち越す |

## 5. レベルアップにひもづいていたものの読み替え（SPEC-103 4.4）

| いま | ショップ |
|---|---|
| マジックカード | **ギフト券**：次の店で 1 品ただ（行き先 Lv.4 まで）。券は **ただにできる品のうちいちばん高いもの** に当たる（安い品で使い切らない） |
| スキルツリー「先手」「天才」の開始レベル | 1 段につき開始時の CE ＋20（各ステージの始まり） |
| スキルツリー「引き直し」 | ただのリロールの回数 |
| スキルツリー「見送りの礼」 | 何も買わずに出ると HP 回復（ボタンの文字もそうなる） |
| クリプトスラッシュ | **店を出るたびに** 周りをなぎ払う |
| テトラクテュス | 4 品目を買うたびに 2 段（品を買うことがピックとして数えられる） |
| レベル（固有スキルのダメージ・活動レポートの「最高 Lv」） | `state.level = 1 + 買った品の数`。スコアの式の版は SPEC-111 で上げる |
| HUD の経験値の帯 | 「CE」の残高（◆）と、次の店までの帯 |
