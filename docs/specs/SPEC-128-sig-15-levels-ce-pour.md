# SPEC-128 — 固有スキルを 15 段に、残った CE は固有スキルへ

- **Status**: Done
- **関連**: SPEC-110（固有スキルの強化）・SPEC-123（10 段）・SPEC-109（財布の持ち越し）

## 1. 作者の依頼（2026-10-20）

- パッシブスキル（固有スキル）は上に 5 段を足して 15 段に（カンストのハードルを上げたい）
- CE はステージ持ち越しではなく、パッシブスキルに自動で振り分ける。クーポン（ギフト券）は持ち越しで OK

## 2. 固有スキル：10 段 → 15 段

- 値段（Lv.2〜15）：40 / 100 / 250 / 500 / 1,000 / 2,000 / 4,000 / 8,000 / 16,000 / **24,000 / 36,000 / 54,000 / 81,000 / 120,000**（Lv.10 から先は 1 段ごとに 1.5 倍。合計 346,890）
- 数値：Lv.5・Lv.10 はそのまま、Lv.11〜15 でもう一段伸ばす

| 固有スキル | Lv.10 | **Lv.15** |
|---|---|---|
| クリプトスラッシュ | 威力 ×5・半径 300 | **×7・360** |
| ワンホールショット | 最大 ×4 | **×5** |
| 忍術・毒霧 | 威力 ×5・6 秒 | **×7・8 秒** |
| ランゲルライン | 最大 ×3.4・280px | **×4.2・330px** |
| テスラコイル | 連鎖 11 体・0.9 秒 | **15 体・0.6 秒** |
| テトラクテュス | 2 品目ごと 4 段 | **2 品目ごと 5 段**（Lv.15） |
| 虎痴 | 最大 ×3 | **×3.8** |
| 女王直属海賊 | 5 秒・範囲 ×3 | **7 秒・×3.8** |
| 幻の生存者 | 3 度・8 秒 | **4 度（Lv.13〜）・10 秒** |
| 李氏朝鮮、宮廷医女 | 毎秒 4・回復 ×5 | **毎秒 6・×7** |

テトラクテュスは数値が 2 つしか無いので、Lv.11〜14 では変わらない（Lv.15 で 5 段）。

## 3. 残った CE は固有スキルへ（次のステージへ持ち越さない）

- ステージをクリアしたとき（最後のステージを除く）、財布の CE をすべて固有スキルへ振る。段の値段に届くたびに上がり、届かない端数は**次の段への積み立て**に残る。財布は 0 になる
- 積み立てはショップの札で「Lv 9 へ あと ◆6617」のように残りの値段で出る。ショップで買うときも残りだけ払う
- 固有スキルが最大（Lv.15）なら振れず、CE は消える
- ギフト券はいままでどおり持ち越す
- ステージクリアの画面に 1 行：「残った CE ◆9273 → クリプトスラッシュ Lv 1 → 8」「次まで あと ◆6617」
- ステージのやり直し（メニュー）では、入ったときの段と積み立てに戻す
