# SPEC-046 — 結果の見せ方：ステージの始まり・ステージクリア・ゲームオーバー・活動レポート

- **Status**: Done
- **Issue**: #57（親 #51 v1.0 仕上げ）
- **関連**: SPEC-009（ゲームオーバー）、SPEC-030（ステージ遷移）、SPEC-033・038（活動レポート）、SPEC-043（トークン）

## 1. 背景 / 課題

- ステージクリアのモーダルは「ステージクリア!」とステージ名だけ。そのステージで何をしたか（時間・撃破・Lv）が出ない。枠と見出しがゲームオーバーと同じ赤
- ゲームオーバーは 3 行の文字（経過時間・Lv・撃破数）。どのステージで倒れたかが分からない
- 活動レポートは開いた瞬間に全部出ていて、スコアが「出てくる」瞬間がない
- メニュー・ランキングもゲームオーバーと同じ赤い枠（失敗の色）
- 次のステージに進むと、何の区切りもなく戦闘が始まる

## 2. ゴール

| 画面 | 見せ方 |
|---|---|
| ステージの始まり | 戦場の上に「STAGE 2 / node : ホレリス」の帯を 1.6 秒（遊びは止めない） |
| ステージクリア | 金の枠。見出しが弾んで出る。進み具合の ●●○。そのステージの ⏱ 時間・💀 撃破・Lv をタイルで出し、撃破数をカウントアップ |
| ゲームオーバー | 赤の枠のまま。「ステージ 2 / 3 で力尽きた」。⏱・💀・Lv をタイルで、撃破数をカウントアップ |
| 活動レポート | ヒーロー → ステージのカード → 合計 → スコアの順に出し、スコアは 0 からカウントアップ |
| メニュー・ランキング | 金の枠・見出し（失敗の赤をやめる） |

- 演出は 0.8 秒以内。**画面のどこかを押すと最後の状態まで飛ぶ**（ボタンはそのまま押せる）
- 演出を減らす / reduced-motion では、最初から最後の状態で出す

## 3. 非ゴール

- スコアの計算・ランキングの送信の変更
- 自己ベストの保存

## 4. 技術設計

### 4.1 `js/reveal.js`（新規）

| 関数 | 役割 |
|---|---|
| `easeOutCubic(t)` | 純関数 |
| `countValueAt(to, elapsedMs, durMs)` | 純関数。0 から `to` まで、`elapsedMs` 時点の整数 |
| `countUp(el, to, { durMs, format })` | 数字を書き換える。reduced なら一度で |
| `revealIn(root)` | `root` の `[data-reveal]` に `--i`（順番）を付けて順に出す。`root` を押したら全部出し、カウントアップも終える |

### 4.2 つなぐ場所

- `battle/index.js` `startBattle`：`#stageIntro` を出す（CSS のアニメーションで 1.6 秒）
- `stage-transition.js`：直前に保存したステージのスナップショットからタイルを作る
- `gameover.js`：`state.currentStageIdx` から「ステージ n / 3」
- `activity-report.js`：各ブロックに `data-reveal`、スコアを `countUp`
- CSS：`.result-tiles` `.result-tile` `.stage-pips` `.stage-intro`、`[data-reveal]` の出方、メニュー・ランキング・ステージクリアの金の枠
