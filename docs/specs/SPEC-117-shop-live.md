# SPEC-117 — ショップを本番に：ヘッダーの「次の店まで」の帯・来店で HP 回復・既定で ON

- **Status**: Done
- **関連**: SPEC-109（ショップ）・SPEC-115（次の店までの秒）・SPEC-111（RTA とスコアの版。まだ）

## 1. 作者の依頼（2026-10-20）

- ショップまでの時間がフィールドの外（右上）に出ていて目に入りにくい → **ヘッダーにカウントダウンの帯**。**次に来る商人が左から右へ移動**して来店までの時間を表す。残り秒も併記
- **残り 10 秒**になったらタイマーを目立たせる
- **ウェーブの節目（来店）で体力が少し回復**
- これを入れたら **一旦本番に適用**

## 2. 決まり

### 2.1 ヘッダーの帯

- 置き場所：HUD の XP の帯の場所（ショップで遊ぶときは XP の帯を隠す）。PC は同じ行、スマホは HUD の 2 段目に横いっぱい
- 中身：「次の店 シャドー◯◯」（PC だけ）・帯・右端に店（🏪）・残り秒・財布の CE（◆）
- 帯の上を、**次に来る商人のドット絵が左から右へ歩く**（位置＝その店までの経過の割合。右を向かせる）。店が開くと、その商人が店番をする（帯で予告した人と同じ）
- **残り 10 秒**：帯が金色に光って脈打ち、秒が金の札で大きく脈打ち、商人が速く跳ねる（動きを減らす設定では脈打たない）
- ボスが出たあと・その先に店が無いときは「店じまい」（帯を薄く）
- 戦場の右上の札（SPEC-115）は外した

### 2.2 来店で HP 回復

- 店が開くたびに **最大 HP の 1 割** 戻る（満タンを超えない）。緑の数字と回復の音。店の上に「来店で HP +11」
- 「見送りの礼」（何も買わずに出ると回復）はそのまま

### 2.3 既定で ON

- ショップは **既定で ON**（`?shop=0` か localStorage `mcs.shop = "0"` で今までのレベルアップに戻せる）
- **RTA は今までどおりレベルアップ**で計る（レギュレーション v4 のまま。記録を混ぜない）。ショップでの RTA の版と総合スコアの係数の見直しは SPEC-111
- 遊び方（ヘルプ）の「強くなる」をショップの説明に（RTA はレベルアップと添える）
