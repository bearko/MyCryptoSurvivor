# SPEC-126 — 「ただ」を「無料」に

- **Status**: Done

## 1. 作者の依頼（2026-10-20）

「ただ」はチープな表現なので「無料」に書き換える。ショップのリロールの表記も。

## 2. 変えた文

| 場所 | 前 | 後 |
|---|---|---|
| ショップのリロール | リロール（ただ） | リロール（無料） |
| ヴァスコ・ダ・ガマのひとこと | 1 回はただで並べ直そう | 1 回は無料で並べ直そう |
| ミッションのごほうび（ギフト券） | 1 枚でショップの品が 1 つただ | 1 枚でショップの品が 1 つ無料 |
| 遊び方（光るカード） | 次のショップで 1 品ただ | 次のショップで 1 品無料 |

コードのコメントとテストの名前も同じ言葉にそろえた。

## 3. 確かめたこと

- `node --test tests/*.test.mjs`：すべて通る
- 画面に出る文に「ただ」（「ただし」などを除く）が残っていない（`data/i18n/ui.json`・`js/`）
