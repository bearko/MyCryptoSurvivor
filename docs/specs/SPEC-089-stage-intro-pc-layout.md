# SPEC-089 — PC でステージの始まりの帯のレイアウトを直す

- **Status**: Done
- **関連**: SPEC-046（ステージの始まりの帯）・SPEC-056（帯の手前にヒーロー）・SPEC-077（キャラを大きく）

## 1. 背景

作者の依頼（2026-10-17）：

- PC で見たときにヒーローの冒頭の帯が出るときにレイアウトが崩れる（ヒーローアイコンが小さい、 文字とアイコンが離れすぎている）ので、 スマホのレイアウトはそのままに、 PC でも違和感ないように修正したい

帯（`#stageIntro`）は、 文字を左 9%・ヒーローを右 3% に置き、 ヒーローは 128px だった（SPEC-056）。 スマホ（390px）では文字とヒーローの間が 54px で収まるが、 1280px では **およそ 740px**、 1920px では **およそ 1300px** 離れ（CSS からの計算）、 128px のヒーローは画面の端に小さく立っていた。

## 2. 仕様（`css/chars.css`）

`@media (min-width: 960px)`（`css/responsive.css` の PC の境目）でだけ変える。 スマホの並びは触らない。

- 帯の中身を **真ん中の 560px**（`--intro-w`）に寄せる
  - 文字は `padding-left: max(9%, calc(50% - 280px))`（= 帯そのものは画面いっぱいのまま）
  - ヒーローは `right: max(3%, calc(50% - 280px))`
- ヒーローは **192px**（= 64 の 3 倍。 `image-rendering: pixelated` はそのまま。 半端な倍率はドットがガタつく）。 足もとは `bottom: -24px`
- 文字を少し大きく（STAGE n は `--fs-md`、 名前は 2rem）、 帯の上下の余白を 0.9rem に
- 帯の動き（縦に開く `stage-intro-band`）とヒーローの動き（右から入って左へ抜ける `stage-intro-hero`）は変えない。 「演出を減らす」 でも同じ

| 画面 | 文字の左 | ヒーロー | 文字とヒーローの間 |
|---|---|---|---|
| 390×844（スマホ。 変えない） | 35px | 128px（右端 374px） | 54px |
| 1280×800 | 360px | 192px（720〜912px） | 104px |
| 1920×1080 | 680px | 192px（1038〜1230px） | 102px |

## 3. 非ゴール

- 帯の出る長さ（2.2 秒）・出すタイミング・マインちゃんのセリフは変えない
- 600〜959px（タブレット）はスマホの並びのまま

## 4. 受け入れ基準

- [x] 1280×800 と 1920×1080 で、 文字とヒーローが真ん中に寄って並び、 ヒーローは 192px
- [x] 390×844 は前と同じ（文字 35px・ヒーロー 128px）
- [x] 帯とヒーローのアニメーションは前のまま

## 5. テスト

- `node --test tests/*.test.mjs` → 170 pass
