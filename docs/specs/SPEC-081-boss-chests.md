# SPEC-081 — ボス戦の宝箱：枠の中のゴールデンモアイから、 マジックカードとお助けアイテム

- **Status**: Done
- **関連**: SPEC-053（お助けアイテム・宝箱）・SPEC-076（宝箱の絵）・SPEC-033（マジックカード）・SPEC-079（ボス戦の枠）・SPEC-080（ボスを強く）

## 1. 背景

作者の依頼（2026-10-17）：

- ボスを強化する代わりに、 ゴールデンモアイがボスステージ内に出現するようにしたい
- レアエネミーが落とすレベルアップアイテム（マジックカード）や、 サンダー・パンケーキなどのお助けアイテムを取って強化できるようにしたい
- 宝箱からマジックカードが出るのはボス戦のみ

## 2. 仕様（`js/battle/field.js`・`BOSS_CHEST`・`BOSS_CHEST_DROPS`）

- ボスが出て **6 秒**たつと、 枠の中に宝箱（ゴールデンモアイ。 SPEC-076 と同じ絵）が出る。 そのあと **14 秒ごと**に足す。 場に出ているのは **2 つまで**
  - 自分から 140〜380 px 離れ、 ボスに重ならないところ
  - ボスを倒したら、 もう出ない
- 壊すと、 次のどれか 1 つと CE を落とす

| 中身 | 重み |
|---|---|
| マジックカード（その場でレベルアップ） | 40 |
| パンケーキ（HP 回復） | 30 |
| 雷鼓（画面の敵に雷。 ボスにも大ダメージ） | 20 |
| 棒磁石（CE を吸い寄せる） | 10 |

- **懐中時計は出ない**（RTA の最短時間を変えない）
- ふつうの宝箱（1 ステージ 4 つ）の中身は変えない（マジックカードは出ない）
- 初めて出たとき、 マインちゃんがひとこと：「ボス戦の宝箱！ マジックカードや雷鼓が出るよ。壊して強くなろう！」

## 3. 非ゴール

- ふつうの宝箱・壺の中身と時刻は変えない
- ボス戦の宝箱の絵を、 ふつうの宝箱と分けない

## 4. 受け入れ基準

- [x] ボスが出て少しすると、 枠の中に宝箱が出る
- [x] 壊すと、 マジックカードかお助けアイテムと CE が出る
- [x] ふつうの宝箱からはマジックカードが出ない。 懐中時計はボス戦の宝箱から出ない

  - 中身の表（懐中時計なし）と、 壊したときに落ちるもの
