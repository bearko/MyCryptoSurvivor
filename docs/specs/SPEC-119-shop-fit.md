# SPEC-119 — スマホのショップをスクロールなしで 1 画面に

- **Status**: Done
- **関連**: SPEC-109（ショップ）・SPEC-110（固有スキルの札）・SPEC-115（最初の店の説明）・SPEC-117（来店の回復）

## 1. 作者の依頼（2026-10-20）

- スマホのショップ画面でスクロールしなくて良いように
- 装備中のエクステと手持ちの CE を 2 列にして同じ行に（8:2 くらい。手持ちの CE はコンパクトに）
- 「あと◯回の店でボス」は商人の名前の横に「（あと◯回でボス）」と併記

## 2. 変えたこと

- **商人の段**：名前の横に「（あと 4 回でボス）」。顔を小さく、ひとことは 1 行（はみ出したら …）
- **装備中（8）と手持ち（2）を 1 行**：手持ちの欄に ◆CE・ギフト券・来店の回復（♥ HP +11）・お断りの残り（✕ 残り 3）をまとめた（下の段の「お断り 残り」の行を外した）
- **品の札（スマホ）**：「武器／強化エクステ」の見出しを外した（枠の色で分かる）。絵を低く・字を小さく・説明は 2 行まで
- **5 枚（マゼラン）**：スマホは 3 列（説明を外し、取り置き・お断りは印だけ）
- **固有スキルの札**：見出しを外し、名前と Lv を 1 行に
- **最初の店**：マインちゃんの説明があるので商人のひとことを畳み、固有スキルの札も畳む（CE は 2〜3、強化は 40 CE からで買えないため。2 回目の店から出る）
- **広い画面でも高さが 920px 以下なら**、札の絵を低くする（ノート PC の 800px でもスクロールしない）
