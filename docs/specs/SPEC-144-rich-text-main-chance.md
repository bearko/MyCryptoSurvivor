# SPEC-144 — 得意武器を確率で・説明の数字と用語に色

- **Status**: Done
- **関連**: SPEC-139（得意武器）・SPEC-133（スキルツリーの詳しい欄）・SPEC-137（ミッションの説明）

## 1. 作者の依頼（2026-10-21）

- スキルツリーの得意武器の出やすさが分かりにくいので、 確率を明記してほしい
- スキル詳細などで、 数字や各種用語が目立つように色を変えて区別してほしい

## 2. 得意武器（`js/battle/levelup.js`）

- これまで：候補に初期武器を 2 枚ずつ重ねる（確率が場面で変わり、 書けなかった）。
- これから：ショップとレベルアップで札が並ぶたびに、 **段 × 20%（20% / 40% / 60%）** の確率で、 初期武器の札を必ず 1 枚目に並べる。 外れたときはいままでどおりのくじ（そこで出ることもある）。
- 初期武器が上がりきっている・お断りした・取り置きで並んでいるときは何もしない。
- 説明：「ショップとレベルアップで札が並ぶたびに、 初期武器の札が必ず並ぶ確率 20%（段ごとに ＋20%。 最大 60%）」。 いまの効果の欄も「初期武器が必ず並ぶ確率 20% → 40%」。

## 3. 色分け（`js/rich-text.js`）

- 文を切り分けて、 **数字**（符号・% 秒 体 枚 倍 段 回 などの単位つき）は金、 **用語**（GUM・CE・ゴールドダスト・HP・Lv・ショップ・初期武器・ボス・無敵・宝箱・エクステの名前など。 英語も）は水色、 **「」の中**は白の太字。
- 文のデータには印を書き足さない（ここで切り分けるだけなので、 文を足しても自動で色がつく）。 中身は textContent で入れる。
- 効く場所：スキルツリーの詳しい欄（説明・条件）、 ミッションの持ちかけの説明、 ミッションのごほうびの説明。
