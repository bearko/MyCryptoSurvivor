# SPEC-106 — LL の解放条件：そのヒーローで全ステージをクリアしたことがあるか

- **Status**: Done
- **関連**: SPEC-101（LL ランクアップ）・SPEC-103（v1.6 の設計 6 章。作者の決定 Q7）

## 1. 背景（作者の依頼 2026-10-20）

LL エクステの強さは今のままでよいが、初回のプレイにしては大味すぎる。**そのヒーローで 3 ステージをクリアしたことがあるか** を解放の条件にしたい。

## 2. 決まり

- 記録：`mcs.meta.v1` に `heroClears: { <heroId>: 回数 }` を足す。全ステージをクリアした（活動レポートに進んだ）ときに 1 足す。**モードは問わない**（NORMAL・ABSOLUTE・RTA。作者の決定 Q7）。壊れた値（数でない・0 以下・id の形でない）は読み込みのときに落とす
- LL の札（SPEC-101）は、`hasHeroCleared(meta, いまのヒーロー)` のときだけ出る。条件を満たさなければ、初期武器は Lv.5 で止まる（ほかの武器と同じ）
- いままでのクリアは、ヒーローごとに残っていないので数えない（ヒーローの顔ぶれも 2026-10-19 に変わったばかり）
- ヒーローの選択画面：まだなら灰色で「**LL：このヒーローで全ステージをクリアすると解放（真・MCHブレード）**」、解放ずみなら今の虹色の「Lv.5 のあと LL：真・MCHブレード」（名前は伏せない。育てきる目標にする）
- 解放した瞬間（そのヒーローで初めて全クリア）：活動レポートの報酬の下に虹色の 1 行「**LL 解放！ 次から「真・MCHブレード」にランクアップできる**」

## 3. テスト

- `tests/ll-rank-up.test.mjs`：解放ずみなら LL の札が出る・まだなら出ない・壊れた記録を落とす
- `tests/meta.test.mjs`：既定の保存に `heroClears: {}`
