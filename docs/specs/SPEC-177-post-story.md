# SPEC-177 — ストーリーを終えたら「ここからが本番」

- **Status**: Approved（作者の依頼 2026-10-26）
- **関連**: SPEC-165（ストーリーモード）・SPEC-174（チュートリアルの段）・SPEC-173（チーム編成）・SPEC-088（初プレイのロック）・SPEC-090（スキルツリー）

## 1. 作者の依頼（2026-10-26）

プレイデータの分析で、 ストーリーモードで最初の離脱は防げたが、 翌日の継続率が低いと報告があった。

- 【仮説①】ストーリーを終えた報酬（NORMAL が開く）が弱い。 ストーリーを終えた＝ゲームを終えた、 ではなく、 ここからが本番だと伝える（難しさ・ランキング・チーム編成など）。 周回 → スキルツリーで強くなる、 の回り方を一枚絵で見せる
- 名前は NORMAL のまま。 Extra パネルの予告は要らない（店で必ず出会うので）

## 2. データ（10/24〜10/26、 テスターを除く）

| | 人数 |
|---|---|
| ストーリーを始めた | 13 |
| 5-5 まで終えた | 6 |
| 終えたあと NORMAL を 1 回でも遊んだ | 2 |
| 翌日も遊んだ | 1（終えたあとにもう 1 回遊んでいた人） |

終えた人の多くが、 NORMAL の入口でそのまま帰っている。 いまは 5-5 のあと「NORMAL が開いた」と 1 行出てモード選択に戻るだけで、 自分から入り直す人しか遊ばない。

## 3. 画面

5-5 をクリア → クリアの画面（ボタンは「つづきへ ▶」）→ エンディングのシーン → **この画面** → 押すとヒーロー選択（NORMAL）。

上から:

1. 見出し「STORY CLEAR」と「ここからが本番」
2. **NORMAL のボス 3 体**: 3 つのノード（アバカス・ホレリス・トロイ）のボスを、 ドット絵のまま大きく並べる（ディープ・ヨシュカ・覚醒魔王ファオ・yamap）。 「3 つのノードを、 ボスを倒しながら駆け抜ける」
3. **開いたもの**（3 行）:
   - ランキング — スコアが bearko.games の総合スコアに載る
   - チーム編成 — ヒーローを仲間にすると、 2 人までサブに連れていける
   - ABSOLUTE・RTA — NORMAL を 1 回遊ぶと開く（難しさを自分で決める・タイムを競う）
4. **一枚絵（回り方）**: ⚔ 挑む → GUM を持ち帰る → スキルツリーで強くなる → もっと遠くへ → ⚔ …の輪
5. ボタンは「NORMAL に挑む ▶」の 1 つだけ

- 出すのは、 この端末で初めて 5-5 を終えたときの 1 回だけ（`mcs.postStory`）。 2 度目からは今までどおりモード選択へ
- この版より前にストーリーを終えて、 NORMAL をまだ遊び終えていない人（`mcs.played` が無い）には、 タイトルからモード選択へ進むときに 1 回だけ出す（データの 4 人がここにいる）
- マインちゃんが 1 行だけ添える（声は付けない）
- 動きを減らす設定では、 入ってくる動きを止める

## 4. 計測（SPEC-174 の段を 2 つ足す）

| step | id | いつ |
|---|---|---|
| 27 | next | この画面を出した |
| 28 | normal | NORMAL（RTA ではない）の挑戦を始めた |

- 共通基盤の漏斗は done（26）を「終えた」として数え、 その先の段もそのまま並べる（共通基盤の変更は要らない）
- これで「ストーリーを終えた人のうち NORMAL を始めた割合」（いまは 2/6）が管理画面で見える

## 5. 実装

- `js/post-story.js`（新規）: 出すかの判定（純関数）・画面の描画・ボタン
- `js/story-map.js`: `backToStoryMap` で、 5-5 のあと初めてならモード選択の代わりにこの画面
- `js/main.js`: タイトルからモード選択へ進むとき、 ストーリーを終えて NORMAL を遊び終えていない人には先にこの画面
- `js/mode-select.js`: `pickNormal()`（モード選択の NORMAL のボタンと同じ道）
- `js/story.js`: `tutorialStepOf("next" | "normal")`
- `js/battle/index.js`: NORMAL の挑戦を始めたとき 28
- `js/battle/stage-transition.js`: 5-5 のクリアの画面のボタンを「つづきへ ▶」に（初めてのときだけ）
- `index.html` / `css/story.css` / `data/i18n/ui.json`
