# SPEC-082 — v1.3 を新しい版で計る：総合スコア balance 3 と RTA v4

- **Status**: Done
- **関連**:
  - SPEC-066（v1.2 を新しい版で計る。 同じやり方）
  - SPEC-078〜081・084（v1.3 の変更）
  - 共通基盤（bearko/MyCryptoPortfolio）の SPEC-002 3.2（総合スコア v4 の balance 3）・SPEC-001 6.17（RTA v4）

## 1. 背景

v1.3 で遊びの中身が変わった。

- 敵の大群：ボスの直前に画面の半分〜9 割が敵で埋まる
- ボス戦の枠：ボスが出るとほかの敵が消え、 1/4 の枠の中で戦う
- ボスの強化：HP 15〜20 倍、 突進などの型
- ボス戦の宝箱

撃破は 1 回で 2 万体を超え、 全クリアの活動レポートのスコアは約 30 万 → 約 260〜400 万に上がった（自動プレイ）。 v1.2 と同じく（SPEC-066）、 総合スコアはふつうの全クリアを 5,000 にそろえ直し、 RTA は新しいレギュレーションで計る。 古い記録は古い版のまま残す。

## 2. 仕様（`js/platform.js`・`index.html`）

### 2.1 総合スコア

- 送る成績の `balance` を **3** にする（`SCORE_BALANCE`）
- 共通基盤の総合スコア v4 が、 `balance: 3` の係数 **560** で割る（v1.2 までの成績の点は変わらない）
- 係数 560 の根拠：v1.3 の自動プレイ（circle ボット。 ボス戦の枠の中では小さく回り、 ボスの突進と叩きつけを避け、 マジックカードも拾う）の全クリア
  - 2,627,114・2,763,289・2,932,984・3,977,709（4 回）→ ふつうの全クリアを 2,800,000 と見た（2,800,000 ÷ 560 ＝ 5,000）
  - v1.3 のボットはよけきれずに倒れることが多いので、 HP を満タンに保って最後まで走らせて測った（撃破の数は HP によらない）

### 2.2 RTA

- NORMAL：`survivor-normal-v3` → **`survivor-normal-v4`**
- ABSOLUTE ×2.0：`survivor-absolute-2x-v3` → **`survivor-absolute-2x-v4`**
- モード選択の RTA ランキングのリンクも v4 に
- 最短時間は v3 と同じ（ボスはゲーム内の 4 分・宝箱は 1 ステージ 4 つのまま。 ボス戦の宝箱から懐中時計は出ない）

### 2.3 マージの順番

共通基盤（MyCryptoPortfolio #47）を先にマージした（`balance: 3` と v4 のレギュレーションを受け付ける）。 そのあとでこのゲームの変更をマージする。

## 3. 非ゴール

- 古いレギュレーション（v3 まで）を `deprecated` にすること（作者が決める）

- [x] RTA は v4 のレギュレーションで計る。 ランキングのリンクも v4
