# SPEC-175 — ミッションの出し手はストーリーの進みに関わらず全員が同じ割合

- **Status**: Approved（作者の依頼 2026-10-24）
- **関連**: SPEC-112（ミッション）・SPEC-137（★1〜3）・SPEC-165 §6.3（絆のある出し手を優先）・SPEC-166〜171（チーム）

## 1. 作者の依頼（2026-10-24）

NORMAL のミッションの出方がストーリーのクリア状況に依存している。 それをやめて、 初期の実装のようにストーリーに関わらず、 あらゆるヒーローのミッションを NORMAL で出したい。 3 人構成で全体に易しくなったので、 ミッションで難しさをプレイヤー自身が選べるようにしたい。

## 2. いまの動き（調べた結果）

- NORMAL の持ちかけは、 もともと 11 人（呂布・切り裂きジャック・信長・クレオパトラ・始皇帝・アレクサンドロス・項羽・ナイチンゲール・ナポレオン・武田信玄・曹操）の中から選んでいた（外すのは、 プレイ中のヒーローの影と、 直前の人だけ）
- ストーリーとのつながりは SPEC-165 §6.3 の **「絆を結んだ出し手は 3 倍出やすい」** だけ。 ストーリーを進めた人ほど、 特定の人（呂布・アレクサンドロス・信長・武田信玄など）に偏っていた
- 持ちかけの割合（1 ウェーブ 40%・1 ステージ 3 回まで）は最初の実装（SPEC-112）から変わっていない

## 3. 決まり

- 絆の重みをやめ、 **全員が同じ割合**（プレイ中のヒーローの影・直前の人は出さない。 これは最初からの決まり）
- 絆の報酬（雷鼓 30% など）はそのまま
- ★1〜3 を選べる（SPEC-137）ので、 難しさはプレイヤーが選ぶ

## 4. 実装

- `js/battle/missions.js`: `pickMission` から `bonded` と `BONDED_GIVER_WEIGHT` を外す（均等）
- `js/bonds.js`: コメントだけ（`bondedGivers` は残す）

## 5. 確かめたこと

- テスト: 22,000 回引いて 11 人すべてが来る・それぞれ 1/11 ± 1.5%・直前の人とプレイ中のヒーローの影は出ない・絆の重みのコードが無い
