# SPEC-180 — ストーリーの区切りで「次」を見せる

- **Status**: Approved（作者の依頼 2026-10-26「P1 の進行をお願いします」）
- **関連**: SPEC-165（ストーリーモード）・SPEC-174（チュートリアルの段）・SPEC-177（ここからが本番）

## 1. 背景（分析の資料の P1）

- チュートリアルの漏斗で、 いちばん人が減るのは W2 を終えたあと（s2-5 → s3-1 で −2 人）。 W1 の途中でも減る
- 持ち越す成長（スキルツリー）が開くのは W3 の始め（3-1）なので、 W2 で離れる人はそれを見ないまま終わる
- 提案: やめる瞬間に「次に開くもの」と「あと◯」を見せ、 やりかけの目標を持ったまま閉じてもらう（オープンループ）

## 2. 結果の画面に足すもの

**どのストーリーのクリアでも**（プロローグと 5-5 を除く）:

- 進みの帯と 1 行: `STORY 10/25` ・ **NORMAL まで あと 15** ・ 絆 2/5（試練のある影のヒーロー 5 人）

**ランドを取り戻したとき（1-5・2-5・3-5・4-5）だけ**、 次のランドで開くものを 1 つ（カード）:

| 終えたランド | 次のランド | 開くもの | ひとこと |
|---|---|---|---|
| W1 | Strawberry | 影のヒーローの試練（アレキサンダー） | 逃げ切れば、 絆の証がもらえる |
| **W2** | **Tangerine** | **スキルツリー** | **倒れても残る強さ。 いま GUM 945**（いまの GUM） |
| W3 | Lime | ミッション（武田信玄） | 自分で選ぶ試練。 越えると報酬 |
| W4 | Grape | 天候操作装置ゼウス（COVID） | 最後のランド。 越えたら NORMAL が開く |

- カードの下に、 次のランドの予告を 1 行（ワールドマップの札と同じ `story.land.<id>.hint`。 作者の文）
- 枠の色は次のランドの色

## 3. 入れなかったもの（資料の P1 のうち）

- **スキルツリーを W2 の終わりへ前倒し**: 2-5 のクリアの台詞（「使い道は次のランドで！」）と 3-1 の始まりの台詞は録音済みで、 木を見せるのは 3-1 という流れで書かれている。 前倒しすると台本と録音を直すことになるので、 今回は **W2 のあとのカードでスキルツリーと貯まった GUM を予告する** にとどめた。 s2-5 → s3-1 の離脱が減らなければ、 次に前倒しを検討する
- ボタンや流れ（ランドの最後は「マップへ」だけ）は変えない（靄が晴れて次のランドが現れる演出を見せるため）

## 4. 測り方

- 管理画面の「チュートリアル」タブ: s2-5 → s3-1 の割合（いま 5/7）と、 チュートリアルを終えなかった人の RR1
- 送るものは増やさない（段は SPEC-174 のまま）

## 5. 実装

- `js/story.js`: `LAND_NEXT`（ランドごとの絵と文のキー）・`storyNextInfo(id, progress)`（純関数）
- `js/battle/stage-transition.js`: `_renderStoryNext`（ストーリーのクリアの画面に描く）
- `index.html`（`#stageTransitionNext`）・`css/story.css`・`data/i18n/ui.json`
