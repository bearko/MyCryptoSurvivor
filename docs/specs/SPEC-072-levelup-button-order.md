# SPEC-072 — レベルアップ：スキップは左で控えめに、リロールは右で目立たせる

- **Status**: Done
- **関連**: SPEC-023（リロール）・SPEC-067（スキップ）

## 1. 背景

作者の依頼（2026-10-17）：

- スキップとリロールの位置を逆にしたい（スマホだと右側のボタンを押しがちで、序盤に誤ってスキップを押してしまいそうになる）
- スキップとリロールのトーンが同じなのは違和感がある。リロールの方が目立つように（スキップをグレーめにして目立たなくする形で）差をつけたい

SPEC-067 では、左にリロール・右にスキップを、同じ枠のボタン（`btn--secondary`）で並べていた。

## 2. 仕様（`index.html`・`css/components.css`）

- 並びを **左：スキップ（取得しない）／右：リロール（残 n）** にする
- リロール：金の主ボタン（`btn`。冒険を始める・閉じると同じ見た目）。少し幅を広く・太字
- スキップ：灰色の控えめなボタン（`btn--ghost`。文字は `--muted`、面はうすい白、縁はうすい灰色）。押せることは分かるが、目を引かない
- リロールを使い切ったとき（押せない）は、いままでどおり薄くなる
- 押したときの動き（リロールで同じものを続けて出さない・スキップで何も取らずに閉じる）は SPEC-067 のまま

## 3. 非ゴール

- スキップに確認（「本当に？」）は入れない（遊びのテンポを止めるため。位置と見た目の差で誤タップを減らす）

## 4. 受け入れ基準

- [x] スキップが左・リロールが右に並ぶ
- [x] リロールは金で目立ち、スキップは灰色で控えめ

## 5. テスト

- `node --test tests/levelup-picks.test.mjs`：スキップが先（左）、リロールは金の主ボタン、スキップは控えめのボタン
- ヘッドレス Chromium（390×844）：レベルアップを開いて撮った。2 回リロール（重なりなし）→ スキップで閉じる（一時停止 1 → 0）。ページのエラーなし
