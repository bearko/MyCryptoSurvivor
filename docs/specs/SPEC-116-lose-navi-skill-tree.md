# SPEC-116 — 倒れたら、マインちゃんがスキルツリーへ誘う

- **Status**: Done（ボイスは録音待ち。録ったら `node tools/voice/build.mjs <WAV のフォルダ> --added2` で鳴る）
- **関連**: SPEC-085（フルボイス）・SPEC-090（スキルツリー）・SPEC-093（スキルツリーの案内）・SPEC-059（画面の下の通信の帯）

## 1. 作者の依頼（2026-10-20）

- 敗北した際は、マインにスキルツリーへの誘導をしてほしい
- **初回**：スキルツリーに誘導 → スキルツリー画面で強化の仕方を説明（強化は引き継がれる＝遊べば遊ぶほど強くなることも）
- **2 回目以降**：作者の 3 つのセリフ
- フルボイスも入れるので、セリフを作る

## 2. 決まり

### 2.1 結果の画面（倒れたとき）

- テロップ（SPEC-058）のあと、画面の下の通信の帯（モード選択・ヒーロー選択と同じ）でマインちゃんが言う。帯は結果の画面より手前、結果の画面は帯のぶん下を空ける
- **初回**＝スキルツリーをまだ始めていない（根を取っていない。SPEC-093 の「入口を脈打たせる」と同じ判定）：「惜しかったね……！「スキルツリーへ」を押してみて。ヒーローをもっと強くできるよ！」（「スキルツリーへ」のボタンは今までどおり脈打つ）
  - 1 回目の敗北で木を開かずに再走したときは、次に倒れたときもこの誘いを言う（誘いを聞いて木を始めるまで）
- **2 回目以降**＝スキルツリーを始めている：作者の 3 つを順に（続けて同じにならない。始まりは乱数）
  1. 惜しかったね。スキルツリーを強化してリベンジしよう！
  2. 頑張ったね！たまった GUM でスキルを強化しよう！
  3. まだまだこれから！少し休んだら、また挑んでみよう。スキルツリーの強化も忘れずにね
- RTA では言わない（RTA ではスキルツリーの効果が切れるため）
- 再走・タイトルに戻る・スキルツリーを開くで帯は引っこむ（それぞれの画面のセリフに替わる）

### 2.2 スキルツリー（はじめて開いたとき）

根をまだ取っていないとき、3 つを続けて言う（吹き出しを押すと次へ）：

1. ここがスキルツリー！挑戦で貯めた GUM とゴールドダストで、ヒーローの力を伸ばせるよ
2. 強化はずっと引き継がれて、どのヒーローにも効くよ。遊べば遊ぶほど強くなれる！
3. まんなかの金の節を 2 回押してね。ここから始まるよ！（今までの案内）

そのあとは今までどおり（緑の節を選ぶ → 取れたら「次の挑戦から効く！」）。
