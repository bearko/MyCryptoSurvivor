# SPEC-165 — ストーリーモード（5 ランド・25 ステージの「実践つきチュートリアル」）

- **Status**: Approved（v3。 作者の 3 回目の答えで §9 がすべて決まった。 §8 の段取りで実装へ）
- **関連**: SPEC-147 / 154（EASY。 本 SPEC が置き換える）・SPEC-112 / 137 / 138（ミッションとシャドーヒーロー）・SPEC-155 / 160 / 164（REVIVE と木のゲート）・SPEC-161（クリア画面から木へ）・SPEC-162 / 163（引き継ぎとバランス）・SPEC-146（自動プレイ）

## 1. 作者の方針（2026-10-21・2 回）

**1 回目**: EASY の 2 ステージで短時間に無理にチュートリアルを終わらせるより、 ストーリーモード（5 ワールド × 3〜7 ステージ、 合計 25）で要素ごとに「実践兼チュートリアル」。 課題と解消のサイクルを短く回せ、 バランス調整もしやすい。 1-1 は雑魚数体と MCH ウォーリアーだけで「自動で攻撃が出て、 倒せる」を実感するまで。 1-2 は店でエリートブレードを強化して倒しやすくなる体験。 **してほしいことを強制する UX** で、 意図しない動きでチュートリアルが壊れないように。 全クリアで NORMAL の全コンテンツが開く。

**2 回目**:
- **大型ボス**（いまの NORMAL のボス）は **3-5 と 5-5 だけ**。 ほかのステージは「特定の地点に到達」など**別のクリア条件**を設ける
- 代わりに**中ボスとして、 いまミッションで登場するシャドーヒーロー**を要所に出す。 **倒す**／**攻撃を N 秒耐える**で勝利。 シャドーヒーローと戦って**絆**ができ、 のちに NORMAL で**試練（ミッション）を与え、 報酬で支援してくる**関係だと分かる流れに
- ステージの長さは **W1 だけなるべく短く、 15〜60 秒**で設計
- **GUM は W1 から貯まる**が、 **スキルツリーの開放は W3 ごろ**。 W1〜W2 は「貯まるけど何に使うかまだ分からない」状態
- ワールド名は **MCH のランド名そのまま**: オーシャン・ストロベリー・タンジェリン・ドラゴン・グレープ。 ステージ名は「1-1」で OK
- 背景は **MCH の Backgrounds にあるランドの色に沿った 9 種**を使う
- **遊び直しは許す**。 **完全なゲート**（買うまで閉じられない など）で OK。 **スキップは入れず、 1 つ 1 つを短く**

**3 回目（決まったこと）**: W4 は **Lime**（名前も Lime）。 ボスの配置 OK。 長さ OK（遊んでから直す）。 **EASY クリア済みの人はストーリーを最初から遊べ、 NORMAL などの解放は保つ**（遊ぶことで解放済みのものがロックされないこと）。 ヒーロー OK。 **試練で HP は減るが、 HP が多くてほとんど減らない**形に。 強すぎることに納得感のあるシャドー（呂布など）を試練に。 **絆の報酬**: お助けアイテムの解放・ミッションに現れる・パッシブスキルの効果の解禁・ギフト券。 **台本は文で実装 → 確認 → フルボイス化のときに直す**。

### 1.x 作者の方針（2026-10-22・3 回目）

ストーリーを通じて意識すること:

- **課題感は小出しに**（1 ステージ 1 要素のまま。 W1〜W2 は倒れない設計、 W3 からも 1 ステージ 1 つずつ）
- **報酬はなるべく早めに、 かつ一気に**。 例: **シャドーヒーローを越えた瞬間に報酬がいろいろもらえて、 一気に強化される感じ**（→ §6.2 の**報酬ラッシュ**）
- **課題感（ストレス）≪≪≪ 報酬**。 釣り合いで迷ったら報酬の側に倒す

運用の注意: **実在する他タイトルの名前を GitHub（SPEC・PR・コミット・コード）に書かない**。 参考にした作りは「参考作」と書く。

## 3. 全体の形

```
タイトル → モード選択
   ├ ストーリー（= EASY の札を置き換える。 初めての人はこれだけ押せる）
   │    └ ランドマップ（5 ランド × ステージの丸。 クリア済み・いま・未開放）→ ステージ → クリア → 次の丸が開く
   ├ NORMAL（🔒 ストーリーを最後までクリアすると開く）
   ├ ABSOLUTE / RTA（🔒 いままでどおり NORMAL を 1 回遊ぶと開く）
```

- **一本道**。 n をクリアすると n+1 が開く。 **クリア済みはいつでも遊び直せる**（レシピは同じ・GUM は入る）。
- **ヒーローは W1〜W2 は MCH ウォーリアー固定**。 3-2 でヒーロー選択が開く（ビリーが仲間に = SPEC-153 の報酬をここへ）。
- **装備・CE はステージごとに完結**（レシピが開始装備を決める）。 5-5 だけ本番と同じ 4 分 → ボス。
- **GUM は 1-1 から入り、 1-3 のクリア画面から数字を見せる**（「使い道はあとで」）。 **スキルツリーは 3-1 で開く**（根を取るまでほかを押せない = SPEC-164 のゲート）。 それまでは木のボタンを出さない。
- **大型ボスは 3-5（ディープ・ヨシュカ）と 5-5（覚醒魔王ファオ）だけ**。 yamap は NORMAL のステージ 3 に残す（「物語は NORMAL に続く」）。
- **成長は店で**。 いまの NORMAL は CE が財布に入り、 店で買う（レベルアップの札はマジックカードのときだけ）。 ストーリーも同じで、 「札を選ぶ」は店の品で教える。
- **できるまでは EASY と並ぶ**。 ストーリーの札を「ストーリー（β）」として EASY の隣に置き、 W5 まで入った最後の PR で EASY を外して NORMAL のロックを差し替える（main がそのまま本番に出るため。 途中の状態で新しい人が行き止まりにならない）。
- **EASY は最後に撤去**。 文と録音はストーリーの台本へ（§7）。
- 保存は `mcs.story`（`{ cleared: ["1-1", …], best: { "1-1": { sec, kills } }, bonds: ["lubu", …] }`）。 **EASY をクリア済みの人も 1-1 から**。 NORMAL・ABSOLUTE・RTA・ビリーの解放は `mcs.played` / `mcs.easyCleared` / `mcs.heroUnlocked` のまま触らない（ストーリーは解放を**足す**だけで、 外さない）。

## 4. ステージのレシピ（データで決める。 コードは 1 本）

いまの EASY は `EASY_STAGES`（NORMAL の表を上書きする 2 行）。 これを `js/story.js` の `STORY_STAGES`（25 行）にし、 戦闘の各所の `easyStage()` を `storyStage()` に差し替える。 **「何を出すか・何を押させるか・どう終わるか」まで 1 行で書く**。

```js
{
  id: "1-2", world: 1, bg: "Image/Backgrounds/2105.png",
  hero: 10001, startExt: [{ extId: 10, level: 1 }],          // 固定のヒーローと開始装備
  clear: { kind: "kills", n: 20 },                            // kills / survive / reach / collect / shadowDefeat / shadowSurvive / boss
  targetSec: 40,                                              // クリアの想定時間 (= 自動プレイで合わせる目安)
  spawn: { everyMs: 1200, pool: [101], max: 6 },              // 湧き: 間隔・敵の種類・同時の上限 (洪水・密度・段階・型は使わない)
  enemyMul: { hp: 1.5, dmg: 0.3 },
  shadow: null,                                               // { id: "lubu", mode: "survive", sec: 20, hp, dmg, aura: { speedMul: 1.4 } } = 中ボス (§6)
  boss: null,                                                 // 3-5 / 5-5 だけ { id: 171, atMs, hpMul, dmgMul }
  features: { shop: true, levelUp: false, items: [], chests: false, pots: false, rare: false, shooters: false, variants: false, mission: false, gimmick: null, magicCards: false, bossChest: false },
  shop: { atMs: [12000], offers: [{ extId: 10, nextLevel: 2 }], only: true, price: 0 },   // 品は固定。 only: ほかの品・リロール・ギフト・禁止を出さない。 price 0 = CE が無くても買える
  levelUp: null,                                              // { picks: [{ extId: 2 }], only: true } = 出る札を固定
  must: [{ at: "shopOpen", do: "buy", target: "ext:10" }],    // ゲート: 満たすまで次へ進めない (時間は止めたまま)。 マインちゃんが指さす
  lines: { intro: "story.1-2.intro", mid: [{ on: "shopOpen", key: "story.1-2.shop" }], clear: "story.1-2.clear" },
  unlock: null,                                               // クリアで開くもの: "hero:4006" / "tree" / "bond:lubu" / "mode:NORMAL" (ランドマップに「解放！」)
}
```

**レシピにないものは出ない**。 `features` が false のものは湧かない・落ちない・出ない。 `only: true` の店は品を固定し、 ほかのボタンを消す。 `must` はゲートで、 満たすまで進めない。 **バランスは行ごと**で、 自動プレイ（`--mode story --stage 1-2`）で 1 行ずつ回せる。

**新しく要る仕組み**（土台の PR で作る）: 到達の光る地点（`reach`。 枠の端に置き、 ミニ矢印で示す）・集める（`collect`）・シャドー戦（§6）・ランドマップ・進みの保存。 ほかは既存の機能を `features` で絞るだけ。

## 6. シャドーヒーロー（中ボス → 絆 → NORMAL のミッション）

### 6.1 戦い方

いまシャドーヒーローは 11 人が**ミッションの出し手**（肖像だけ。 `missions.js` の `giver`）。 ストーリーでは**戦う相手**として出す。 新しいしくみ `js/battle/shadow.js`:

- 絵は `Image/Enemies/<id>.png`（ゴースト◯◯）。 大きさはボスより小さい（半径 32・1.5 倍の絵）。 **場は縮めない**（ボスと違う。 雑魚も湧き続ける）。
- **型はボスの型を借りる**（突進・叩きつけ・放射 = `boss-moves.js`）。 加えて**その人のミッションの効き目を「オーラ」として場に出す**（例: 呂布 = 雑魚の湧き ×4、 信玄 = 風林火山、 曹操 = 小さく速い雑魚、 信長 = 鉄砲隊）。 **試練の中身 = NORMAL でその人が出すミッションの中身**。 ここで世界観がつながる。
- 2 つの勝ち方（レシピの `shadow.mode`）: **survive**（T 秒耐える。 シャドーは倒せない・HP なし。 時間が来ると「見事」と言って消える）／**defeat**（HP を削って倒す）。 W2 は survive、 W4〜W5 は defeat。
- 倒れたら（HP 0）そのステージをやり直す。 survive の試練は **HP を減らさない**（W2 は倒れない設計のため。 当たると「あっ」と出て、 ミッションの「無被弾」の予習になる）。

### 6.2 絆と、 その報酬（作者の決定）

試練を越えると **絆**（`mcs.story.bonds` に id）。 絆には**目に見える報酬**がつく（レシピの `bond`）:

| 相手 | どこで | 試練 | 絆の報酬 |
|---|---|---|---|
| アレキサンダー | 2-4 | 15 秒耐える（速い突進） | **お助けアイテム「懐中時計」の解放**（以後のステージと NORMAL で落ちる） |
| 呂布 | 2-5 | 20 秒耐える（湧き ×4 ＋ 叩きつけ） | **ギフト券 ×2**（次の店から使える） |
| 織田信長 | 4-5 | 倒す（鉄砲隊） | **雷鼓の対ボス 20% → 30%**（パッシブの解禁。 木の「雷鳴」の 2 段ぶん） |
| 武田信玄 | 5-3 | ミッション「風林火山」★3 達成 | **お助けアイテム「合体ロボ」の解放** |
| 項羽 | 5-4 | 倒す（重い一撃） | **ギフト券 ×3**・ミッションの出し手に |

**報酬ラッシュ**（作者の方針 §1.x「早めに・一気に」）: 試練を越えた**その瞬間**に、 足もとへ **CE の宝石の輪（120）・マジックカード ×2（その場でレベルアップ）・ハート**が降り、 **ギフト券はその場で財布へ**、 **GUM +30** がクリアの内訳に「絆の報酬」の行で乗る。 画面の真ん中に 1 枚の札で中身を見せる（解放したものも書く）。 既定は `story.BOND_BURST`、 レシピの `bond.burst` で上書き（5-4 の項羽は本番の湧きの中なので CE 200・カード 3・GUM 50）。 5-3 の信玄はミッション達成の瞬間に同じラッシュ。

**NORMAL でも、 ミッションの出し手は絆のある人が優先**（絆が無い人は「初めて会う」演出つきで出し、 1 回達成すると絆）。 これで「試練を越えた相手が、 のちに依頼と支援をくれる」が遊びの中で分かる。 残り 6 人（ナイチンゲール・クレオパトラ・始皇帝・ナポレオン・曹操・ジャックザリッパー）は NORMAL で出会う。

**解放済みの人を縛らない**: NORMAL をすでに遊べる人（`mcs.played` か `mcs.easyCleared`）は、 懐中時計・合体ロボ・雷鼓 30% などが**最初から解放**されている扱い。 絆の報酬は「新しい人が順に手に入れる」ための鍵で、 すでに持っている人から取り上げない。

## 7. マインちゃんの解説と、 EASY からの移り方

- ステージごとに 3 本（始まり・★が出た瞬間・クリア）＋ シャドーの一言（登場・勝ち・負け）= **約 90 本**。 既存 15 本のうち CE・店・ボス・レア・ギフト・ミッション・雷鼓・覚醒は文と録音を当て直す。 `lesson.s2.start`（「エクステは引き継がれない」）は事実と合わないので捨てる。
- 文は `story.<id>.<intro|mid|clear>`・`shadow.<id>.<appear|win|lose>`。 録音は後から（文だけで動く）。 台本は `docs/voice/script-story.csv`。 **文は実装の前に下書きを出し、 作者が直す**。
- EASY: できるまでは「ストーリー（β）」の札を EASY の隣に。 W5 まで入ったら EASY の札・`EASY_STAGES`・レッスンを外す。 レッスンの「1 回だけ」管理は不要（ステージの進みが管理）。 根まで ×0.5（SPEC-164）は不要。 「負ける設計」（SPEC-154）は撤去（**倒れて学ぶ**ではなく**やって学ぶ**）。 ビリーは 3-2 の解放に。 NORMAL の 🔒 は「ストーリーを最後までクリアする」（EASY クリア済み・NORMAL を遊んだことがある人は開いたまま）。
