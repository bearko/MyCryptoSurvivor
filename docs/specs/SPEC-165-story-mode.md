# SPEC-165 — ストーリーモード（5 ワールド・25 ステージの「実践つきチュートリアル」）

- **Status**: InReview（設計案。 作者の §9 の答えを待って実装に入る）
- **関連**: SPEC-147 / 154（EASY。 本 SPEC が置き換える）・SPEC-155 / 160 / 164（REVIVE と木のゲート）・SPEC-161（クリア画面から木へ）・SPEC-162 / 163（引き継ぎとバランス）・SPEC-146（自動プレイ）

## 1. 作者の方針（2026-10-21）

> EASY の 2 ステージで短時間に無理にチュートリアルを終わらせるより、 **ストーリーモード**を設けて 5 ワールド × 各 3〜7 ステージ、 合計 25 の細かいステージで、 要素ごとに「実践兼チュートリアル」をする。 ステージを細かく分けると、 **課題と解消のサイクルを短いスパンで回せ**、 **バランス調整もしやすい**。 全ステージをクリアしたら、 いま NORMAL にある全コンテンツが開放される。
>
> 1-1 はレアも商人もボスも出さず、 通常の敵数体と MCH ウォーリアーだけ。 **自動で攻撃が行われ、 倒してクリアできることを実感する**まで。 1-2 は敵が少し強くなり、 **店でエクステンションを強化すると倒しやすくなる**体験。 強化する品は固定（エリートブレード）など、 **ユーザーにしてほしいことを強制する UX** にして、 意図しない動きでチュートリアルが壊れないようにする。 何をすべきかを親切に指定する。
>
> お助けアイテムの解放・レアエネミーやミッションの存在・ボスの脅威など、 ゲーム内の各コンテンツを**マインちゃんの解説つきで、 世界観を伝えながら**ひとつずつ理解してもらい、 そのうえで NORMAL の周回に入ってもらうほうが定着率が高い。

## 2. ねらいと、 守ること

| ねらい | どう実現するか |
|---|---|
| 1 ステージ 1 要素 | ステージごとに「新しく出るもの」を **1 つだけ**（§5 の表）。 それ以外は前のステージまでに出たものだけ |
| 短いサイクル | 1 ステージ 30〜120 秒。 クリア条件は「N 体倒す」「T 秒生き残る」「ボスを倒す」のどれか 1 つ |
| 強制する UX | ステージの**レシピ**（§4）で、 出る札・店の品・押せるボタンを決める。 してほしいことは**それしか押せない**形で出し、 マインちゃんが指さす（lesson-cursor） |
| 壊れない | 倒れたら**同じステージをすぐやり直す**（REVIVE の演出は W2 の最後まで出さない）。 レシピにないものは湧かない・落ちない・売らない |
| 世界観 | 5 ワールドは MCH の **node（土地）** を旅する筋。 各ステージの始まりと終わりにマインちゃんの一言（文→録音） |
| 既存の原則を変えない | 共通基盤にはスコア・RTA を送らない（EASY と同じ）。 GUM は入る（木は育つ）。 ガチャ・課金要素は無い |

## 3. 全体の形

```
タイトル → モード選択
   ├ ストーリー（= いまの EASY の札を置き換える。 初めての人はこれだけ押せる）
   │    └ ワールドマップ（5 行 × ステージの丸。 クリア済み・いま・未開放）→ ステージ → クリア → 次の丸が開く
   ├ NORMAL（🔒 ストーリーを最後までクリアすると開く）
   ├ ABSOLUTE / RTA（🔒 いままでどおり NORMAL を 1 回遊ぶと開く）
```

- **進み方は一本道**。 ステージ n をクリアすると n+1 が開く。 クリア済みのステージは**いつでも遊び直せる**（レシピは同じ・GUM は入る）。
- **ヒーローは W1〜W2 では MCH ウォーリアー固定**。 W3-1 でヒーロー選択が開く（ビリーが仲間に = SPEC-153 の報酬をここへ）。
- **装備・CE はストーリーの中では持ち越さない**（1 ステージ完結。 毎回「この武器から始める」をレシピが決める）。 W5 の「本番と同じ 3 ステージ連戦」だけ SPEC-162 の引き継ぎで遊ぶ。
- **スキルツリー**は W2 の最後で開く（§5 の 2-4）。 それまでは木のボタンも GUM の表示も出さない（見せるものを増やさない）。
- **EASY は撤去**（モード札・`EASY_STAGES`・15 本のレッスン）。 文と録音はストーリーの台本に移せるものは移す（§7）。
- 保存は `mcs.story`（= `{ cleared: ["1-1", …], best: { "1-1": { sec, kills } } }`）。 すでに EASY をクリアしている人は **W1 をクリア済みの扱い**で始める（§9 Q4）。

## 4. ステージのレシピ（データで決める。 コードは 1 本）

いまの EASY は `EASY_STAGES`（NORMAL の表を上書きする 2 行）で動いている。 これを 25 行に伸ばし、 **「何を出すか・何を押させるか」まで書けるようにする**。 `js/story.js` に置き、 戦闘の各所が `easyStage()` を呼んでいるところを `storyStage()` に差し替える。

```js
{
  id: "1-2", world: 1, nameKey: "story.1-2",
  hero: 10001, startExt: [{ extId: 10, level: 1 }],        // 固定のヒーローと開始装備
  durMs: 45000, clear: { kind: "kills", n: 25 },            // クリア条件: kills / survive / boss
  spawn: { everyMs: 1100, pool: [101, 124], max: 8 },       // 湧き: 間隔・敵の種類・同時の上限 (洪水・密度・段階・型は使わない)
  enemyMul: { hp: 1, dmg: 0.4 },
  boss: null,                                               // { id: 171, atMs, hpMul, dmgMul, moves: ["charge"] }
  features: { shop: true, levelUp: false, items: [], chests: false, pots: false, rare: false, shooters: false, mission: false, gimmick: null, magicCards: false, bossChest: false },
  shop: { atMs: [15000], offers: [{ extId: 10, nextLevel: 2 }], only: true, price: 0 },   // 品は固定。 only: ほかの品・リロール・ギフト・禁止を出さない。 price 0 = CE が無くても買える
  levelUp: null,                                            // { picks: [{ extId: 2 }], only: true } = 出る札を固定
  must: [{ at: "shop", do: "buy", target: "ext:10", gate: true }],   // 強制: 店が開いたら その札を買うまで「閉じる」が押せない。 マインちゃんが指さす
  lines: { intro: "story.1-2.intro", mid: [{ on: "shopOpen", key: "story.1-2.shop" }], clear: "story.1-2.clear" },
  unlock: null,                                             // クリアで開くもの (= "hero:4006" / "mode:NORMAL" / "feature:mission" など。 ワールドマップに「解放！」と出す)
}
```

**レシピにないものは出ない。** `features` が false のものは湧かない・落ちない・出ない。 `only: true` の店は品を固定し、 ほかのボタンを消す。 `must` は**ゲート**で、 満たすまで次へ進めない（時間は止めたまま）。 これで「意図しない動き」を構造的に封じる。

**バランスは行ごと**。 1 ステージを直すのに他へ波及しない。 自動プレイ（`tools/autoplay/run.mjs --mode story --stage 1-2`）で 1 行ずつ回せる。

## 6. マインちゃんの解説

- **ステージごとに 3 本**: 始まり（ステージの帯の下で 1 文）・途中（★が出た瞬間、 画面の上の通信窓 ＋ カーソル）・クリア（結果の画面の帯）。 25 × 3 = **75 本**。 いまのレッスン 15 本のうち使い回せるもの（CE・店・ボス・レア・ギフト・ミッション・雷鼓・覚醒）は文と録音をそのまま当てる。
- 文は `data/i18n/ui.json` の `story.<id>.<intro|mid|clear>`。 録音は `assets/voice/mine/story.<id>.<…>.mp3`。 **文だけでも動く**（録音が入るまでは文の長さで待つ。 いまのレッスンと同じ）。
- 台本は `docs/voice/script-story.csv` に出す（`tools/voice/lines-csv.mjs` を拡張）。 **文は実装の前に作者が確認する**（世界観の言葉を決める人が作者なので）。
- 世界観: 5 ワールドは MCH の node を旅する。 W1〜W2 は「node の入口」、 W3 アバカス、 W4 ホレリス、 W5 トロイ、 のように**いまの 3 つの node の名前を使い切る**案と、 新しい node の名前を 2 つ足す案がある（§9 Q6）。

## 7. いまの EASY からの移り方

| いまのもの | ストーリーで |
|---|---|
| モード札「EASY」 | 「ストーリー」に差し替え。 押すとワールドマップ |
| `EASY_STAGES`（2 行）・`easyStage()` | `STORY_STAGES`（25 行）・`storyStage()`。 呼び出し側は関数名の差し替えだけ |
| 15 本のレッスン（`LESSON_KEYS`・`mcs.lessons`） | ステージの `lines` に吸収。 「1 回だけ」の管理はステージごとに不要（そのステージの進みが管理） |
| 根まで ×0.5（SPEC-164） | 不要。 W1〜W2 は根が無い前提のレシピ。 2-4 で根を取る |
| 「負ける設計」（SPEC-154） | 撤去。 **倒れて学ぶ**のではなく**やって学ぶ**。 REVIVE と木は 2-4 で「クリアの報酬」として出会う |
| ビリーが仲間に（SPEC-153） | 3-1 の解放に |
| NORMAL の 🔒「EASY をクリアする」 | 「ストーリーを最後までクリアする」。 EASY クリア済みの人は W1 クリア済みで始める（Q4） |

## 9. 作者に決めてほしいこと

1. **NORMAL が開く時刻**: 案どおり「5-5 クリア」でよいか。 途中（例: W3 クリア）で開けて、 ストーリーと並行して周回できるようにもできる。 開けるとストーリーを飛ばす人が出る。
2. **ステージの長さ**: 30〜120 秒の目安でよいか。 25 ステージ合計で **約 25〜35 分**（倒れ直しを含まず）になる。 もっと短く（15〜60 秒）もできる。
3. **W1〜W2 で倒れない設計**でよいか（攻撃 ×0.3〜0.8・HP が減ると回復が落ちる）。 「倒れる体験」は W3 から。
4. **EASY をクリア済みの人の扱い**: W1 をクリア済みで始める（案）／最初から／W2 までクリア済み。
5. **ストーリーの中の GUM**: 入れる（案。 1 ステージ 20〜60）／入れない。 入れると 5-5 までに木が 10〜15 節育ち、 NORMAL の 1 周目が楽になる。
6. **世界観**: 5 ワールドの名前と筋。 いまの 3 node（アバカス・ホレリス・トロイ）を W3〜W5 に当て、 W1〜W2 は「入口」とする案。 新しい node の名前を 2 つ足すなら教えてほしい。 マインちゃんの文（75 本）は、 こちらで下書き → 作者が直す、 の順でよいか。
7. **ヒーロー**: W1〜W2 は MCH ウォーリアー固定、 3-1 でビリー、 以降は 10 人から選べる、 でよいか。
8. **やり直し**: クリア済みのステージを遊び直せる（GUM は入る）でよいか。 星（例: 無被弾・時間）のような評価は要るか（入れないのが案。 増やすと周回がストーリーに寄る）。
9. **強制の強さ**: 「買うまで閉じられない」「受けるまで進めない」のような**完全なゲート**でよいか。 どうしても嫌な人のために「スキップ」を置くか（置かないのが案。 1 ステージが短いので我慢できる範囲）。
