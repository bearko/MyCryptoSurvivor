# SPEC-162 — 装備と CE のステージ間の引き継ぎ・エクステンション 15 段階

- **Status**: Done
- **関連**: SPEC-030（3 ステージ・武器リセット）・SPEC-109 / 123（ショップと値段）・SPEC-128（残った CE を固有スキルへ）・SPEC-101（LL）・SPEC-139（仕込み）・SPEC-147 / 154（EASY）
- **次**: SPEC-163（バランス調整: 湧き・HP・GUM の設計と sim）

## 1. 作者の方針（2026-10-21）

EASY のステージ 2 でボスが倒せない報告が相次ぎ、 NORMAL も「何周しても進んだ感がない。 いつも同じタイミングで敵がどばーっとなって死ぬ」。
原因は**エクステンションがステージをまたいで引き継がれないまま敵だけ強くなる**こと（NORMAL も同じ形で、 パッシブとスキルツリー頼みになり、 スキルツリーの伸びが控えめなので序盤〜中盤で圧死する）。

- ステージ間でエクステンションのレベルを引き継ぐ
- CE も引き継ぐ
- そのかわりエクステンションのレベルを 15 段階に。 3 段階ごとにランクが上がる
- 今のレベル最大（Lv.5）を新 Lv.10 相当にし、 以降は今以上に強力に（LL を解放したら Lv.16 まで）

## 2. 直したこと

### 2.1 引き継ぎ

| # | 中身 |
|---|---|
| 1 | `startBattle` の `state.ownedExtensions = []` をやめ、 `carryOwnedExtensions(idx)`: ステージ 1 は空から、 新しいステージはいまの装備のまま、 **同じステージのやり直し（メニュー）は入ったときの装備に戻す**（`state.run.ownedAtStage`。 店の財布の `snapshot` と同じ考え） |
| 2 | 初期武器は持っていないときだけ Lv.1 で足す。 引き継いだ**強化系列（buff）は `resetBuffs()` のあと `applyBuff` で掛け直す**。 武器は `rebuildWeaponsFromOwned` |
| 3 | ステージの終わりに残った CE を固有スキルへ振る（SPEC-128）のをやめ、 **CE はそのまま次のステージへ**。 固有スキルは店の「Lv n へ ◆ p」で上げる（そのまま）。 ステージクリアの「残った CE → 固有スキル」の行は出なくなる（`sigPour` が無い） |
| 4 | 復活（REVIVE）は SPEC-146 のままステージ 1 から（装備は空から） |

### 2.2 15 段階（`js/ext-level.js`）

データ（`data/extensions.json` の `tierParams` / `tierNames` / `tierIconIds`）は 5 段のまま。 ここで 15 段に伸ばす。

| | 中身 |
|---|---|
| ランク（絵・名前） | **3 段ごと**: Lv.1〜3 が 1 段目、 4〜6 が 2 段目、 7〜9 が 3 段目、 10〜12 が 4 段目、 13〜15 が 5 段目。 LL は Lv.16（`ll` の絵と名前） |
| 数値（威力・間隔・弾数…） | 5 段の数値を **Lv.1・3.25・5.5・7.75・10** に置いて、 あいだを線で結ぶ（= **Lv.10 が今までの Lv.5 と同じ数値**）。 **Lv.11〜15 は 4 → 5 段目の傾きのまま伸ばす**（例: リボルバー Lv.15 は 威力 108・弾 10・間隔 0.68 秒。 Lv.10 は 75・6・0.9 秒）。 間隔など小さいほど良い数値は 5 段目の半分で止める。 整数の欄は丸め、 小数は 2 桁 |
| LL | Lv.16。 数値は `ll.params`（どの武器も Lv.15 より強いまま） |
| 説明文 | `{dmg}` `{bullets}` `{cd}` はその段の数値で埋まる |

### 2.3 経済

| | 今まで | これから |
|---|---|---|
| `SHOP_PRICE`（ステージ 1・行き先の段） | Lv.1〜5: 15 / 30 / 500 / 2,000 / 10,000 | Lv.1〜15: 15 / 25 / 40 / 80 / 150 / 260 / 420 / 650 / 950 / 1,400 / 2,000 / 2,800 / 3,900 / 5,300 / 7,000（Lv.10 まで合計 3,555、 Lv.15 まで 24,555） |
| ステージの掛け率 | ×1 / ×1.8 / ×2.6 | そのまま |
| LL | 20,000 | そのまま（Lv.15 の初期武器） |
| ギフト券の枚数 | 段で 1 / 1 / 2 / 3 / 5 | **ランク**で 1 / 1 / 2 / 3 / 5 |
| 仕込み（SPEC-139） | 1 段 = +1 Lv | 1 段 = **+2 Lv**（`EXT_START_LEVEL_STEP`。 15 段では 1 段が薄い） |

## 3. 作者に見てほしいところ

1. Lv.11〜15 の伸び方（傾きのまま）。 弾数が増えすぎる系列（ナイフ Lv.15 で 16 発）は SPEC-163 の sim で見る。
2. 値段の表。 1 回の挑戦（3 ステージ）で初期武器を Lv.15 に、 ほか数本を Lv.7〜10 に届かせる想定。 CE の収入は SPEC-163 で合わせる。
3. EASY のステージ 2 は装備を引き継ぐぶん楽になる。 「根を取るまで負ける」設計（SPEC-154）が成り立つかは SPEC-163 の自動プレイで見て、 必要なら `EASY_STAGES` を直す。
4. ステージクリアの画面から「残った CE → 固有スキル」の行が消える。 固有スキルの段は店で買う（`shop.sig.*` の文はそのまま）。

## 4. 確かめ方

- `node --test tests/*.test.mjs`（`tests/ext-level.test.mjs` を追加。 値段・ギフト券・クラウンのテストを 15 段に）。
- ブラウザ（EASY・根あり・CE +400）: ステージ 1 の店で 4 品買う（例: 初期武器 Lv.2・雪だるま Lv.1・鎧…）→ クリア → ステージ 2 の開始で `ownedExtensions` が同じ、 `shop.ce` が残り、 武器が組み直され、 強化が掛かっている。
