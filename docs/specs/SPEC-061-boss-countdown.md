# SPEC-061 — ボスが出るまでのカウントダウン

- **Status**: Done
- **関連**: SPEC-045（ボスの予告）・SPEC-057（予告の帯・カットイン）

## 1. 背景

作者の依頼（2026-10-17）：「ボス接近」の表示から、ボスが出るまでのカウントダウンがほしい。

いまはゲームの中の 3:30 に予告の帯が 3.2 秒点滅して消え、4:00 にボスが出る。残り時間はどこにも出ない。

## 2. 仕様

- 予告の帯（`#bossBanner`）の下に、出るまでの残り（`0:30` → `0:01`）を出す（`#bossBannerCount`）
- 予告が 3.2 秒（`BOSS_BANNER_INTRO_MS`）大きく出たあと、帯は画面の上の**小さな帯**にたたんで、そのまま数え続ける（警告色の縞・1 秒ごとに明るく脈打つ）
- **最後の 5 秒**（`BOSS_COUNTDOWN_BIG_SEC`）は、画面の真ん中に大きな数字（5・4・3・2・1。1 秒ごとに大きく出て縮む）
- ボスが出たら、帯と数字を消してカットイン（SPEC-057）
- 数えるのは**ゲームの中の時間**（`stageElapsedMs`）：一時停止（レベルアップ・メニュー）で止まり、懐中時計で速まる。ボスが出る時刻とずれない
- DOM を触るのは、表示の秒が変わるときだけ
- 動きを減らすときは、帯の動きと数字の大きさの動きを止める（数字は出す）

## 3. 非ゴール

- ボスが出る時刻（4:00）・予告の時刻（3:30）は変えない

## 4. 受け入れ基準

- [x] 予告から、帯の下に 0:30 から数える。3.2 秒後に上の小さな帯にたたみ、数え続ける
- [x] 最後の 5 秒は真ん中に大きな数字
- [x] ボスが出ると帯と数字が消える。次のステージでは出ていない

## 5. テスト

- `node --test tests/boss-countdown.test.mjs`：残りの表示（切り上げ・0:00・1 分以上）、帯をたたむのは大きな数字より前
- ヘッドレスの Chromium で、予告（0:29）・小さな帯（0:24）・大きな数字（4）・ボスが出た瞬間を 390×844・360×640 で撮って確かめた
