# SPEC-118 — スキルツリーの「経験値」を CE に・タイトルの数の札が欠ける

- **Status**: Done
- **関連**: SPEC-090（スキルツリー）・SPEC-093（入口の NEW と数の札）・SPEC-109 / 117（ショップ）

## 1. 作者の報告（2026-10-20）

- タイトル画面で、スキルツリーの通知アイコン（数の札）が見切れていた
- スキルツリーで「経験値」の表記は CE に統一したい

## 2. 直したこと

### 2.1 数の札と NEW が欠ける

- 原因：ボタンは角を切った形（`clip-path`）で、その外にはみ出した数の札・NEW が切り取られていた
- タイトルの「スキルツリー」ボタンは角を切らない（文字だけのボタンなので見た目は変わらない）
- 結果の画面の「スキルツリーへ」（角を切った金のボタン）の NEW は、ボタンの中の右上に置いた（以前は左上が欠けていた）

### 2.2 スキルツリーの文（ショップが既定になったので、レベルアップの言葉を読み替える）

| スキル | 前 | 後 |
|---|---|---|
| 学びの速さ | 経験値 ＋4%（段ごと） | 拾う CE ＋4%（段ごと） |
| 先手 | 開始時にレベルアップ 1 回（段ごと） | ステージの始めに CE ＋20（段ごと） |
| 見送りの礼 | スキップすると HP 10% 回復 | 何も買わずに店を出ると HP 10% 回復 |
| 天才 | 開始時にレベルアップ ＋2 回、リロール ＋2 | ステージの始めに CE ＋40、リロール ＋2 |

- 「いまの効果」の欄：「経験値」→「拾う CE」、「開始レベル ＋2」→「開始の CE ＋40」
- 効き目は変えていない（SPEC-109 の読み替えのとおり。RTA ではスキルツリーは効かない）

## 3. 確かめたこと

- `node --test tests/*.test.mjs`：すべて通る
- ブラウザ（390px）：タイトルの数の札・NEW が欠けない／スキルツリーに「経験値」が出ない（「拾う CE」「開始の CE」）
