# SPEC-058 — 結果とメニュー：結果のテロップ・数字のタイル・活動レポート・メニュー・設定・ランキング・遊び方

## 1. 背景

SPEC-055 でパネルの外側は「ノード端末」になったが、結果の画面とメニューの**中の部品**（数字のタイル・ステージの枠・行・つまみ）は v1.0 の角丸のまま。結果は画面がいきなり出るだけで、勝った・負けたの手ごたえがない。

| ゼンゼロの考え方 | 結果とメニューでの読み替え |
|---|---|
| キャラと UI・テロップを重ねる | 結果の前に斜めの帯のテロップ。帯の上にヒーロー、下にアインが重なる |
| リアクション | アインが結果に反応する（喜ぶ → ばんざい／涙ぐむ → 泣く） |
| ページめくり・メニューの動き | パネルは光の線から縦に開く。メニューの行は 1 行ずつ入ってくる |
| 素材感・縁のハイライト | タイル・行・欄・つまみまで、角を切った筐体と金 → シアンの縁 |

## 2. 仕様

### 2.1 結果のテロップ（`js/result-telop.js` 新規・`css/result-ui.css` 新規）

- `presentResult(modal, kind, { heroId, then })`：結果の画面を開いた直後に呼ぶ。テロップのあいだ（**1.6 秒**＝`TELOP_MS`）は結果の中身を隠し（`result-hold`）、終わったら `then()`（SPEC-046 の順に出す・数え上げ）
- 帯：幅 150%・-10° に傾いた暗い帯が飛びこむ（MCH の `Style/Cutins/battle_result_cutin.css` の `mch-battle-result-jack-in` をそのまま写す。0.75 秒）。英字の大見出しと日本語の小見出し。光が一度走る
- ヒーロー：帯の上の縁に立つ（原本 64px の 3 倍）。倒れたときは灰色で傾く
- アイン：帯の下の縁から顔を出し（96×128 の 2 倍）、吹き出しで一言。0.7 秒でポーズが変わる
- 押すと飛ばせる。動きを減らすときは出さない（すぐ `then`）。戦闘の通信の窓は引っこめる
- pauseTime には触らない（結果の画面が止めている）。RTA の計測（ゲーム内時間）にも影響しない

| 種類 | 使うところ | 見出し | 小見出し | アイン |
|---|---|---|---|---|
| `clear` | ステージクリア | NODE CLEAR | ステージクリア | きらきら → ウインク「やりました！」 |
| `allClear` | 活動レポート（全クリア） | ALL NODES CLEAR | 全ステージ突破 | きらきら → ばんざい「ぜんぶ突破です！」 |
| `lose` | ゲームオーバー | SIGNAL LOST | 通信が途切れた…… | 涙ぐむ → 泣く「まだ、いけます……！」 |

- ゲームオーバーの英字の小見出しも結果に合わせる（倒れた：SIGNAL LOST、クリア：ALL CLEAR）

### 2.2 パネルが開く動き（`css/node.css`）

- 全パネル（SPEC-055 の対象）が、端末の電源が入るように細い光の線から縦に開く（`node-boot` 420ms）。テロップのあとの結果の画面も、テロップが終わってから開く

### 2.3 結果の中身（`css/result-ui.css`）

- ステージの節（●●○）を**ノードの鎖**に：菱形の節を線でつなぎ、終えた節は金、次の節はシアンで点滅
- ステージ名は端末の表示（`›` と数字の書体）
- 数字のタイル：角を切った小さな端末。1 枚ずつ下から起き上がる（70ms ずつ）
- 次のステージ：シアンの `NEXT` の札
- 主ボタン（次のステージへ・リトライ・再走）に 3.2 秒ごとに光が走る
- 名前の欄：角を切った欄。触れると縁がシアンに

### 2.4 活動レポート

- ヒーロー：勢力の色の帯と `HERO` の札。顔は角を切った枠で、ドットのまま大きく
- ステージのカード：左に番号（01・02・03）、カードどうしを線でつなぐ（ノードの鎖）
- 合計：札（レギュレーション・時間・撃破）。スコアは金のグラデーションの文字で、数え上げたあと 3.6 秒ごとに光が走る。`SCORE` の両側に線

### 2.5 メニュー・設定・ランキング・遊び方

- メニュー：行に番号（01〜04）と `›`。開くと 1 行ずつ左から入ってくる。触れると右へ寄る
- 設定：行を角を切った筐体に。音量のつまみは 10 マスの帯がいまの値まで金で埋まり（`--val` は `js/settings-ui.js` が入れる）、頭は菱形。スイッチ・言語の切り替えも角を切る
- ランキング：見出しは端末の表示。上位 3 つは金・銀・銅の札
- 遊び方：節に番号（01〜04）とシアンの縁。項目の印は菱形。開くと節が順に入ってくる
- 入ってくる動きは `animation-fill-mode: backwards`（終わったあとに押したときの縮みを消さない）

### 2.6 憲章の改訂（`docs/charters/DESIGN_CHARTER.md`）

- 14.1：角丸の例外からスライダーのつまみと言語の切り替えを外す（菱形・角を切る）
- 14.5：パネルの開き方（420ms）、結果のテロップ（1.6 秒・押すと飛ばせる・文字にキャラをかぶせない）、並んだ行の入り方

## 3. 非ゴール

- 結果の数値・スコアの式・ランキングの送信は変えない（見た目だけ）
- 結果の SE・ジングルは今のまま（MCH の win / lose をすでに鳴らしている）
- 評価の段（S・A・B など）は足さない（数字の基準を新しく決めることになるため、作者の判断が要る）
