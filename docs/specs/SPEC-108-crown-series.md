# SPEC-108 — クラウンシリーズ（拾う CE が増える強化）

- **Status**: Done
- **関連**: SPEC-103（v1.6 の設計 7.3）・SPEC-011（強化の系列）・SPEC-109（ショップ。CE が通貨になる）

## 1. 背景（作者の依頼 2026-10-20）

CE のドロップ量を増やすエクステンションを、クラウンシリーズで表したい。

## 2. 決まり

- 強化（buff）の **11 種目** として足す（`data/extensions.json` の extId 21・`archetype: "ceGainUp"`）。名前・技の名前・絵は資産リポジトリのまま（手で書かない）

| 段 | 品（id） | 技の名前（MCH） | 効き目 |
|---|---|---|---|
| Lv.1 | クラウン（1036） | マジェスティ | 拾う CE ×1.15 |
| Lv.2 | エリートクラウン（2036） | 〃 | ×1.3 |
| Lv.3 | ウィズダムクラウン（3036） | 〃 | ×1.5 |
| Lv.4 | 宝冠（4036） | 〃 | ×1.75 |
| Lv.5 | 冕冠（5036） | 〃 | ×2.0 |

- 倍率は **拾った CE すべて**（敵・壺・宝箱・木馬）に、ヒーローに届いた瞬間に掛ける（端数は貯めて持ち越す。いまの「学びの速さ」と同じ仕組み）。1 体あたり 1 の雑魚でも少しずつ効く
- SPEC-103 7.3 の案（Lv.5 だけ壺・宝箱も ×2）は、すべての CE に同じ倍率を掛ける形にまとめた（分かりやすさのため）
- 技の名前は系列で 1 つ（いまの強化と同じ）。LL（真・冕冠 5536）は使わない（LL は初期武器だけ。SPEC-101）
- いまはレベルアップの品。v1.6 のショップ（SPEC-109）では「先に投資して、あとで多く買う」品になる

## 3. テスト

- `tests/crown.test.mjs`：系列のデータ（名前・絵の id・倍率）・強化が 11 種・付けると倍率が掛かる
- `tests/perks.test.mjs`：強化の土台に `ceGainMul: 1`
