# SPEC-104 — 中断する画面を閉じたら、3 秒数えてから再開する

- **Status**: Done
- **関連**: SPEC-103（v1.6 の設計。作者の決定 Q3）・SPEC-034（メニュー）・SPEC-072（レベルアップ）

## 1. 背景（作者の決定 2026-10-20）

ショップに限らず、遊びを中断する画面を閉じた瞬間に動き出すと、戦況が分からないまま倒される理不尽がある。**閉じたあと 3 秒数えてから再開** する。

## 2. 決まり

- 戦闘中に時間が止まっていて（レベルアップ・メニュー・設定・ランキング。あとでショップとミッション）、それが全部閉じて動き出す瞬間に、**真ん中より少し上に「再開まで 3・2・1」** を出し、そのあいだは時間を止めたままにする
- 画面ごとに書かない。ゲームのループで「止まっていた → 動き出す」を見て、`js/battle/resume-countdown.js` が止めを 1 つ足し、数え終えたら外す（`pauseTime` / `resumeTime` を対で使う）
- 数えないとき：ステージが始まって 1 秒未満（敵がまだいない・次のステージへ進んだ直後）、止まっていたのが 0.15 秒未満
- 数えているあいだに別の画面が開いた・タブを離れて戻った → 閉じてから・戻ってから **数え直す**
- 戦闘が終わった・タイトルに戻った・やり直した・次のステージが始まった → 数えるのをやめる（足した止めも外す）
- 動きを減らす設定では、数字の拡大の動きを止める（数字は出す）
- RTA（実時間）では、止めるたびに 3 秒ぶん記録が伸びる。v1.6 のショップで遊びが変わるときに RTA のレギュレーションを新しい版にする（SPEC-111）

## 3. テスト

- `tests/resume-countdown.test.mjs`：閉じたら 3 秒止まって動く・メニューが重なったら数え直す・タブを離れたら数え直す・ステージの始まりと戦闘の終わりで止めを外す
