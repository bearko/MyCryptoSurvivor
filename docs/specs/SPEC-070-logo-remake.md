# SPEC-070 — ロゴの作り直し

- **Status**: Done
- **関連**: SPEC-029（画像ロゴ）・SPEC-055（ノード端末）・SPEC-069（タップしてはじめる）

## 1. 背景

作者の依頼（2026-10-17）：ロゴのバランスが悪い。四角い枠の中で左下に寄っているように見え、背景から浮いているので作り直したい。

SPEC-029 のロゴ（`assets/logo.png`・2200×640）は、暗い色（#0b0218）で塗りつぶした横長の四角の中に、エンブレムと「MyCryptoSurvivors」の文字が左下寄りに置かれていた。タイトルの背景（ステージ 1 の絵）の上では、その四角がそのまま箱に見える。

## 2. 仕様

### 2.1 ロゴ（`assets/logo.png`・1029×583・背景は透明）

- 縦に積んで中央にそろえる：エンブレム → 「— MYCRYPTO —」→「SURVIVORS」→ 点線
- エンブレム：SPEC-029 のロゴから円の中だけを切り出したもの（`tools/logo/emblem.png`・外は透明）
  - 縁は金からシアンへの輪（ノード端末のパネルの縁と同じ向き）。シアンと桃色の光を足した
- 「MYCRYPTO」：Chakra Petch・シアン・字間を広く・両側に光の線
- 「SURVIVORS」：Dela Gothic One（Press to Start と同じ）・白。左に桃色・右にシアンをずらした色収差（SPEC-029 のロゴの名残）
- 点線：シアン（SPEC-029 のロゴの名残）
- 光は絵に入れてある（CSS の `filter: drop-shadow` はやめた）。光の外は透明なので、どの背景にもなじむ

### 2.2 置き方（`css/layout.css`）

- タイトル：幅 `min(80vw, 420px)`。縦の短い画面（高さ 700px 以下）では `min(60vw, 240px)` にして、画面の間隔も少し詰める（マインちゃんの吹き出しと言語のボタンを重ねない）
- スプラッシュ（読み込み中・タップしてはじめる）：幅 `min(72vw, 340px)`

### 2.3 作り直せるように（`tools/logo/`）

- `tools/logo/logo.html` がロゴの元。Chromium で開き、`#logo` を背景なし・2 倍で撮って、光の外の透明を切りつめたものが `assets/logo.png`
- 文字はゲームと同じ Google Fonts。書き出す前に読み終わるのを待つ（`display=block`）
- 共通基盤のサムネイル（`MyCryptoPortfolio/tools/thumbs/thumbs.json`）も `assets/logo.png` を参照している。次にサムネイルを作り直すと、新しいロゴになる

## 3. 非ゴール

- 共有用の画像（`assets/og-image.png`）は変えない（別の構図の絵）
- 共通基盤のサムネイルは作り直さない（このリポジトリの外）
- ロゴの文字をライブの HTML にはしない（読み込み中にフォントが入れ替わって見えるため。画像のまま）

## 4. 受け入れ基準

- [x] ロゴの四隅が透明で、タイトルの背景の上で箱に見えない
- [x] タイトルとスプラッシュで、ロゴが画面の中央にそろう（390 幅で左右 39px ずつ）
- [x] 360×640・375×667 で、マインちゃんの吹き出しと言語のボタンが重ならない

## 5. テスト

- `node --test tests/logo.test.mjs`
  - PNG を読み、RGBA で四隅が透明・縦に積んだ形の比率であることを確かめる（SPEC-029 の画像では失敗することを確かめた）
  - ロゴの元があり、スプラッシュとタイトルが同じ画像を使うことを確かめる
- ヘッドレスの Chromium で 390×844・375×667・360×640・1280×800 のタイトルと「タップしてはじめる」を撮った。ロゴの中心は画面の中心と一致。ページのエラーなし
