# SPEC-085 — マインちゃんのフルボイス（タイトルコール・全セリフ・ボイスの音量）

- **Status**: Done
- **関連**: SPEC-056（ナビのマインちゃん）・SPEC-059（置き場所）・SPEC-068（初めてのひとこと）・SPEC-069（タップの関門）

## 1. 背景

作者の依頼（2026-10-17）：

- マインちゃんのセリフをフルボイスにしたい。 作者が全セリフ（35 本）を WAV で作り、 `assets/` に置いた
- 最初にゲームを開いたときのロゴ画面を押したら、 タイトルコール「マイクリプト サバイバー！」を出す
- MP3 に変換して実装する
- ヒーローの紹介文は、 全部同じ言い回しで単調だったので変えた（音声もその文で作った）

作者の決定：mycryptoheroes はゲームを横断して使う素材の置き場なので、 **タイトル固有のフルボイスはこのリポジトリで管理する**。

## 2. 仕様

### 2.1 ファイル（`assets/voice/mine/`・`js/voice-lines.js`・`tools/voice/build.mjs`）

- 作者の WAV（`番号-セリフ.wav`。 00 がタイトルコール、 01 から台本の CSV の並び）を、 MP3（モノラル・44.1kHz・64kbps）にした。 35 本で 1.1MB（WAV は 12MB）
- 名前はセリフの場面から付ける（`title.call`・`hero.1001`・`tip.item.heal` など）
- `node tools/voice/build.mjs <WAV のフォルダ>` で、 MP3 と `js/voice-lines.js`（名前 → ファイルと長さ）を作り直せる（ffmpeg が要る）
- 元の WAV はリポジトリから外した（履歴には残る）

### 2.2 鳴らし方（`js/voice.js`）

- マインちゃんの吹き出しが出たら、 そのセリフのボイスを鳴らす（タイトル・難易度・ヒーロー選択・ステージの始まり・ボス・初めてのひとこと）
- 1 度に 1 つ。 次のセリフに進んだら、 前のボイスは止める
- 戦闘の小窓は、 ボイスが言い終わるまで引っこまない
- タブを離れたら止める
- 要素は 1 つを使い回す（iOS で、 操作の中で一度鳴らした要素なら、 あとから鳴らせる。 SPEC-069 の BGM と同じ）
- 日本語のボイスだけ。 英語の表示でも同じボイス

### 2.3 タイトルコール

- 最初のロゴ画面（「タップしてはじめる」）を押したときに鳴らす。 押さずに進めた環境（音を自動で鳴らせる環境）では、 タイトルに進むときに鳴らす
- 鳴り終わるまで、 タイトルのあいさつのボイスを待たせる（重ねない）

### 2.4 ボイスの音量（設定）

- 設定に「🗣 ボイス」を足す（0〜100%。 既定 100%。 前の版の設定も 100%）。 0% で鳴らさない
- つまみを離すと、 「ヒーローたちが待ってるよ！」で確かめられる

### 2.5 セリフの文

- ヒーローを選んだとき：ヒーローごとの紹介（いままでは「{name}！ 最初の武器は「{weapon}」だよ。」の 1 つだけ）

| ヒーロー | セリフ |
|---|---|
| コナン・ドイル | コナン・ドイル！「リボルバー」で敵を狙い撃つよ！ |
| 甲斐姫 | 甲斐姫！ 「ブレード」で近くの敵を斬り伏せる！ |
| シートン | シートン！ 「モアイ像」が降り注ぐよ！ |
| ピタゴラス | ピタゴラス！ 「ノービスブック」が周囲を守るよ！ |
| ライト兄弟 | ライト兄弟！ 「レーザーガン」で貫通攻撃！ |
| スパルタクス | スパルタクス！ 「アックス」を投げつけるよ！ |
| グリム兄弟 | グリム兄弟！ 「ピエロ」で爆破攻撃だ！ |
| 孫子 | 孫子！ 「手裏剣」で連続攻撃！ |
| 石田三成 | 石田三成！ 対角線に「ナイフ」を飛ばすよ！ |
| 許褚 | 許褚！ 「パンジャンドラム」で敵を一掃しよう！ |

- ボイスのないヒーロー（これから足すヒーロー）は、 いままでのひな形
- 棒磁石：「落ちているジェム」→「落ちている**CE**」（ボイスに合わせる。 画面の表示も CE）
- 読み方だけ違う行（「みっつ」「よっつ」「アブソリュート」「ノード アバカス」「ひとつ」）は、 画面の文はいままでのまま

## 3. 非ゴール

- 英語のボイス
- 口の動きをボイスに合わせる（いままでどおり、 文字が出るあいだ口が動く）

## 4. 受け入れ基準

- [x] ロゴ画面を押すとタイトルコール、 そのあとあいさつのボイス
- [x] どのセリフにもボイスがある。 次のセリフに進むと前のボイスは止まる
- [x] 設定の「ボイス」を 0% にすると鳴らない

## 5. テスト

- `node --test tests/voice.test.mjs`
  - ファイルがすべてある（大きさと長さ）
  - どのセリフにもボイスがあり、 使っていないボイスがない
  - ヒーローごとの紹介と、 ボイスのないヒーローのひな形
  - 設定の既定と前の版の設定
  - タイトルコールは鳴り終わるまで次を待たせる、 要素は 1 つ、 0% で鳴らない
- ヘッドレス Chromium（自動で鳴らせない設定）：ロゴ画面を押してからヒーローを選ぶまで
  - タイトルコール（0 秒）→ あいさつ（1.9 秒）→ 難易度 → ヒーロー選択 → ピタゴラスの紹介の順に鳴った
  - ページのエラーなし
