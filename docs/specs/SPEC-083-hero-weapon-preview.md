# SPEC-083 — ヒーロー選択：最初の武器の動きのプレビュー

- **Status**: Done
- **関連**: SPEC-013（ヒーローと最初の武器）・SPEC-056（ヒーローの見せ場）・SPEC-028（武器の段）

## 1. 背景

作者の依頼（2026-10-17）：

- ヒーロー選択画面で、各ヒーローの使う武器の実際の動きをプレビューで見られるようにしたい
- 選んで 1 秒後に、 ヒーローの演出画面をプレビューに切り替え、 ヒーローがエクステンションで戦っている様子を流す
- Common → Uncommon → Rare の 3 段階を 3 秒ずつ（レアリティを併記して）流し、 流し終えたら最初の演出に戻る

いまは、 武器の名前と絵（詳細の行）しか分からなかった。

## 2. 仕様

### 2.1 流れ（`js/hero-preview.js` の `previewPhase`）

| 選んでから | 見せ場に出るもの |
|---|---|
| 0〜1 秒 | 大きなドット絵と名前（いままでの演出） |
| 1〜4 秒 | Common（武器の 1 段目） |
| 4〜7 秒 | Uncommon（2 段目） |
| 7〜10 秒 | Rare（3 段目） |
| 10〜13 秒 | 大きなドット絵と名前 |
| 13 秒〜 | また Common から（くり返す） |

- ほかのヒーロー・同じヒーローを押すと、 はじめから
- ヒーロー選択を閉じる・冒険を始めると止まる
- 切り替えは 0.22 秒で重ねて替える（動きを減らす設定では、 すぐ替える）

### 2.2 プレビューの戦場

- 本番の武器のコード（`weapons.js`・`archetypes.js`・`projectiles.js`・`damage.js`・`fx.js`・`render.js`）を、 別の小さな戦場で動かす
  - 動かすあいだと描くあいだだけ、 `state.battle`・`state.buffs`・HP をプレビューのものに差し替え、 すぐ戻す
  - 強化なし・HP は満タン（HP の帯と画面の縁の赤は出ない）
- ヒーローは真ん中で動かない。 ステージ 1 の雑魚（101・124）が 9 体、 まわりから歩いてくる（少し手前で止まり、 痛くない）
  - 敵の HP は「1 段目の武器のダメージ × 2.2」（= 段が上がるほど早く倒れて見える）
  - 倒すと、 画面の外からまた 1 体歩いてくる
- 撃破数は数えない。 CE は拾わない（レベルアップしない）。 効果音は鳴らさない（`audio.js` の `setSeMuted`）
- 段が替わるたびに、 戦場を作り直す（敵も置き直す）
- 見える広さは横 380 くらい（見せ場の幅で 0.7〜1.4 倍）

### 2.3 レアリティの札（左上）

- 「コモン ／ アンコモン ／ レア」（`hero.rarity.*`）と、 その段の武器の名前（`getTierName`）
- 3 つの目盛りが、 段の数だけ灯る（Common は灰・Uncommon は緑・Rare は青）
- 言語を替えると、 札も替わる

## 3. 非ゴール

- 4 段目より上（Epic・Legendary）は見せない
- 2 つ目からの武器（レベルアップで取るもの）は見せない
- プレビューの戦場で、 ヒーローは動かない

## 4. 受け入れ基準

- [x] 選んで 1 秒たつと、 見せ場がプレビューに替わる
- [x] Common → Uncommon → Rare を 3 秒ずつ、 札にレアリティと武器の名前
- [x] 流し終えると大きな絵に戻り、 3 秒してまた流す
- [x] 閉じると止まる。 撃破数は増えない。 音は出ない
