# SPEC-099 — ヒーローの選択画面にレーダーチャート

- **Status**: Draft
- **関連**: SPEC-097（PHY / INT を効かせる）・SPEC-083（ヒーローと武器のプレビュー）・SPEC-100（固有スキル）

## 1. 背景（作者の依頼 2026-10-19）

ヒーローの性能差を、数字だけでなく **レーダーチャート** で意識できるようにしたい。

## 2. 軸（5 つ）

ヒーローのステータス 4 つに、武器の性格を 1 つ足す。どれも **戦闘で実際に効いているもの** だけにする（SPEC-097 で PHY・INT が効くようになる）。

| 軸 | 中身 | 元 |
|---|---|---|
| 体力 | HP の上限 | HP（SPEC-014） |
| 攻撃 | 武器のダメージの倍率 | PHY（SPEC-097） |
| 連射 | 武器の間隔の短さ | INT（SPEC-097） |
| 速さ | 移動の速さ | AGI（SPEC-014） |
| 射程 | 初期武器の届く距離（近い ⇄ 遠い） | 武器の系列（ブレード・雪だるまは近い、ライフル・レーザーは遠い） |

- 目盛りは **10 人の中での位置**（いちばん低い人を 1、いちばん高い人を 5 の 5 段）。生の値は軸の横に小さく添える（例「体力 4　HP 148」）
- 形はヒーローごとの属性色（青龍・朱雀…）で塗る。選んでいるヒーローと、比べるために **いま使っているヒーローの形を薄く重ねる**

## 3. 画面

- ヒーローを選ぶと、詳しい欄（SPEC-083 のプレビューの横、狭い画面では下）に、チャート・固有スキルの名前と一行の説明（SPEC-100）・初期武器（LL まで上がることの表示。SPEC-101）
- ロック中のヒーローもチャートは見られる（何が手に入るかが分かると、解放したくなる）
- SVG で描く（外部のライブラリは足さない）。`prefers-reduced-motion` では形が伸びる動きを止める
- 読み上げ用に、軸と段を文章でも持つ（`aria-label`「体力 4、攻撃 5、…」）

## 4. テスト

- 5 段の目盛りの計算（純関数）：10 人の値 → 1〜5。同じ値は同じ段
- 軸の値が SPEC-097 の式と同じ関数から出ている
