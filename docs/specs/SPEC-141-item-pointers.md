# SPEC-141 — お助けアイテムを最前面に・画面の外のアイテムを矢印と絵で示す

- **Status**: Done
- **関連**: SPEC-053（お助けアイテム・宝箱の矢印）・SPEC-033（マジックカード）・SPEC-140（合体ロボ）

## 1. 作者の依頼（2026-10-21）

- 終盤は敵で画面が覆い尽くされ、 どこにどのアイテムが落ちているか分からなくなる。 宝箱と同じように、 画面外のどの方面にどのアイテムがあるかを、 アイコン付きの矢印で示してほしい
- アイテムを最前面に出して、 敵の大群に埋もれないようにしてほしい

## 2. 変えたこと（`js/battle/render.js`）

- **描く順**：お助けアイテムとマジックカードを、 敵・弾・自分・撃破の粒のあとに描く（最前面）。 霧の夜（SPEC-112）では霧の下（霧で隠す遊びはそのまま）。 ダメージの数字はその上。
- **画面の外の矢印**：お助けアイテム（パンケーキ・棒磁石・雷鼓・懐中時計・合体ロボ）とマジックカードが画面の外にあるとき、 その向きの縁に小さな矢印を置き、 すぐ内側に絵の丸（アイテムの色の縁）を出す。 合体ロボは虹色。
  - 近い順に 8 つまで（縁が埋まらないように）。 丸はゆっくり脈打つ。
  - 上の端は HUD の下（隠れないように）。
- 宝箱・木馬の矢印（SPEC-053 / 064）とボスの予告（SPEC-079）はそのまま。

## 3. 確かめたこと

- `node --test tests/*.test.mjs`：338 件すべて通過（`tests/item-pointers.test.mjs`）。
- ブラウザ（390×844）：6 方向に置いたアイテムがそれぞれの縁に矢印と絵で出る、 敵を重ねた上にパンケーキが見える。 エラーなし。
