# SPEC-102 — CE がヒーローに吸い込まれる

- **Status**: Implementing（`js/battle/absorb.js`・`js/battle/gems.js`・`js/battle/render.js`・`js/audio.js`）
- **関連**: SPEC-007（CE と経験値）・SPEC-019（ギョクで拾う範囲が広がる）・SPEC-053（棒磁石）

## 1. 背景（作者の依頼 2026-10-19）

いまは拾える範囲に入った CE がその場で消える。**消すのではなく、ヒーローに吸い込まれる** ように見せたい（棒磁石を拾ったときと同じ動き）。経験値を集める気持ちよさを味わってもらう。

## 2. 決まり

- 拾える範囲（`GEM_PICKUP_RADIUS × ギョクの倍率`）に入った CE は、その場で消さずに **「吸い込み中」** になる
- 吸い込み中の CE は、ヒーローへ向かって **だんだん速く** 飛ぶ（最初はゆっくり。ふつうの範囲なら約 0.14 秒、ギョクで 3 倍に広げても約 0.26 秒で届く。初速 60px/秒・加速 2000px/秒²）。3 割 5 分まで小さくなり、光の尾を引く
- **ヒーローに届いた瞬間** に経験値が入る（いまの計算と同じ。学びの速さ SPEC-090c も同じ）
- 吸い込み中の CE はもう落ちているものとして数えない（重ねて吸い込まない・敵に消されない）
- 届いたときの音はいまの音（80ms に 1 回まで）。続けて届くときは（0.4 秒以内）、音の高さを 4% ずつ上げて「じゃらじゃら」と鳴らす（8 段まで）
- 棒磁石（SPEC-053）は、画面のすべての CE を一度に吸い込み中にするだけ（動きは同じものを使う）
- `prefers-reduced-motion`・設定の「演出を減らす」のときは、いままでどおりその場で消して経験値を入れる（棒磁石の CE も、いままでどおり一直線に飛んでくる）

## 3. 気をつけること

- 吸い込みのあいだに経験値が入るのが遅れても、レベルアップの判定は届いた瞬間（1 フレームに複数届いてもまとめて判定。いまと同じ）
- ステージの終わり・ゲームオーバーのとき、吸い込み中の CE は経験値を入れずに消す（いまの「落ちている CE」と同じ扱い）
- 数が多いときの重さ：吸い込み中の CE は描くだけで当たり判定をしない

## 4. テスト

- 範囲に入る → 吸い込み中 → 届いて経験値（純関数で位置と速さ）
- reduced-motion ではすぐ入る
- 棒磁石・ギョク・学びの速さとの組み合わせで、入る経験値がいまと同じ
