# SPEC-066 — v1.2 を新しい版で計る：総合スコア v4（balance 2）と RTA v3

- **Status**: Done
- **関連**:
  - SPEC-041（総合スコア）・SPEC-051（難易度の係数）・SPEC-040 / SPEC-048 / SPEC-054（RTA）
  - SPEC-062〜065（v1.2 の変更）
  - 共通基盤（bearko/MyCryptoPortfolio）の SPEC-002 3.2（総合スコア v4）・SPEC-001 6.16（RTA v3）

## 1. 背景

v1.2（撃ってくる敵・雷鼓・ステージの仕掛け・トロイの大群・レベルアップ約 2 倍）で、全クリアの活動レポートのスコアが約 15〜17 万 → 約 26〜31 万に上がった（自動プレイ）。遊びの中身も変わったので、RTA の記録も前の版とは並べられない。

作者の決定（2026-10-17）：新しい版にする。総合スコアは係数を測り直して、ふつうの全クリアを今と同じ 5,000 にそろえる。RTA は新しいレギュレーションで計る。古い記録は古い版のまま残す。

## 2. 仕様（`js/platform.js`・`index.html`）

### 2.1 総合スコア

- 送る成績に `balance: 2`（`SCORE_BALANCE`）を足す
- 共通基盤の総合スコア v4 が、`balance` ごとの係数で割る（`balance` なし＝v1.1 まで：30、`balance: 2`：**60**）。v1.1 までの成績の点は変わらない
- 係数 60 の根拠：v1.2 の自動プレイ（circle ボット。撃ってくる敵の弾・珠の列・パンチの印も避ける）の全クリア 261,521・279,872・311,237（3 回）→ ふつうの全クリアを 300,000 と見た（300,000 ÷ 60 ＝ 5,000）

### 2.2 RTA

- NORMAL：`survivor-normal-v2` → **`survivor-normal-v3`**
- ABSOLUTE ×2.0：`survivor-absolute-2x-v2` → **`survivor-absolute-2x-v3`**
- モード選択の RTA ランキングのリンクも v3 に
- 最短時間は v2 と同じ（ボスはゲーム内の 4 分・宝箱は 1 ステージ 4 つのまま。木馬を壊したときの中身に懐中時計は出ない）。雷鼓はボスにも効くので、ボスを早く倒せる

### 2.3 マージの順番

共通基盤（総合スコア v4・RTA v3）を先にマージしてから、この SPEC をマージする（知らないレギュレーション・知らない `balance` を送らないため）。SPEC-062〜065 は、この SPEC と続けてマージする。

## 3. 非ゴール

- 古いレギュレーション（懐中時計なし・v2）を `deprecated` にするかは作者が決める（記録は消さない）

## 4. 受け入れ基準

- [x] 全クリアで送る成績に `balance: 2` が入る
- [x] RTA は v3 で始まる。モード選択のリンクが v3 のランキングを開く

## 5. テスト

- `tests/platform.test.mjs`：レギュレーションの ID（v3）、送る成績に `balance: 2`
- 共通基盤の側：v4 の点（balance なしは v3 と同じ、balance 2 は 1/60、知らない版は受け付けない）、v3 のレギュレーション（最短時間は v2 と同じ・横断 RTA の区間にも数える）
