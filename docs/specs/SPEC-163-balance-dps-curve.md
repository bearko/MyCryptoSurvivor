# SPEC-163 — DPS の期待値に合わせたバランス調整（湧き・HP・ボス・木・店）と、 sim・自動プレイ

- **Status**: Done
- **関連**: SPEC-162（引き継ぎ・15 段階）・SPEC-078 / 084（洪水と密度）・SPEC-107（敵の段階）・SPEC-109 / 123（店）・SPEC-090（木）・SPEC-146（自動プレイ）

## 1. 作者の方針（2026-10-21）

- ステージ開始 ◯ 秒時点の **DPS の期待値で敵を殲滅できるように**、 湧き率や敵のパラメーターを調整する
- どれくらいスキルツリーが育ったら、 どれくらいの DPS で分布するかを**各エクステンションごとにシミュレーション**する
- 敵の数や HP で、 **何周したらどのくらい GUM がたまって、 数周するごとに如実に生存時間が延びる**ようにする
- 徹底的にテストプレイする

## 2. 測る道具

| 道具 | 中身 |
|---|---|
| `tools/autoplay/run.mjs` | ゲームそのものを Playwright で自動で遊ぶ（**偽の時計で実時間の 3〜4 倍速**）。 店は買う（`--buy all` 安い順 / `focus` 初期武器 → 持っている武器 → 新しい武器 → 強化）、 ミッションは受ける、 倒れたら木を安い順に取って復活（`--runs N` で周回）。 受けるダメージ `--k`（0.3 = ふつう、 0.15 = 上手い、 0.5 = 不慣れ）。 10 秒ごとに 撃破・CE・画面の敵・HP・与ダメ・装備 を記録して JSON に |
| `tools/sim/balance.mjs` | 机上 sim。 ゲームの定数と純関数（`levelParams`・`floodMul`・`densityTarget`・段階の型）から、 **武器ごと・段ごとの DPS の期待値**と、 **時刻ごとの流入 HP/秒**を出し、 「圧」（流入 ÷ DPS）を 1 秒刻みで見る。 店の買い方も同じ。 数字は目安で、 本番の答えは自動プレイ |

## 3. 測って分かったこと（SPEC-162 直後・調整前）

| 条件 | 結果 |
|---|---|
| NORMAL・木なし・K 0.3 | ステージ 1 の **104 秒**で倒れる。 撃破 90・CE 19（40 秒で 12 しか入らず、 店で何も買えない） |
| NORMAL・木なし・2 周目 | 139 秒。 撃破 272 |
| NORMAL・1,500 GUM（21 節）・K 0.3 | **148 秒**。 撃破 584。 2:00 の群れ（16 体 / 12 秒）で画面の敵が 113 体になり圧死。 CE 833 が余っていた |
| EASY・根あり・K 0.15 | 2 ステージとも楽にクリア（引き継ぎのおかげ） |

原因は 3 つ。 (1) **始まりの湧き（0.8 秒に 1 体 = 31 HP/秒）が初期武器 Lv.1 の DPS（15〜20）を最初から超えている**ので、 敵は開始直後からたまる。 (2) **洪水（×12・pow 2.5）と 2:00 からの群れ、 密度の目標 0.85** が同じ時刻に重なって「どばーっ」になる。 (3) 店は 1 回に 4 枚しか買えず、 **15 段を登る速さが CE ではなく札の枚数で頭打ち**になる（CE が余ったまま倒れる）。

## 4. 直したこと

### 4.1 敵（`STAGE_TABLE`・`ENEMY_SPECS`）

| | ステージ 1 | ステージ 2 | ステージ 3 |
|---|---|---|---|
| 湧きの間隔（×0.8 秒） | 1.0 → **1.4** | 0.85 → **1.1** | 0.7 → **0.9** |
| 洪水（最大倍率 / pow / 開始） | ×12 / 2.5 / 0:30 → **×4 / 1.8 / 0:40** | ×16 / 2.5 / 0:20 → **×7 / 1.8 / 0:30** | ×20 / 2.5 / 0:15 → **×9 / 1.8 / 0:20** |
| 群れ（開始 / 間隔 / 数） | 2:00 / 12 秒 / 16 → **3:00 / 20 秒 / 6** | 2:00 / 10 秒 / 20 → **2:00 / 15 秒 / 10** | 1:30 / 8 秒 / 28 → **1:40 / 10 秒 / 18** |
| 密度の目標（最大 / 開始） | 0.85 / 0:20 → **0.3 / 1:30** | 1.45 / 0:15 → **0.6 / 0:40** | 1.65 / 0:10 → **0.95 / 0:30** |
| 雑魚の HP | ×1 | ×1.5 → **×2.2** | ×2.0 → **×3.5** |
| 雑魚の攻撃 | ×1 | ×1.25 → **×1.4** | ×1.5 → **×1.8** |
| 同時の上限 | 320 → **260** | 440 → **380** | 600 → **480** |
| ボスの HP（最終値） | 60,000 → **12,000** | 90,000 → **45,000** | 90,000 → **100,000** |

考え方: **始まりの流入 HP/秒 を初期武器 Lv.1 の DPS より下に置き**（ステージ 1 は 22 HP/秒）、 そこから **CE の収入で装備が育つ傾き**に合わせて増やす。 装備が引き継がれるので（SPEC-162）、 ステージ 2・3 は**数ではなく HP**で強くする。

**ボスの HP は、 いままで `ENEMY_SPECS` × `BOSS_MOVES.hpMul`（×20 / ×15。 SPEC-080「ボスの前にレベルが 40 前後まで上がる」前提）で 60,000 / 90,000 / 90,000 だった。** 湧きをゆるめた今はボスの時刻のレベルが 15〜25 なので、 この前提は成り立たない。 倍率を 1 にして、 最終値を `ENEMY_SPECS` に書く。 値は**その時刻に育っている装備の単体 DPS で 20〜30 秒**: ステージ 1 は 4:00 の典型的な装備（初期武器 Lv.6〜7 ＋ 2〜3 本）の単体 DPS 400〜600 → 12,000。 ステージ 2 は引き継いだ装備（Lv.8〜10 ＋ 4 本）の 1,500〜2,500 → 45,000。 ステージ 3 は 3,000〜4,500 → 100,000。 EASY の `bossHpMul` は 0.015 / 0.032 にして、 実体（180 / 1,440）は SPEC-154 のときと同じ。

**ボスは 4:00 に出る**（`BOSS_SPAWN_AT_MS`）。 ステージ 1 を「生き残る」とは、 4:00 までの湧きに耐え、 そこからボスを倒すことの 2 段になる。 §5 の「ステージ 1 の 4:00 に届いた」と「クリア」は別に数える。

### 4.2 木（`skill-data.js`）

段ごとの効き目が控えめだったので上げた: 頑丈なからだ 4% → **6%**、 厚い皮 3% → **4%**、 鋭い一撃 3% → **5%**、 手早さ 2% → **3%**（どれも段ごと）。 1 周（約 500〜700 GUM）で安い節を 10〜15 取れるので、 2 周目には 攻撃 +15〜25%・HP +18〜30% になる。

### 4.3 店（`shop.js`・`SHOP_PRICE`）

**同じ札を続けて買える**（買っても札は残り、 次の段の値段になる。 上がりきったら売り切れ。 セールは 1 回だけ）。 15 段を 1 回の店で何段も登れる。 CE は札の枚数ではなく値段で尽きる。

値段の表（ステージ 1・行き先の段）は、 序盤の CE の収入（1 秒に 1〜2）で **2 分までに主武器を Lv.4〜5** にできる傾きに下げた: 15 / 20 / 30 / 50 / 90 / 150 / 240 / 380 / 560 / 800 / 1,100 / 1,500 / 2,000 / 2,600 / 3,300（Lv.10 まで合計 2,285、 Lv.15 まで 12,785。 SPEC-162 の表は 3,555 / 24,555 だった）。

得意武器（`wm_main`）は、 **土台 50%** にして段ごと ＋15%（65 / 80 / 95%）。 木を触っていない人でも、 レベルアップの札の半分に初期武器が来る。

### 4.4 EASY（`easy.js`）

ボスの HP の倍率を新しい最終値に合わせた（ステージ 1: 12,000 × 0.015 = 180、 ステージ 2: 45,000 × 0.032 = 1,440。 どちらも SPEC-154 のときの実体と同じ）。 装備を引き継ぐぶん楽になる。 「根なしの 1 回目はステージ 2 で倒れる」設計（SPEC-154）がどうなったかは §5。

### 4.5 自動プレイのボット（`tools/autoplay/run.mjs`）

数字を測る道具のほうも 2 つ直した。 (1) 囲まれると逃げる向きが打ち消して止まっていたので、 **12 方向の危険を足して、 いちばん安全な向き**へ。 (2) **ボスから逃げ続けていた**（ボスの危険を 4 倍に見ていた）ので、 人と同じく**武器が届く距離（射程のある武器なら 220 px、 近接だけなら 70 px）を保って戦う**。 v4 までの「4:00 直後に倒れる」はこのボットの癖で、 ゲームの数字ではなかった。

## 6. 作者に見てほしいところ

1. **ステージ 2 の 3:00 以降が次の壁。** 装備 Lv.8〜11 でも 100〜150 体で押される。 最終値（群れ 10 体 / 15 秒・密度 0.6）の周回は未測定。 もっと早く越えさせたいなら、 洪水 ×7 → ×6 か群れの開始を 2:30 に。
2. **ステージ 3 とボス 100,000 は机上の値。** 自動プレイがステージ 2 を越えられないので確かめていない。 Lv.10〜13 を 4〜5 本持つ前提。
3. **不慣れな人の EASY。** 根を取ってもステージ 2 のボスで倒れる。 「根なしは倒れる」を守りつつ助けるなら、 根の効き（`EASY_HERO_MUL` 0.6 → 0.5）か、 ボスが出た瞬間の雷鼓を 20% → 40% に。
4. **周ごとの伸びが「引き」に負ける。** 木 6〜9 節（攻撃 +15%・HP +18%）より初期武器の札が来るかどうかの差が大きい。 得意武器 50% → 60% か、 `GUM_RATE` を上げて 1 周 800 GUM にすると「周で伸びる」が見えやすくなる。 「1 周ごとに +30 秒」の目安はまだ満たしていない。
5. **ボットの限界。** 突進の見切り・近接の出し入れ・札の選び方は人に劣る。 §5 の時刻は下限。 ステージ 1 のボス戦（ふつうの腕で 15〜55 秒）は人なら 20〜30 秒に収まる見込み。
6. 店の連続購入で、 強い人は 1 回の店で主武器を 3〜4 段上げられる。 値段の表（§4.3）がそのブレーキ。
