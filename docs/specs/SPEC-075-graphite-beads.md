# SPEC-075 — そろばんの珠：球状黒鉛の絵と、横以外の向き

- **Status**: Done
- **関連**: SPEC-064（ステージの仕掛け）・SPEC-068（マインちゃんの補足）

## 1. 背景

作者の依頼（2026-10-17）：

- そろばんのギミックは、グラファイトシリーズの Legendary のアートを使ってほしい
- そろばんのギミックは、水平以外のパターンがあってもよさそう

SPEC-064 の珠は、canvas で描いた木の珠（左右のとがった形）で、列はいつも横に走っていた。

## 2. 仕様

### 2.1 珠の絵（`js/battle/gimmicks.js`・`js/battle/gimmicks-render.js`）

- 珠を **5042 球状黒鉛**（グラファイトシリーズの Legendary。黒い球に緑の六角の模様）で描く（`BEADS.extId`）
- 転がった道のりぶん回す（道のり ÷ 半径）。絵は枠の 9 割ほどなので、当たりの円（半径 22）より少し大きく描く
- 珠が通るあいだの軸は、黒鉛の色の棒に緑の光を細く足す
- 絵を読み込むまでは、いままでの木の珠で描く

### 2.2 列の向き

- 列を **出発点・向き（単位ベクトル）・長さ** で持つ（横・縦・斜めを同じ計算で）
- 向きの選び方（`beadDirChoices`）
  - 最初の列：横（いままでどおり）
  - 2 本目から：横・縦（4 通り）
  - 1:30 から（`diagFromMs`）：横・縦・斜め（8 通り）
- 列は自分の近く（列に直角に ±140px）を通り、画面の外から外へ横切る
  - 長さは、画面を向きに合わせて測った幅に、両端の余り 120px を足したもの（`beadSpan`）
  - 世界の外には切りつめる（`clipRowToWorld`）
- 2:30 からの 2 列は、いままでどおり平行に離して逆向きに走らせる
- 予告（赤い帯・点線・▶▶）とそろばんの軸は、列の向きに回して描く
- 敵は、列から離れる向き（列に直角）にはじく
- 速さ・珠の数・間隔・予告の長さ・ダメージ・出る間隔は変えない

### 2.3 遊び方

- 「アバカスは珠の列が横切る（縦や斜めにも走る。敵もはじく）」

## 3. 非ゴール

- 名前（そろばんの珠）・マインちゃんの補足の文は変えない
- ほかのステージの仕掛けは変えない

- [x] 珠が球状黒鉛の絵で、転がって回る

- [x] 予告の帯と矢印が列の向きに合う
