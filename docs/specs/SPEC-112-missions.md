# SPEC-112 — ミッション

- **Status**: Done
- **関連**: SPEC-103 7.4（設計）・SPEC-104（閉じたら 3 秒数える）・SPEC-109 / 117（ショップ）・SPEC-110（固有スキルの強化）

## 1. 何をするか

ウェーブの途中に、シャドーヒーローがミッションを持ちかける。**時間を止めて「受ける / 断る」を選ぶ**（キーボードは Y / N。閉じたら 3 秒数えてから再開）。受けたら一定時間、そのヒーローらしい厳しい条件がかかる。最後まで生き残れば（追加の条件があればそれも満たせば）達成で報酬。**失敗しても罰は無い**。

- **ショップで遊ぶときだけ**（報酬がショップに効く）。SPEC-111 で RTA でも出るようにした

## 2. いつ出るか

- 店を出てから **10〜30 秒目**に、1 ウェーブで最大 1 回、**4 割**の確率（ウェーブの始めに決める）
- **1 ステージ 3 回まで**。1 回目の店の前・次の店の 10 秒前より後・終わりがボスの予告（3:50）に重なるときは出さない
- 出し手は乱数（同じ人が続けて来ない・プレイ中のヒーローと同じ人は出さない＝ジャックザリッパーで遊ぶときはシャドージャックザリッパーは来ない）
- ボスが出たら、受けているミッションは達成として終える（生き残った）

## 4. 画面

- **持ちかけ**：画面の上に斜めの帯が飛びこむ（シャドーの顔・MISSION と重さ・出し手・ミッション名・説明・時間・条件・報酬・「断る（N）」「受ける（Y）」）。重さで帯の色（軽＝緑・中＝紫・重＝赤）
- **受けているあいだ**：HUD の下の段に、顔・ミッション名・条件（撃破 n / 200 など）・残りの帯・残り秒。残り 5 秒で金色に光る
- **結果**：画面の上に「MISSION CLEAR!」（＋報酬）か「ミッション失敗……罰はないよ。次のチャンスに！」。遊びは止めない
