# SPEC-056 — ナビのアインと、キャラクターと UI の重なり

- **Status**: Done
- **関連**：SPEC-055（ノード端末）・SPEC-014（ヒーローの詳細）・SPEC-046（ステージの始まりの帯）・DESIGN_CHARTER 14.4
- **シリーズ**：UI の見直しの 2 本目（作者の決定 2026-10-17：案内役はナビのアイン）

## 1. 背景（参考作の UI の考え方から）

| 考え方 | この SPEC |
|---|---|
| 吹き出しがセリフの量で伸び縮みする → 「システムが表示している」ではなく「キャラが喋っている」 | アインの吹き出し（端末の通信窓）が、セリフに合わせてばねで伸び縮みし、1 文字ずつ出る |
| 画面に入るたびにカメラアングル・ポーズが変わる → 飽きさせない | ヒーロー選択で、選ぶたびに構図（大きさ・位置・傾き・向き）が変わる。アインはセリフごとにポーズが変わる |
| 文字の裏にキャラクター／テロップの手前にキャラクター → UI と空間を分けない | ヒーローの名前の大きな文字はヒーローの**裏**、ステージの始まりの帯の**手前**にヒーロー |
| 会話の送りは漫画のページをめくるような 500〜700ms | 吹き出しを押すと、めくれるように次のセリフ（520ms） |

いま（v1.0）は、キャラクターはタイルの小さなアイコンでしか出てこず、ヒーロー選択の詳細も 64px の顔だけ。

## 2. 仕様

### 2.1 ナビのアイン（`js/navi.js`・`css/chars.css` 新規）

- 絵：mycryptoheroes の `Image/Characters/navi_ain_*.png`（96×128）。整数倍（2 倍・1 倍）で `pixelated`
- 動き：
  - 喋っているあいだは talk のコマを 130ms ごと（腕組みのセリフは腕組みの talk）
  - 言い終えるとセリフのポーズ（指さし・腕組み・両手を上げる・ウインク・キラキラ・照れ・泣く など）を 1.6 秒保ち、ふだんの待機へ
  - 待機中は 2.6〜4.4 秒ごとに瞬き。タイトルの最初はあいさつ（6 コマ）
- 吹き出し（通信窓）：シアンの縁・走査線。左下の角がアインのほうへ伸びる。セリフの大きさを先に測り、幅・高さをばね（300ms）で追う。1 文字 28ms。続きがあれば ▼
- 押す：吹き出しは「途中なら最後まで出す → 次のセリフへ（めくる 520ms）」。アインは反応（タイトルでは押すたびに違う 4 通り）
- 置き場所：

| 場面 | 置き方 | セリフ |
|---|---|---|
| タイトル | 左下から 2 倍でのぞきこむ | あいさつ → 「3 つのノードを突破しよう」。押すと反応 |
| モード選択 | 右下に 1 倍（左右反転）。言い終えて 3.5 秒で吹き出しをたたむ（押すと開く）。縦 700px 以下は吹き出しを出さない | 「迷ったら NORMAL」「ABSOLUTE は 4 つの軸を自分で」 |
| ヒーロー選択 | **通信窓**（顔だけの小窓＋吹き出し）を大きな絵の左上に | 「ヒーローを選んで」→ 選ぶと「◯◯！ 最初の武器は「△△」だよ」（ポーズは選ぶたびに変わる） |
| 戦闘（ステージの始まり） | **通信窓**を HUD の下（RTA なら時計の下）に。押せない。言い終えて 1.6 秒で引っこむ | 最初・途中・最後のノードで違う。RTA の最初は「懐中時計を狙って」 |

- 通信窓（ヒーロー選択と戦闘）は、ボタン・タイル・戦場を隠さないための形。顔の小窓は 96×128 の絵の (21, 20) から 46×46
- 縦 760px 以下のタイトルは 1 倍
- 文言は `data/i18n/ui.json` の `navi.*`（日本語・英語）
- 「演出を減らす」：1 文字ずつ出さず、コマの動き・ばね・めくりもしない（ポーズの切り替えだけ）

### 2.2 ヒーロー選択：大きなドット絵と、その裏の名前

- 詳細の上に「ステージ」（高さ 130〜190px）：派閥の色の斜めの帯と光、走査線
- 名前の大きな文字（英語・大文字・縁取りだけ）を**ヒーローの裏**に。長い名前ほど小さく（コンテナの幅 ÷ 文字数）
- ヒーローは 192px（3 倍）か 256px（4 倍）、たまに 128px。**選ぶたびに構図が変わる**（5 通り。前と同じにはならない）：大きさ・位置・傾き・左右反転、名前の位置
- 入ってくる：ヒーローは右から、名前は左から（カメラが回りこむように）
- 詳細の行の 64px の顔は隠す（大きな絵があるので）。名前は見出しの書体

### 2.3 ステージの始まり：帯の手前にヒーロー

- 帯（STAGE n / node : 〜）は左寄せにし、右に**帯の手前に重なる**ヒーロー（128px）
- 帯は上下に開いて出て（走査線・上は金・下はシアンの線）、ヒーローは右から入って左へ抜ける。2.2 秒（v1.0 は 1.6 秒）

## 3. 非ゴール

- 結果の画面（ステージクリア・ゲームオーバー・活動レポート）のアインとヒーロー（SPEC-058）
- 戦闘中のレベルアップ・ボス出現のセリフ（SPEC-057）

## 4. 受け入れ基準

- [x] タイトルでアインがあいさつし、吹き出しがセリフの長さで伸び縮みする。押すと反応する
- [x] モード選択・ヒーロー選択・ステージの始まりで、場面に合ったセリフを言う
- [x] ヒーロー選択で大きなドット絵が出て、名前の文字がその裏に重なる。選び直すたびに構図が変わる
- [x] ステージの始まりの帯の手前にヒーローが重なる
- [x] アインが「冒険を始める」・タイル・モードのボタン・戦場を隠さない（390×844・360×640・1280×800）
- [x] コンソールにエラーがない

## 5. テスト

- `node --test tests/navi.test.mjs`：
  - どの場面のセリフにも日本語・英語の文言とポーズがある
  - ステージの最初・途中・最後で言うことが変わり、RTA の最初だけ懐中時計の話をする
  - ヒーローを選ぶと名前と最初の武器を言い、選ぶたびにポーズが変わる
  - タイトルで押すと 4 通りの反応
  - 絵が mycryptoheroes の navi_ain であること・通信窓の場所
- ヘッドレスの Chromium で、タイトル・モード選択（たたむ前後）・ヒーロー選択（選ぶ前・2 人）・ステージの始まり・戦闘の通信窓を、390×844・360×640・1280×800 で撮って確かめる
