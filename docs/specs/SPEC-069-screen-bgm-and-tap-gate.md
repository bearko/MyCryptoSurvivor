# SPEC-069 — 画面ごとの BGM（タイトル craft.mp3）・「タップしてはじめる」・音の鳴らし始めの見直し

- **Status**: Done
- **関連**: SPEC-017（BGM と SE）・SPEC-044（音量の設定）・SPEC-060（メニューの BGM とボタンの音。本 SPEC で一部を置き換える）

## 1. 背景

作者の依頼（2026-10-17）：

- タイトル画面やヒーロー選択画面など、各種画面で BGM がほしい
- ボタンを押したときの SE もほしい（crash.mp3 など）
- craft.mp3 をタイトル画面の BGM にしてほしい

SPEC-060 でメニューの BGM（land.mp3）とボタンの音（crash.mp3）は入れていたが、作者の手元では聞こえていなかった。調べて分かったこと：

1. **ボタンの音が小さすぎた**。crash.mp3 は元の音が小さい（平均 -30.8 dB・最大 -6.8 dB、0.71 秒）。音量 0.45 では BGM より 13 dB ほど小さく、BGM に埋もれる
2. **スマートフォン（iOS）で BGM が始まらないおそれ**があった。
   - いまは最初に指を置いた瞬間（`pointerdown`）に鳴らしている。iOS はこの瞬間を「操作」と認めない（指を離した `touchend`・`click` から認める）。
   - 止められても鳴らし直さないので、1 回目の戦闘を終えてタイトルに戻るまで無音のままになる。
   - BGM の要素を曲ごとに作り直していたので、操作の外（ワイプのあと・ジングルのあと）で曲を替えると、iOS では止められうる。
   - ヘッドレスの Chromium では再現しない（Chromium は指を置いた瞬間も操作と認める）。iOS の実機は手元にないので、上の 3 つはすべて直す
3. **タイトルでは BGM がほぼ鳴らない**。ブラウザは操作の前に音を出せず、最初の操作が「Press to Start」（= タイトルを出ていく）だから

作者の決定（同日）：

- 読み込みのあとに 1 回タップを挟む（タイトルで最初から craft.mp3 を鳴らすため）
- モード選択・ヒーロー選択は land.mp3 に切り替える

## 2. 仕様

### 2.1 画面ごとの BGM（`js/constants.js`・`js/ui-sound.js`）

| 画面 | 曲 | 音量 |
|---|---|---|
| タイトル（遊び方・ランキング・設定を開いても続く） | `Audio/SE/Actions/craft.mp3`（`BGM_TITLE`） | 0.26 |
| モード選択・ヒーロー選択 | `Audio/BGM/land.mp3`（`BGM_MENU`） | 0.26 |
| 戦闘（ステージクリアをはさんでも続く） | `Audio/BGM/pvp.mp3` | 0.32 |
| ゲームオーバー・活動レポート | ジングルのあと land.mp3（SPEC-060 のまま） | 0.26 |

- craft.mp3 は素材では SE の置き場にあるが、1 分 48 秒の曲（320 kbps・4.3 MB）。ループで流す
- 大きさは land.mp3 とほぼ同じ（-12.9 / -12.5 LUFS）なので同じ音量
- タイトルに戻るとき（モード選択の「タイトルに戻る」・メニュー・ゲームオーバー・活動レポート）は craft.mp3 に戻す
- 曲は**押した操作の中で**替える（Press to Start・タイトルに戻る。ワイプや読み込みを待ってからだと iOS で止められうる）

### 2.2 「タップしてはじめる」（`index.html`・`js/main.js`・`css/layout.css`）

- 読み込みが終わったら、まずタイトルの曲を鳴らしてみる（`waitAutoplay`）
  - **鳴らせた**（自動再生が許されている）・**鳴らさなかった**（BGM の設定が 0）→ そのままタイトルへ
  - **ブラウザに止められた**（`NotAllowedError`）→ ロゴの下の「読み込み中…」を「TAP TO CONNECT / タップしてはじめる / 🔊 音が出ます」に替える
    - 画面のどこを押しても（Enter・Space でも）よい
    - 押すとその操作の中で craft.mp3 を鳴らし、タイトルへ
- 0.6 秒待っても鳴らせたか分からない（読み込み中）ときは、鳴らせるとみなしてタイトルへ（止められたときはすぐ返ってくる）
- 「Press to Start」と並ばないよう、金のキーではなく、点滅する端末の案内にする。「音が出ます」で、電車の中などで開いた人に先に知らせる
- 演出を減らす設定では点滅しない
- マインちゃんのあいさつは、タイトルに入ってから

### 2.3 鳴らし始めの見直し（`js/audio.js`・`js/ui-sound.js`）

- BGM の要素は 1 つを使い回し、曲を替えるときは `src` だけ替える（iOS は、操作の中で鳴らした要素なら、あとから曲を替えても鳴らせる）
- ブラウザに止められた（`NotAllowedError`）ら覚えておき（`isBgmBlocked`）、次に触ったときに鳴らし直す（`retryBgm`）
  - 「触った」は `pointerup`・`touchend`・`click`・`keydown`（`GESTURE_EVENTS`）。指を置いた瞬間（`pointerdown`・`touchstart`）は入れない
- SPEC-060 の「タイトルを最初に触ったら land.mp3 を始める」は、2.2 と鳴らし直しに置き換える

### 2.4 ボタンの音

- crash.mp3 のまま（作者の指定）。音量を 0.45 → 1.0（`UI_CLICK_VOLUME`。設定の効果音の音量がかかる）
- 鳴らすボタン・鳴らさないボタンは SPEC-060 のまま。「タップしてはじめる」は鳴らさない（`data-se="off"`。曲の始まりと重ねない）

## 3. 非ゴール

- 戦闘の中の SE・戦闘の BGM は変えない
- 音を Web Audio API に移さない（iOS の消音スイッチで鳴らなくなるため。HTML の audio 要素のまま）
- 「タップしてはじめる」に設定（音量）の入口は置かない（タイトルの「設定」にある）

## 4. 受け入れ基準

- [x] 自動再生が止められる設定で開くと「タップしてはじめる」が出て、押すとタイトルで craft.mp3 が鳴る
- [x] 自動再生が許される設定・BGM が 0 の設定では、出さずにタイトルへ
- [x] Press to Start で land.mp3、モード選択の「タイトルに戻る」で craft.mp3、冒険を始めるで pvp.mp3、メニューの「タイトルに戻る」で craft.mp3
- [x] ゲームオーバー：lose.mp3 → ジングルのあと land.mp3 →「タイトルに戻る」で craft.mp3
- [x] BGM の要素は最初から最後まで 1 つ
- [x] ボタンで crash.mp3 が音量 1.0 で鳴る
