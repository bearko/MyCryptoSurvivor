# SPEC-064 — ステージごとの仕掛け：そろばんの珠・パンチカード・トロイの木馬

- **Status**: Done
- **関連**: SPEC-030（ステージ）・SPEC-053（建物・宝箱）・SPEC-063（雷鼓）

## 1. 背景

作者の依頼（2026-10-17）：ステージごとの独自ギミックがもっとほしい。作者の決定：下の 3 つを入れる（ステージ名にちなむ）。

いまのステージの違いは、背景・建物・ボス・雑魚の強さだけ。

## 2. 仕様（`js/battle/gimmicks.js`・`js/battle/gimmicks-render.js` 新規）

時間はゲームの中の時間（一時停止で止まり、懐中時計で速まる）。どれも**予告を先に見せる**（見てから避けられる）。仕掛けのダメージには、ステージと ABSOLUTE の攻撃力の倍率がかかる。被弾の間隔（0.5 秒）は体当たりと共通。

### 2.1 ステージ 1 アバカス「そろばんの珠」（`beads`）

- 0:40 から 22 秒ごと。2:30 からは 2 列ずつ（離して逆向き）
- 自分の近く（±140px）の横の線に、**矢印つきの赤い帯**で 1.4 秒予告 → 木の珠 5 つの列が 720px/s で画面を横切る（珠が通るあいだはそろばんの軸）
- 自分に当たる：20（1 列で 1 回まで）
- 敵に当たる：120 ダメージと、列から離れる向きに 70px はじく（1 列で 1 体 1 回。ボス・木馬ははじかない）。**うまく使えば味方**

### 2.2 ステージ 2 ホレリス「パンチカード」（`punch`）

- 0:30 から 9 秒ごと。2:30 からは 6 秒ごと
- 穴を 4 つ打つ。**1 つは自分の足もと**、ほかは自分のまわり 70〜230px（重ならない）。穴はパンチカードの穴のような縦長（44×64）
- 赤い点線の印が 1.2 秒かけて下から埋まり → パンチ：中にいる自分に 22、敵に 150。白く光って暗い穴が 0.9 秒残る。紙くずが散る
- 止まっていると当たるので、動き続ける理由になる

### 2.3 ステージ 3 トロイ「トロイの木馬」（`trojan`）

- 1:00・2:00・3:00 に、自分から 260〜380px の場所（建物を避ける）に木馬（素材のエクステンション 5179。128px）が現れる。「TROJAN!」と予告の音
- 9 秒で開く。上に残り秒、まわりに減っていく赤い輪。残り 3 秒で揺れて赤くなる。画面の外にいるときは、縁に赤い矢印（宝箱の金の矢印と同じ形）
- **開く前に壊す**（HP 500 × ステージの HP の倍率 × ABSOLUTE の HP の軸）：宝箱と同じ中身（回復・磁石・雷鼓。**懐中時計は出さない**＝RTA の最短時間を変えない）と CE 8 つ。「BREAK!」。撃破数には数えない
- **開く**：その時刻の雑魚の顔ぶれから、1 頭目 18 体・2 頭目 26 体・3 頭目 34 体（だんだん増える。ABSOLUTE の出現数の軸がかかる。出現の上限まで）を木馬のまわりから吐き出す。「OPEN!!」
- 木馬は動かず、触れても痛くない。武器・雷鼓・珠で壊せる

### 2.4 遊び方

- 「ステージ」に 1 行：ステージごとの仕掛け（珠・パンチ・木馬の要点）

## 3. 非ゴール

- ボス・建物・宝箱の数と時刻は変えない
- 戦闘の中のマインちゃんのセリフは変えない

## 4. 受け入れ基準

- [x] アバカス：赤い帯の予告のあと珠の列が横切り、当たった敵がダメージを受けてはじかれる
- [x] ホレリス：自分の足もとを含む 4 つの印が埋まり、パンチで中の敵と自分にダメージ
- [x] トロイ：木馬が現れて残り秒を数え、開くと群れが出る。開く前に壊すと中身が出る
