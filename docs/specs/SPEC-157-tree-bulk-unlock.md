## 2. 作者に見てほしいところ

1. 一括解放の既定はゴールドダストを**使わない**（道の到達点の素材を一括で食わないため）。 ON にすると到達点も安い順に入る。
2. 一括は**確かめずに**その場で買う（作り直すで全額戻る）。 ボタンに個数と費用を出してある。
3. 黄色い枠の色（#ffd54a）と脈打ち。 動きを減らす設定では止まる。
