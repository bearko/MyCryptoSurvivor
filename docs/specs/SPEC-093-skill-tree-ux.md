# SPEC-093 — スキルツリーの使い勝手：詰めた木・いまの効果の欄・初回の案内・画面ごとのセリフ

- **Status**: Done
- **関連**: SPEC-090（スキルツリー）・SPEC-090c（効果）・SPEC-056 / SPEC-059（マインちゃん）・SPEC-085（ボイス）

## 1. 背景

作者の依頼（2026-10-18）：

1. 節と節の距離が離れすぎていてスカスカに見える。 距離を半分くらいにして、 1 画面で見られる節を増やしたい
2. 攻撃力や頻度など数値を変える節は、 いまの値（スキルツリーで足されている分）を画面の右側に出したい
3. スキルツリーの存在に気づいてもらえるよう、 初回はマインちゃんが補足する。 入口のボタンを動かして目立たせ、 どこを押せば強化できるかが分かるようにしたい
4. 結果の画面 → スキルツリーへ移るとき、 タイトルに戻ったときのセリフ（ボイス「待ってたよ！」）が流れる。 移ったあとの画面に合わせてセリフを出し分けたい

## 2. 仕様

### 2.1 木を詰める

- 座標の比率（`skill-data.js`）：中心から 1 段目 2.6 → **1.5**、 段の間 1.7 → **0.95**、 左右のずれ 0.98 → **0.6**（1 マス 108px のまま）
  - 木の半径 832px → 約 470px（ほぼ半分）。 いちばん近い節どうしでも約 100px 離れる（節の幅 96px と重ならない）
- 節の大きさ・文字はそのまま（読みやすさを落とさない）。 根を取ったときに引く距離（`RING_R`）も比率に合わせる

### 2.2 いまの効果の欄

- 木の右に「いまの効果」の欄。 数値を変える効果だけを、 道の色の印つきで 1 行ずつ（例：`攻撃  ＋9%`・`CD  −4%`・`弾数  ＋1`）。 値は `computePerks`（= 次の挑戦で効く表と同じ）
  - 数値ではない効果（大盛り・不死鳥など）は欄の下に名前だけ並べる
  - 何も取っていなければ「まだ効果はない」
- 節を選ぶと、 その節で変わる行を光らせ、 **買ったあとの値**を並べる（`攻撃  ＋9% → ＋12%`。 まだ欄に無い行は足して出す）。 選んだ節の下の欄にも同じ 1 行を出す（狭い画面で欄を閉じていても分かる）
- 置き場所：幅 900px 以上は木の右の列（幅 220px）。 それより狭い画面は木の右上に重ねる小さな札で、 「効果」の見出しを押すと開く／閉じる（既定は閉じる。 木を隠さない）
- 欄の見出しの下に「次の挑戦から効く（RTA では切れる）」と 1 行（SPEC-090 §7）

### 2.3 初回の案内（マインちゃん）

「初回」はセーブ（`mcs.meta.v1`）から決める（新しい印は持たない）：

| 段 | 条件 | 案内 |
|---|---|---|
| ① 気づく | 1 回以上遊んだ・根を取っていない | タイトルの「スキルツリー」ボタンが脈打ち、 「NEW」の札。 結果の画面の「スキルツリーへ」も脈打つ。 タイトルではマインちゃんが「GUM が貯まったよ！『スキルツリー』で次の挑戦を楽にしよう！」（その起動中に 1 回） |
| ② 根を押す | 木を開いた・根を取っていない | 根に「ここを 2 回！」の指し示し。 マインちゃん「まんなかの金の節を 2 回押してね。ここから始まるよ！」 |
| ③ 最初の 1 つ | 根を取った・ほかの節を 1 つも取っていない | 買える節（いちばん安いもの）に同じ指し示し。 マインちゃん「緑に光る節が強化できる節だよ。2 回押すと GUM で解放！」。 買える節が無ければ「GUM が足りないみたい。挑戦して貯めてこよう！」 |
| ④ できた | ③ のあと最初の節を買った | マインちゃん「やったね！ 効果は右の欄に出るよ。次の挑戦から効く！」（1 回） |

- 段はいつもセーブの状態から決める。 作り直して節が 0 に戻れば ③ がまた出る（迷っている人には、 いつでも同じ案内が出る）
- 案内のセリフにはまだボイスが無い（録音を足すときは `tools/voice/build.mjs` の `ORDER` に足す）

### 2.4 画面ごとのセリフ

- 結果の画面の「スキルツリーへ」は、 タイトルに戻すときにタイトルのセリフを言わせない（`returnToTitle({ navi: false })`）。 木を開いたら木のセリフ
- 木を開いたときのセリフ（案内の段でないとき）：買える節があれば「解放できる節が光ってるよ！」、 無ければ「挑戦で GUM を貯めて、また来てね。」。 しばらくで引っこむ
- 木を閉じてタイトルに戻ったら、 タイトルのセリフ（いままでの反応のセリフ）
- 木の中のマインちゃんは、 木の左上の小窓（戦闘の通信窓と同じ形）。 木を隠しすぎない

## 3. 非ゴール

- 節の費用・効果・数は変えない（SPEC-090d の釣り合いのまま）
- 案内のボイスの録音
