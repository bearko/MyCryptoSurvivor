# SPEC-110 — 固有スキルの強化（ショップの常設の札）

- **Status**: Done（SPEC-109 と同じく `?shop=1` のときだけ）
- **関連**: SPEC-103 5 章（設計）・SPEC-100（固有スキル）・SPEC-109（ショップ）

## 1. 何をするか

ショップに **固有スキルの強化** の札を常に置く（広い画面は品の右、狭い画面は品の上）。

- 札：ヒーローの顔・固有スキルの名前（MCH のパッシブスキル名）・`Lv n / 5`・次の段で伸びるもの（いま → 次）・値段のボタン
- 段：Lv.1（はじめから）〜 Lv.5。値段は Lv.2 40 → Lv.3 70 → Lv.4 110 → Lv.5 160（ステージの倍率・ギフト券は効かない）
- **挑戦のあいだ、ステージ 1〜3 をまたいで残る**（`state.shop.sigLevel`）。ゲームオーバー・再走・タイトルに戻るで Lv.1。メニューの「ステージをはじめからやり直す」では、そのステージに入ったときの段に戻す（SPEC-109 の財布と同じ控え）
- **Lv.1 はいまの数値とまったく同じ**。ショップでないとき（レベルアップで遊ぶとき）は Lv.1 のまま
