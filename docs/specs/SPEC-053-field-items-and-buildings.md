# SPEC-053 — ステージの建物・壺・宝箱とお助けアイテム

- **Status**: Done
- **関連**:
  - SPEC-007（ジェム）・SPEC-012（武器）・SPEC-022・SPEC-030（ステージ・ボス）
  - SPEC-033（マジックカード）
  - SPEC-054（RTA の懐中時計。宝箱から出す）

## 1. 背景（作者の要望 2026-10-17）

- フィールドに落ちている CE（経験値のジェム）を一括で集めるお助けアイテムがほしい
- HP を回復するお助けアイテムがほしい
- ステージに障害物（建物）・宝箱・壺を置き、壺や宝箱を割るとお助けアイテムが出るようにしたい

## 2. 仕様

### 2.1 建物（作者の決定：自分・敵・弾すべて止まる）

- ステージごとに 4 つ、決まった場所に置く（`STAGE_TABLE[].obstacles`）
  - ステージ 1：持ち運びハウス（3182）× 4
  - ステージ 2：お城（5182）× 1 ＋ 持ち運びハウス × 3
  - ステージ 3：お城 × 4
- 当たりは絵の大きさの 8 割の四角。ヒーローの出発点 (0, 0) のまわり 150px には置かない
- 何が止まるか：

| もの | 建物で |
|---|---|
| 自分 | 押し戻される（通れない） |
| 敵・ボス | 押し戻され、壁に沿ってプレイヤーのほうへ回りこむ |
| 弾（リボルバー・手裏剣・ナイフ・斧・パンジャンドラムなど）・ボスの弾 | 消える |
| レーザー | 建物の手前で止まる（その先の敵には当たらない） |
| モアイ（頭上から落ちる）・周回する武器（本・剣）・爆発（ピエロ）・衝撃波 | 止まらない（宙・まわりを回る・その場で起きるため） |

### 2.2 壺と宝箱

壺と宝箱は `state.battle.enemies` に `isProp` で入れる。こうすると **どの武器でも壊せる**。

- 動かず、ぶつかってもダメージはない
- 撃破数・経験値・ボスの判定には数えない
- 武器はまず敵を狙い、射程の中に敵がいないときだけ壺・宝箱を狙う（モアイも同じ）

| | 壺（ぴっぴ教 一攫千金壺 4600） | 宝箱（金色） |
|---|---|---|
| 出る | ステージの始めに 4 つ。そのあとゲーム内の 20 秒ごとに 1 つ（場に 6 つまで） | **1 ステージ 4 つ**。ゲーム内の 0:30・1:30・2:30・3:30 |
| 場所 | プレイヤーから 200〜700px、建物から離れたところ | プレイヤーから 220〜420px |
| 体力 | 1（1 発で割れる） | 60 × ステージの敵 HP 倍率（60 / 90 / 120） |
| 出るもの | CE の小山（ジェム 5 個）55% ／ パンケーキ 30% ／ 棒磁石 15% | パンケーキ 50% ／ 棒磁石 50%（＋ ジェム 6 個） |

- 宝箱は光らせる。画面の外にあるときは、画面の縁に金色の矢印を出す
- 宝箱の形は mycryptoheroes の `Data/Effects/GoldChest/treasure-chest.svg`（CC0）。塗りが `currentColor`（黒）なので、同じ形を canvas の `Path2D` で金色に塗る
- ジェムの値はステージの経験値倍率（1 / 2 / 3）
- 時刻はステージのゲーム内時間（`stageElapsedMs`）で数える。一時停止・レベルアップの選択中は進まない
- 宝箱の数と時刻は、共通基盤の RTA の最短時間（SPEC-054・SPEC-001 6.15）の根拠なので、変えるときは共通基盤も直す

### 2.3 お助けアイテム

| アイテム | 絵 | 効果 |
|---|---|---|
| 棒磁石 | 1156 | 拾った時点で落ちているジェムを **すべて** プレイヤーへ吸い寄せる（毎秒 900px で飛んでくる） |
| パンケーキ | 1129 | HP を最大 HP の 30% 回復（緑の数字で「+N」） |

- 拾える距離は 30px（ギョクの吸引の倍率が効く）
- 消えない（ステージが終わると片付ける）
- 「お手軽カップラーメン」は強化（HP の自然回復）の絵なので、回復のアイテムにはパンケーキを使う

### 2.4 遊び方

遊び方（SPEC-042）の「強くなる」に 2 行足す（壺・宝箱・アイテム、建物）。

## 3. 影響

- **活動レポートのスコア**：アイテムでレベルが上がりやすく、倒れにくくなる。自動プレイ（共通基盤の `tools/e2e/survivor-autoplay.mjs` に壺・宝箱を拾う動きを足したもの）の全クリアは 162,684・164,899 で、今の係数の根拠（150,000 の ±1 割、実測 147,663〜162,500）の範囲。係数は直さない
- **RTA**：建物で道がふさがるので、少しだけ遅くなりうる。最短時間（ボスは 4 分）は変わらない

## 4. 受け入れ基準

- [x] 各ステージに建物が 4 つあり、自分・敵が通れない。弾は建物で消え、レーザーは建物の手前で止まる
- [x] 壺はステージの始めに 4 つあり、1 発で割れる。宝箱はゲーム内の 0:30・1:30・2:30・3:30 に出て、何発かで開く
- [x] 壺・宝箱を壊しても撃破数は増えない
- [x] 棒磁石を拾うと、落ちているジェムがすべて飛んでくる。パンケーキで HP が回復する
- [x] 画面の外の宝箱の向きが、画面の縁の矢印で分かる
- [x] コンソールにエラーが出ない（自動プレイ 3 回）

## 5. テスト

  - レーザーの長さ・ドロップの抽選
