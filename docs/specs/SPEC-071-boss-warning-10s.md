# SPEC-071 — ボスの予告を 10 秒前に・RTA ではカウントダウンを右端に

- **Status**: Done
- **関連**: SPEC-045（ボスの予告）・SPEC-061（カウントダウン）・SPEC-040（RTA）

## 1. 背景

作者の依頼（2026-10-17）：

- ボスの予告は 10 秒前でよい。30 秒前は長すぎる
- RTA 中は、予告のカウントダウンが（共通基盤の）RTA の時計と重なる。カウントダウンを右端にずらしたい

RTA の時計は共通基盤の SDK が画面の上の真ん中に出す（HUD の下）。ボスの予告は、大きく出たあと上の真ん中の小さな帯にたたむので、その位置が重なっていた。

## 2. 仕様

### 2.1 予告の時刻（`js/constants.js`）

- `BOSS_WARNING_LEAD_MS`：30000 → **10000**。予告は 3:50（ボスは 4:00 のまま）
- 予告の帯の流れは SPEC-061 のまま：大きく 3.2 秒 → 上の小さな帯にたたんで残りを数える → 最後の 5 秒は真ん中に大きな数字

### 2.2 RTA のときの小さな帯（`js/battle/fx.js`・`css/battle-ui.css`）

- RTA のときは、帯に `boss-banner--rta` を付ける
- たたんだ帯は**右端**に置く。「ボス接近」と残りの秒を縦に積み、細くする（WARNING の印は出さない）
- 390 幅で x 313〜382。RTA の時計（x 135〜255）と重ならない
- RTA でないときは、いままでどおり上の真ん中

## 3. 非ゴール

- ボスの出る時刻（4:00）・ステージの長さは変えない。総合スコア・RTA の最短時間にも関わらない
- 共通基盤の RTA の時計の位置は変えない

## 4. 受け入れ基準

- [x] ボスの 10 秒前に予告が出て、0:10 から数える
- [x] RTA のとき、たたんだ帯が右端に出て、RTA の時計と重ならない
- [x] RTA でないとき、たたんだ帯は上の真ん中のまま

## 5. テスト

- `node --test tests/boss-countdown.test.mjs`
  - 10 秒前であること・0:10 → 0:01 の数え方
  - 予告の帯の長さが 10 秒に収まること
  - RTA の帯の CSS（右端・縦積み）と、RTA のときに付く印
- ヘッドレス Chromium（390×844）で、3:49 から 4:00 まで 0.5 秒ごとに帯の位置を記録した
  - RTA の時計は、共通基盤の SDK と同じ見た目の時計を置いて確かめた
  - RTA：小さな帯は x 313〜382、時計は x 135〜255
  - RTA でない：小さな帯は x 93〜297（真ん中）
  - ページのエラーなし
