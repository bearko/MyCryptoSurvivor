# SPEC-149 — EASY の釣り合い直し（敵 1/3・ステージ 1 は動かなくても負けない・ステージ 2 は動かないと負ける）、 レッスンのボイスの中断、 クリアの紙吹雪

- **Status**: Done
- **関連**: SPEC-147（EASY）・SPEC-085（マインちゃんのボイス）・SPEC-058（結果の画面）

## 1. 作者の依頼（2026-10-21）

1. EASY の敵の数は **1/3** でよさそう。 極端な話、 **ステージ 1 は動かなくても負けない**くらい、 **ステージ 2 は動かないと負ける**くらいにしたい。
2. マインちゃんの説明の途中でボスを倒した場合、 **ボイスを中断してクリア演出の SE を流す**。
3. クリアしたときは**紙吹雪**を出す。 実装は `bearko/mycryptoheroes` の `Data/Effects/GoldChest/confetti.js`（マイクリの金宝箱の演出から抜き出したもの）。

## 2. EASY の釣り合い（`js/easy.js` の `EASY_STAGES`）

| | 湧きの間隔 | 雑魚 HP / 攻撃 | ボス HP / 被ダメ | ねらい |
|---|---|---|---|---|
| ステージ 1 | 320 → **960 ms**（1/3） | **0.5 / 0.25** | **0.003 / 0.25** | **動かなくても倒れない**（自動攻撃だけで 15 秒＋ボス。 最初の値 0.7 / 0.5・0.005 / 0.4 では、 動かないとボスが出た直後に倒れた） |
| ステージ 2 | 380 → **1140 ms**（1/3） | 1.0 / **1.2** | 0.008 / 0.4 | **動かないと倒れる**。 逃げれば（受けるダメージ ×0.15 の自動プレイで）勝てる |
| ステージ 3 | 380 → **570 ms**（1/2） | 1.6 / **2.2** | **0.016 / 0.7** | 根を取るまでは倒れる（SPEC-147 の筋）。 1/3 にすると根なしでも通ってしまったので、 ここだけ 1/2 にして敵を少し重くした |

- 確かめ方は §5（動かない自動プレイと、 逃げる自動プレイ）。
- 1/3 にしても「敵を倒すと CE が落ちる」「光ってる敵」のレッスンは出る（レアとミッションは時刻で必ず出る）。

## 3. レッスンのボイスの中断（`js/lesson.js` + `js/battle/stage-transition.js`）

- レッスンの「つぎへ」を押しても、 ボイスは最後まで鳴っていた。 その直後にボスを倒すと、 クリアのテロップと SE の上にマインちゃんの声が重なる。
- **ステージの終わり（`triggerStageEndOrTransition` と `triggerActivityReport`）で `stopVoice()` を呼ぶ**。 クリアの SE（`win.mp3`）はそのあとに鳴る。
- 「つぎへ」で閉じたときのボイスは止めない（= 読み上げを聞きながら戦える。 作者の依頼は「ボスを倒したとき」に限る）。

## 4. 紙吹雪（`js/confetti.js`）

- `Data/Effects/GoldChest/confetti.js` を ES Module に写した。 **粒子数 120・速さ 2・12 色の固定パレット・15 ms 間隔**はマイクリのクライアント JS から抜き出した値のまま。 線を傾けながら落とす描き方も同じ。
- 出す場所: **ステージクリア（S-30 の戦果の画面）と全クリア（活動レポート）**。 テロップが終わって結果が出るときに始め、 **3.5 秒**で降らせるのをやめ、 残りは画面の下へ抜ける。 画面を閉じたら消す（`removeConfetti`）。
- 画面の一番上（`z-index: var(--z-help) + 2`）の固定 canvas。 `pointer-events: none` なのでボタンは押せる。
- `prefers-reduced-motion` のときは出さない。 ゲームオーバーでは出さない。

## 5. 確かめ方

- `node --test tests/easy.test.mjs tests/confetti.test.mjs`
- 自動プレイ `tools/autoplay/easy.mjs`（逃げる・受けるダメージ ×0.15）: ステージ 1 → 2 を通り、 ステージ 3 で倒れ、 根を取って復活 1 回でクリア（SPEC-147 の筋のまま）。 実測:

```
ステージ 3 も 1/3 (1140 ms・1.8・0.012/0.5)   根なしで S1 21s → S2 45s → S3 もクリア (= 負ける設計が崩れた)
ステージ 3 は 1/2 (570 ms・2.2・0.016/0.7)    根なしで S1 23s (HP 62/67) → S2 45s (HP 27/67) → S3 で倒れる (51s・GUM 341)
                                              → 根＋7 節 → 復活 1 回で S1 22s (113/116) → S2 42s (93/116) → S3 クリア
```
- **動かない自動プレイ**（`MOVE=0`・受けるダメージそのまま ×1.0・根なし HP 67）:

```
最初の値 (雑魚 0.7 / 0.5・ボス 0.005 / 0.4)   ステージ 1 で倒れる (16 秒。 ボスが出た直後)
採用した値 (雑魚 0.5 / 0.25・ボス 0.003 / 0.25) ステージ 1 クリア (16 秒・HP 29/67 残り) → ステージ 2 で倒れる (10 秒)
```
