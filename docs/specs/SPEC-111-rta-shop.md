# SPEC-111 — RTA でもショップ

- **Status**: Done
- **関連**: SPEC-103（ロードマップ）・SPEC-109 / 117（ショップ）・SPEC-112（ミッション）・SPEC-082（RTA v4）

## 1. 作者の決定（2026-10-20）

「RTA でも、私以外まだ遊んでいないので実装して OK」

## 2. 変えたこと

- **RTA でもショップ**（レベルアップではなく、CE で品を買う）。ミッションも出る
- **レギュレーションの版は分けない**（`survivor-normal-v4` / `survivor-absolute-2x-v4` のまま）。v4 の記録は作者のものだけなので、混ざっても困らない
- RTA で変わらないもの：スキルツリーの効果は切れる（先手の CE・引き直し・見送りの礼なども効かない）・宝箱から懐中時計が出る（2 倍速のあいだは店も早く来る）
- RTA の時間は実時間（ゲーム内時間も別に送る）。店とミッションを選んでいる時間も実時間には入る（メニューの操作も含めて計るふつうの RTA と同じ）
- 総合スコアの係数（SPEC-082 の balance 3・係数 560）は据え置き。レベルは「1 ＋ 買った品の数」なので、活動レポートのスコアはおおむね同じ幅に収まる。ずれが大きければ共通基盤の SPEC-002 で見直す
- 遊び方（ヘルプ）の「RTA ではレベルアップ」の添え書きを外した

## 3. 確かめたこと

- `node --test tests/*.test.mjs`：すべて通る（RTA で `state.shop` を外さないこと）
- ブラウザ（RTA で始めた状態）：ショップが 0:10 に開く・ミッションが有効・スキルツリーの効果は切れたまま・コンソールエラーなし
