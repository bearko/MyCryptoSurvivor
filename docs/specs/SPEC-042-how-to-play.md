# SPEC-042 — 遊び方：ヘルプの書き直しと、はじめての操作ガイド

- **Status**: Done
- **Issue**: #53（親 #51 v1.0 仕上げ）
- **関連**: SPEC-005（アクションへの転換）、SPEC-034（メニュー）、SPEC-037（モード）

## 1. 背景 / 課題

- ヘルプ（ヘッダーの ?）が旧テーマのまま：「雪山サバイバル + リソース管理」「ホーム画面で待機している間のみ時間が進行」。今のゲームの説明が 1 行もない
- タイトル画面から遊び方を見る手段がない（ヘルプは戦闘中のヘッダーにしかない）
- 初めての人は、戦闘が始まった瞬間に「何をすればいいか」（移動だけ・攻撃は自動）が分からない

## 2. ゴール

- ヘルプが今のルール（操作・流れ・強くなり方・モード）を ja/en で説明している
- タイトル画面からも開ける
- 初めての 1 戦目だけ、戦闘の上に短い操作ガイドが出て、**遊びを止めずに** 消える

## 3. 非ゴール

- 指差しで 1 手ずつ進めるチュートリアル（操作が移動だけなので要らない）
- レベルアップ画面・モード選択の説明（カードに説明があるため）

## 4. ユーザー体験

### 4.1 ヘルプ

```
┌──────────────────────── ✕ ┐
│ 遊び方                       │
│ 🕹 操作                      │
│  ・移動：画面をドラッグ（指の下にスティック）／WASD・矢印キー │
│  ・攻撃：自動。武器は近くの敵を勝手に狙う │
│ ⏱ ステージ                   │
│  ・4 分でボスが出る。倒すか 5 分耐えるとクリア │
│  ・全 3 ステージ。Lv は引き継ぎ、武器は選び直し │
│ ⬆ 強くなる                   │
│  ・敵が落とすジェムで Lv アップ → 武器か強化を 1 つ │
│  ・同じものを選ぶと段階が上がる。リロールは 1 ステージ 3 回 │
│  ・光るカードを拾うとその場で Lv アップ │
│ 🏆 モード                    │
│  ・NORMAL／ABSOLUTE（難易度を自分で、スコアに倍率）／RTA │
│            [ 閉じる ]        │
└────────────────────────────┘
```

- ヘッダーの ? と、タイトル画面の「遊び方」から開く
- 開いている間は戦闘を止める（今と同じ `pauseTime`）。閉じ方は ✕・閉じる・背景・Esc
- タイトル画面の上にも出る（重なり順を上げる）

### 4.2 はじめての操作ガイド（コーチ）

- 条件：**ステージ 1 の開始** で、まだ一度もガイドを見終えていない（`mcs.coachSeen` がない）
- 戦闘の上に、半透明の帯を 1 つ出す。触れても操作の邪魔をしない（`pointer-events: none`）
  1. 「ドラッグで移動（PC は WASD）／攻撃は自動」と、指が左右に動く絵
  2. 動いた合計が 0.6 秒を超える か、戦闘が 8 秒進んだら、次へ
  3. 「敵が落とすジェムを拾うと Lv アップ」を 4 秒（戦闘の時間で）出して消える
- 消えたら `mcs.coachSeen = 1` を保存。2 回目からは出ない
- 一時停止中（メニュー・レベルアップ・ヘルプ）は数えない
- reduced-motion では指の絵を動かさない

## 5. 技術設計

### 5.1 データ

| 置き場所 | 中身 |
|---|---|
| `localStorage["mcs.coachSeen"]` | `"1"` なら出さない |
| `state.battle.coach` | `{ step: 0|1|2, movedMs, stepMs }`（ステージ 1 の開始で作る。出さないときは `null`） |

### 5.2 関数（`js/battle/coach.js`）

| 関数 | 役割 |
|---|---|
| `nextCoach(coach, dtMs, moving)` | 純関数。経過と移動から次の状態を返す（`step` が 2 を過ぎたら `null` ＝ 終わり） |
| `startCoachIfFirst()` | 条件を満たせば `state.battle.coach` を作り、帯を出す |
| `tickCoach(dt, moving)` | ループから呼ぶ。`nextCoach` で進め、帯の文言を変える／消して保存する |

定数：`COACH_MOVE_MS = 600`、`COACH_STEP1_MAX_MS = 8000`、`COACH_STEP2_MS = 4000`。

### 5.3 i18n

`help.*`（見出し 4 つ・本文 9 行・`help.open`）、`coach.move`、`coach.gems` を ja/en で足す。旧 `help.body` / `help.timeNote` は消す。

## 6. 受け入れ基準

- [x] ヘルプに旧テーマの文言が残っていない（ja/en）
- [x] タイトル画面の「遊び方」で、タイトルの上にヘルプが出る
- [x] 戦闘中のヘルプは時間が止まり、✕・閉じる・背景・Esc で閉じる
- [x] 初回のステージ 1 で操作ガイドが出て、動くと 2 段目に進み、消える。リロードしても 2 回目は出ない
- [x] ガイドが出ていても、スティックの操作・タップが効く
