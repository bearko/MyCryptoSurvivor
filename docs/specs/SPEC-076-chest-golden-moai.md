# SPEC-076 — 宝箱の絵を財宝ゴールデンモアイに

- **Status**: Done
- **関連**: SPEC-074（宝箱の絵をエクステンションに）

## 1. 背景

作者の指定（2026-10-17）：宝箱にはゴールデンモアイを当てたい。

SPEC-074 では 1165 オルゴール（木の箱）にしていた。

## 2. 仕様（`js/constants.js`・`js/battle/render.js`）

- 宝箱の絵を **5106 財宝ゴールデンモアイ**（`CHEST_EXT_ID`）にする
- 絵は壺と同じく枠いっぱいなので、SPEC-074 の 1.3 倍はやめて 1.0 倍で描く（当たりの円にそろう）
- 宝箱の後ろの金の光の円・HP の帯・画面の縁の矢印・絵を読み込むまでの金の宝箱の形は、いままでどおり
- **重なり**：モアイの武器の 5 段目（クリプトモアイ）の弾も、この絵で頭上から落ちてくる。宝箱は止まっていて光の円と HP の帯があり、弾は落ちてすぐ消えるので、見分けられるとした

## 3. 非ゴール

- 名前（宝箱）・中身・出る時刻・固さは変えない

## 4. 受け入れ基準

- [x] 宝箱がゴールデンモアイの絵で出る
- [x] 武器・強化の 1 段目の絵とは重ならない（重なるのはモアイの 5 段目の弾だけ）

## 5. テスト

- `node --test tests/prop-art.test.mjs`：宝箱は 5106。壺・アイテム・木馬とは別の絵。武器・強化の 1 段目とは重ならず、重なるのはモアイの 5 段目だけ
- ヘッドレス Chromium（390×844）：ステージ 1 の 0:30 に出た宝箱を自分の近くに寄せて撮った（壺と並べて大きさを確かめた）。ページのエラーなし
