# SPEC-059 — マインちゃんの通信の帯：モード選択とヒーロー選択に専用の表示エリア

- **Status**: Done
- **関連**:
  - SPEC-056（ナビとキャラクターの重なり）・SPEC-055（ノード端末）
  - DESIGN_CHARTER 14.4（この SPEC で改訂）

## 1. 背景

作者の指摘（2026-10-17）：

- モード選択とヒーロー選択で、マインちゃんがほかの UI と重なりがち。顔のアイコンとメッセージを出す**専用のエリア**を設けて独立させたい
- ヒーロー選択の大きなヒーローの絵は、ヒーローをかっこよく見せる**見せ場**。そこにマインちゃんを重ねたくない
- 案内役の名前は「マインちゃん」（いままでの「アイン」から直す）

SPEC-056 では、モード選択は右下に全身（言い終えて 3.5 秒で吹き出しをたたむ）、ヒーロー選択は大きな絵の左上に通信窓を置いていた。どちらも「たたむ」「小さくする」で重なりを減らしていただけで、重なりそのものは残っていた。

## 2. 仕様

### 2.1 通信の帯（`js/navi.js`・`css/chars.css`）

- 置き場所 `mode`・`hero` を**通信の帯**にする（`NAVI_DOCK_PLACES`）。`battle` はいままでどおり通信窓（`NAVI_COMM_PLACES`）、`title` は全身
- 帯：画面の下に固定（左右 8px・最大 560px・高さ 88px）。角を切った筐体で、縁はシアン → 金
  - 左：顔のアイコン（72×72。96×128 の絵の (34, 25) から 36×36 を 2 倍で）。喋ると口が動き、待っていると瞬きする
  - 右：`NAVI // MINE` の小見出しと、セリフ（1 文字ずつ。最大 3 行）。押すと次のセリフへ
  - 帯の大きさは決まっているので、セリフに合わせて伸び縮みさせない（測らない）
- 帯は下からせり上がる（420ms）。モード選択とヒーロー選択の行き来では出し直さず、続けて喋る（ページをめくる動き）
- 動きを減らすときは、せり上がる動きを止める

### 2.2 画面のほうが帯のぶんを空ける

- モード選択：下に帯の高さ＋16px を空ける。中身が収まらないときは画面がスクロールする（いままでは下が切れていた）
- ヒーロー選択：下に帯の高さ＋16px を空け、カードはその上に収まる
  - カードの中身は縮めない（大きなヒーローの絵が潰れない）。はみ出すぶんはカードの中でスクロールし、「冒険を始める」はカードの下に貼りつく
- 縦が 700px 以下の画面：帯を 66px に細くする（顔 52px・2 行）
- 横が 1200px 以上の画面：帯をカードの左下の空きに置き（幅 `min(340px, 50vw - 300px)`）、ヒーロー選択のカードは縦いっぱいに使う。帯の右端はカードの左端に届かない

### 2.3 名前

- 自己紹介を「ナビのマインちゃんだよ」（英語は Mine）に。コード・CSS のコメント、SPEC-055〜058、憲章の「アイン」も「マインちゃん」に直す
- 絵のファイル名（`navi_ain_*.png`）は素材のものなので、そのまま

### 2.4 憲章の改訂（`docs/charters/DESIGN_CHARTER.md` 14.4）

- 操作する画面（モード選択・ヒーロー選択）では、案内役は画面の下の専用の帯に出し、ボタン・カードと重ねない。画面のほうが帯の高さぶんを空ける
- ヒーローの見せ場（ヒーロー選択の大きな絵）には、案内役も吹き出しも重ねない

## 3. 非ゴール

- タイトル（全身でのぞきこむ）・戦闘（通信窓）・結果のテロップの置き方は変えない
- セリフの中身は変えない（名前だけ）

## 4. 受け入れ基準

- [x] モード選択・ヒーロー選択で、マインちゃんの顔とセリフが画面の下の帯に出て、カード・ボタン・タイルと重ならない
- [x] ヒーロー選択の大きなヒーローの絵の中に、マインちゃんがいない
- [x] 390×844・360×640・1280×720 で、ヒーローの絵が潰れない。「冒険を始める」がいつも見える
- [x] 自己紹介が「ナビのマインちゃんだよ」になる

## 5. テスト

- `tests/navi.test.mjs`：帯の置き場所はモード選択とヒーロー選択、通信窓は戦闘だけで重複しない。帯に出るセリフは 3 行に収まる長さ（長い名前と武器名を入れても 45 文字以内）
- ヘッドレスの Chromium で、タイトル・モード選択・ヒーロー選択（選ぶ前・選んだあと）を 390×844・360×640・1280×720 で撮り、帯の上端がカードの下端より下にあること、マインちゃんがヒーローの絵の中にいないことを確かめた
