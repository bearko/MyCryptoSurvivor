# SPEC-057 — 戦闘の UI と演出：HUD・配られるカード・ボスのカットイン・数字と拾得・背景の彩度

- **Status**: Done
- **関連**:
  - SPEC-055（デザイン言語「ノード端末」）・SPEC-056（ナビのアインと重なり）
  - SPEC-044（演出を減らす）・SPEC-053（建物・壺・宝箱・アイテム）・SPEC-054（懐中時計）
  - DESIGN_CHARTER 14 章（色の優先度・生きている UI）
- **シリーズ**：UI の見直し（作者の依頼 2026-10-17「HoyoVerse のゲームと同等まで」）の 3 本目。続きは SPEC-058（結果とメニュー）

## 1. 背景

SPEC-055・056 でモーダルとホームは「ノード端末」になったが、遊んでいる時間のほとんどを占める戦闘の画面は v1.0 のまま。

| ゼンゼロの考え方 | 戦闘での読み替え |
|---|---|
| 色の優先度（UI をいちばん鮮やかに） | 戦場の背景の彩度を落とし、HUD・カード・帯を鮮やかに |
| UI を死なせない | HUD の帯を光が流れ、XP のバーに光が走る |
| リアクション・テロップとキャラの重なり | ボスが出た瞬間に斜めの帯のカットインと、アインの一言 |
| ページめくりの快感 | レベルアップのカードが 1 枚ずつめくれて配られる |
| 手ざわり（押した・当たった） | 大きいダメージほど数字が大きく弾む。拾ったときに粒が散り、何を拾ったかが文字で出る |

## 2. 仕様

### 2.1 HUD（`css/battle-ui.css` 新規・`index.html`・`js/survival.js`）

- ヘッダーと HUD の面を端末の帯（走査線・下に金とシアンの線）に。HUD の面を 7 秒ごとに光が流れる
- レベルは金の角を切った札
- HP・XP のバーは角を切った形。HP は **10 マスに区切る**（1 マス = 最大 HP の 10%）
- **HP の残像**：減ったぶんを白い帯が 260ms 遅れて 520ms で追う（`hud__bar-ghost`。`renderHud` が幅を HP と同じにし、CSS の transition で遅らせる）
- **HP が 30% 以下**でバーが赤く脈打つ（`hud__bar--low`）
- XP のバーに 2.4 秒ごとに光が走る

### 2.2 レベルアップのカード（`css/battle-ui.css`・`js/battle/levelup.js`）

- カードを角を切った筐体に。縁の色は種類で分ける（武器 = イフリートの赤、強化 = ガルーダの緑）。左上の角に種類の色、右下にシアン。触れると光が横切る
- **配る**：開いたとき（引き直しのときも）カードが 1 枚ずつ、90ms ずつずれて裏からめくれて出る（560ms）。見出しは大きく打ちつける
- **選ぶ**：選んだカードが光って前に出て、ほかは沈む。**240ms（`PICK_FX_MS`）** 見せてから確定する。その間はもう押せない（二度押しで 2 枚取らない）
- 動きを減らすときは、配る動きを止め、選ぶとすぐ確定する

### 2.3 ボス（`css/battle-ui.css`・`js/battle/fx.js`・`index.html`）

- 予告の帯を、上下に警告色（黄と黒）の縞が入った赤い帯に
- **カットイン**：ボスが出た瞬間、斜めの帯が右から入って左へ抜ける（1.9 秒）。帯にはボスの絵（256px）・英字の小見出し `BOSS // NODE GUARDIAN`・ボスの名前。MCH の `passive_skill_cutin` の写し（斜めの帯・光が走る・大きいドット絵）
- 同時に、ナビのアインが通信の窓で一言（「ボスです！」の場面 `navi.boss`。腕組み）
- 時間は止めない（ボスはもう出ているので、帯は押せない飾り。`pointer-events: none`）
- 動きを減らすときはカットインを出さない（予告の帯と名前は今までどおり）

### 2.4 数字と拾得（`js/battle/damage.js`・`js/battle/render.js`・`js/battle/field.js`・`js/battle/fx.js`）

- ダメージの数字に 3 つの大きさ：ふつう 14px、**40 以上で 18px**（淡い金）、**100 以上で 24px**（金）
- 出た瞬間に 1.6 倍から 140ms で元の大きさへ弾む（`damagePopScale`）
- 拾ったとき・割ったときに粒が散る（`fxBurst`）
  - 宝箱を開けた：金の粒と「OPEN!」
  - 壺を割った：土色の粒
  - HP 回復：「+回復量」を大きく、緑の粒
  - 磁石：「MAGNET!」
  - 懐中時計：「×2 SPEED!」

### 2.5 背景の彩度（`js/battle/render.js`）

- 戦場の背景（写真）を描いたあと、彩度の合成（`saturation`・灰色・不透明度 **0.45**＝`BG_DESATURATE`）で彩度を落とす。敵・弾・UI はその上に描くので鮮やかなまま
- 憲章 14 章「色の優先度」の実装

## 3. 非ゴール

- 敵や弾の絵・当たり判定・数値は変えない（見た目だけ）
- ゲーム内の時間には触らない（カードを選んだあとの 240ms は、レベルアップの画面が開いて時間が止まっている間）
- 結果の画面・メニュー・設定の中身（SPEC-058）

## 4. 受け入れ基準

- [x] HP が 10 マスに区切られ、減ると白い残像が遅れて追う。30% 以下で脈打つ
- [x] レベルアップのカードが 1 枚ずつめくれて出る。選ぶと光ってから閉じ、二度押しで 2 枚取らない
- [x] ボスが出ると、斜めの帯にボスの絵と名前が出て、アインが一言言う
- [x] 大きいダメージほど数字が大きい。拾ったときに粒と文字が出る
- [x] 戦場の背景が少しくすみ、敵と UI が浮いて見える
- [x] 「演出を減らす」で、配る動き・カットイン・残像・脈打ちが止まる
- [x] 通しの自動プレイ（3 ステージ・ふつう）でコンソールにエラーがない

- `tests/navi.test.mjs`：場面に `boss` を足した（すべての場面に ja・en の文がある）
- ヘッドレスの Chromium（時計の早回し）で、レベルアップを配る途中・選んだ瞬間、ボスの予告・カットイン、HP の残像を撮って確かめた
