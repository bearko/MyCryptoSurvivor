# SPEC-138 — シャドー武田信玄のミッション「風林火山」

- **Status**: Done
- **関連**: SPEC-112（ミッション）・SPEC-137（★の難易度）

## 1. 作者の依頼（2026-10-21）

シャドー武田信玄もミッションを与えるヒーローに。 風林火山になぞらえて
（風：敵のスピードアップ・林：BGM/SE がなくなる・火：敵の数が増える・山：移動ができなくなる）、
★1 が風林・★2 が風林火・★3 が風林火山と対象を広げる。

作者の決定：対象は **すべて同時に** 最後まで効く。

## 2. 中身

| ★ | 秒 | 効き目 |
|---|---|---|
| ★1 | 30 | 風（敵の足 ×1.4）・林（BGM と効果音が消える） |
| ★2 | 30 | ＋火（敵の湧き ×3） |
| ★3 | 20 | ＋山（その場から動けない） |

- 絵はゴースト・武田信玄（`Image/Enemies/519.png`）。 力添えは「無敵」（動かざること山の如し）。
- 林：BGM は止めずに音だけ消し（`setMissionSilence`）、 終われば続きから鳴る。 効果音も鳴らさない。 達成・失敗・タイトルに戻る・ステージの始まりで戻す（達成の音は戻してから鳴らす）。
- 山：入力を 0 にする（`canMove()`。 `player.js`）。

## 3. 確かめたこと

- `node --test tests/*.test.mjs`：331 件すべて通過（★ごとの対象・つなぎ）。
- ブラウザ（390×844）：★3 で受けると矢印キーで動かない・音が消えている、 達成で音が戻りごほうびの画面が出る、 エラーなし。
