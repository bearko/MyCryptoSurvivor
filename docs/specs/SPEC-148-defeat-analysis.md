# SPEC-148 — 負けた理由の分析（被ダメの内訳・DPS・前回との比較・マインちゃんのおすすめ）

- **Status**: Draft（作者の確認待ち）
- **関連**: SPEC-116（倒れたらスキルツリーへ）・SPEC-136（GUM の内訳）・SPEC-146（もう一度挑む）

## 1. 作者の依頼（2026-10-21）

負けても「敵の物量に押された」としか分からず、 スキルツリーでどのパネルを取れば打開できるか想像しにくい。 被ダメだけでなく DPS なども見られるようにし、 前回の敗北との比較も見たい。

## 2. 記録するもの（`state.run.stats`。 挑戦のあいだ積む。 純関数は `js/battle/run-stats.js`）

| 項目 | 中身 |
|---|---|
| 被ダメの内訳 | 接触 / 敵の弾 / ボス（接触・技） / 仕掛け（珠・パンチ・木馬） / 横断・精鋭などの型 |
| 倒した敵 | 何に倒されたか（最後の一撃の出どころと敵の名前） |
| 与ダメ | 武器ごとの合計 → DPS（= 合計 ÷ 生存秒）。 ボスへの与ダメは別に |
| 撃破 / 分 | 撃破数 ÷ 生存分 |
| 回復 | パンケーキ・自然回復・店の回復の合計 |
| 無敵で防いだ | 無敵時間中に当たった回数 |

## 3. 画面（倒れた画面の GUM の内訳の下。 `#gameOverAnalysis`）

```
倒れた理由                                  前回 → 今回
 被ダメ 1,240   接触 62% ■■■■■■  弾 30% ■■■  ボス 8% ■
 DPS 48.2 (▲ +9.5)   撃破/分 310 (▼ −20)   生存 2:34 (▲ +0:41)
 与ダメ  ブレード 61%  リボルバー 39%
 とどめ  疾走クリーパー（接触）
```

- 前回の敗北は `mcs.lastDefeat` に覚えて、 ▲▼ と差を出す（同じヒーローのときだけ比べる。 初めては「—」）。
- 色分けは SPEC-144 の `rich-text` と同じ（数字は金・用語は水色）。
- 全クリアの活動レポートにも同じ表を出す（比較は前回のクリアと）。

## 4. マインちゃんのおすすめ（倒れた画面。 SPEC-116 のセリフの代わりに 1 つ）

| 条件（優先順） | おすすめ |
|---|---|
| 弾の被ダメ ≥ 45% | 「弾で削られてるね。 **厚い皮**（被ダメ −3%）か **受け身**（無敵時間）がおすすめ」 |
| 接触 ≥ 60% かつ 撃破/分 が低い | 「囲まれてるね。 **鋭い一撃**・**二連**で火力を上げよう」 |
| 接触 ≥ 60% かつ 撃破/分 が高い | 「数に押されてるね。 **俊足**か**長い腕**（範囲）で距離を取ろう」 |
| ボス ≥ 50% | 「ボスの一撃が重いね。 **竜の爪**や**見切り**（ボスの道）を」 |
| 仕掛け ≥ 40% | 「仕掛けに当たってるね。 予告が出たら離れよう」（スキルではなく操作） |
| それ以外 | 「HP が足りないね。 **頑丈なからだ**を」 |

- おすすめの節をタップで、 その節を選んだ状態でスキルツリーを開く（`openSkillTree({ focus })`）。

## 5. 敵の役割（別 SPEC-149 で）

隊列（貫通が効く）・盾持ち（範囲が効く）・重撃（被ダメ減が効く）、 ショップでの次のウェーブの予告は、 敵の作り直しになるので SPEC-149 に分ける。

## 6. 決めてほしいこと

1. 表の項目は §2 で足りるか（例：CE の取りこぼし、 ショップで買った数も要るか）。
2. 比較の相手は「前回の敗北（同じヒーロー）」でよいか、 それとも「自己ベスト」か。
3. 全クリアの画面にも出すか（§3 の最後）。
