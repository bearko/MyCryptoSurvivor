# SPEC-105 — 撃破数の節目の演出

- **Status**: Done
- **関連**: SPEC-103（v1.6 の設計 7.1）・SPEC-107（節目で敵の段階が上がる）

## 1. 背景（作者の依頼 2026-10-20）

「100 体」「500 体」「1,000 体」などの節目で、撃破したことをはっきり知らせたい。ゲームの流れは止めず、画面の上に派手な通知を出す。

## 2. 決まり

- 節目：**通算**（挑戦の頭から、ステージをまたいで数える）の撃破数が **100・250・500・1,000・1,500・2,000・3,000・5,000・7,500・10,000**、その先は 5,000 ごと
- 通算 ＝ ステージの始まりの `run.totalKills` ＋ そのステージの `killCount`（ステージの終わりの足し込みで二重に数えない）。ステージ 1 から始め直したら 0 から
- 一度に 2 つ越えたら（ありえないが）大きいほうだけ出す
- 出し方：HUD とマインちゃんの通信窓の下に、**大きな数字 ＋「体撃破！」**（英語は「KILLS!」）。数字が弾けて出て、金の光の筋が回り、1.6 秒で上へ抜ける。効果音（宝箱を開ける音）
- **遊びは止めない**（`pauseTime` に触らない・操作を奪わない・当たり判定のある場所を隠さない半透明の帯）
- 動きを減らす設定では、弾ける動きと光の筋を止め、文字だけを 1.2 秒
- 「敵が強くなった」の一言は、敵の段階（SPEC-107）を足すときにこの通知の下に添える
