# SPEC-074 — 宝箱の絵をマイクリのエクステンションに

- **Status**: Done
- **関連**: SPEC-053（壺・宝箱）

## 1. 背景

作者の依頼（2026-10-17）：宝箱も、宝箱でなくてもいいので、マイクリのエクステンションを使いたい。

壺は SPEC-053 からエクステンションの絵（4600 ぴっぴ教 一攫千金壺）だが、宝箱だけは素材の宝箱の形（SVG）を金色に塗った手描きの絵だった。

## 2. 仕様（`js/constants.js`・`js/battle/render.js`）

- 宝箱の絵を **1165 オルゴール**（`CHEST_EXT_ID`）にする
  - 素材の中に「宝箱」のエクステンションはない
  - 箱・宝の名のつくもの（オルゴール・財宝ゴールデンモアイ・大海賊の秘宝・宝冠・重箱など）を、ゲームの大きさ（約 40px）で見比べた。木の箱のふたが開いたオルゴールが、いちばん「箱」に見えた
  - ほかの武器・アイテムで使っていない
- オルゴールの絵は枠の 7 割ほど（壺は枠いっぱい）なので、1.3 倍で描いて当たりの円にそろえる
- 宝箱の後ろの金の光の円・HP の帯・画面の縁の矢印はいままでどおり
- 絵を読み込むまでは、いままでの金の宝箱の形で描く

## 3. 非ゴール

- 名前（宝箱）・中身・出る時刻・固さは変えない（総合スコア・RTA の最短時間に関わらない）

## 4. 受け入れ基準

- [x] 宝箱がオルゴールの絵で出る
- [x] 壺・お助けアイテム・マジックカード・木馬・武器の絵と重ならない

## 5. テスト

- `node --test tests/prop-art.test.mjs`
  - 宝箱は 1165
  - 壺・宝箱・お助けアイテム・マジックカード・木馬はみな別の絵
  - 武器・強化の絵とも重ならない
