# SPEC-063 — 雷鼓：画面の敵を一掃するお助けアイテム

- **Status**: Done
- **関連**: SPEC-053（壺・宝箱・お助けアイテム）・SPEC-054（懐中時計）・SPEC-062（撃ってくる敵の弾）

## 1. 背景

作者の依頼（2026-10-17）：画面内にいる敵を一掃するお助けアイテムがほしい。作者の決定：ボスにも大ダメージ（最大 HP の 20%）。

## 2. 仕様

- 名前は**雷鼓**（素材のエクステンション 5071。雷のついた太鼓）。種類は `thunder`
- 拾うと、**画面に映っている敵すべてに雷**が落ちる（半分見えている敵も入れる。`inView`）
  - 雑魚・レア・撃ってくる敵：倒れる。撃破数・経験値・マジックカードは、ふつうに倒したときと同じ
  - ボス：最大 HP の 20%（`THUNDER_BOSS_RATIO`）のダメージ。残りが少なければ倒れる
  - 壺・宝箱：壊さない（中身を取りこぼさないため）
  - 画面の中の敵の弾（撃ってくる敵・ボスの弾）も消える
- 演出：落ちた場所ごとに上から稲妻（0.42 秒）・白い閃光・揺れ・振動・「THUNDER!」・範囲攻撃の音（`2_area_damage.mp3`）。動きを減らすときは閃光を出さない
- 落ちる場所（重み）：

| | いままで | これから |
|---|---|---|
| 壺 | CE 55・回復 30・磁石 15 | CE 50・回復 27・磁石 13・**雷鼓 10** |
| 宝箱 | 回復 50・磁石 50 | 回復 40・磁石 35・**雷鼓 25** |
| 宝箱（RTA） | 懐中時計 50・回復 25・磁石 25 | 懐中時計 50・回復 20・磁石 15・**雷鼓 15** |

  - RTA の宝箱の懐中時計の重み（50）は変えない（共通基盤の RTA の最短時間の根拠）
- 遊び方の「強くなる」の行に雷鼓を足す

## 3. 非ゴール

- 宝箱・壺の数と出る時刻は変えない

## 4. 受け入れ基準

- [x] 拾うと、画面の敵に稲妻が落ちて倒れ、経験値が落ちる。撃破数が増える
- [x] ボスは最大 HP の 20% 減る
- [x] 壺・宝箱から出る。RTA の宝箱からも出る

## 5. テスト

- `node --test tests/thunder.test.mjs`：画面に映っているか（半分見えている敵）、3 つの表すべてに雷鼓、RTA の懐中時計の重みはそのまま、ボスに 20%、稲妻は上から落ちてその敵に届く（形は seed で決まる）
- `tests/field.test.mjs`：落ちる物の種類に `thunder` を足した
- ヘッドレスの Chromium で、雷鼓を拾ったとき（画面の敵 9 体 → 1 体・撃破 +9・経験値が落ちる）と、ボスに使ったとき（3000 → 2400）を確かめた
