# SPEC-084 — 序盤の湧きを v1.2 並みに戻す（ボスの前だけ急に濃く）

- **Status**: Done
- **関連**: SPEC-078（敵の湧きを大幅に）・SPEC-065（大群）

## 1. 背景

SPEC-078 を出したあと、 自動プレイのボットが、 ステージ 1 の 1 分すぎで倒れるようになった。 確かめると 2 つあった。

- **湧きの速まりが、 はじめからまっすぐ上がっていた**。 ステージ 1 の 1:00 ですでに v1.2 の 2.6 倍、 1:30 で 4.3 倍だった
  - 作者の依頼は「ボス出現直前は画面の 50% 以上」で、 序盤を難しくすることではなかった
- **置いていかれた敵の寄せ直しが、 はじめから効いていた**。 逃げ回って置いていった敵が、 すぐ前に現れなおすので、 逃げ回る意味が薄れていた

## 2. 仕様

### 2.1 湧きの速まりを、 はじめはゆるく（`floodMul` の `pow`・`STAGE_TABLE[].flood.pow`）

- 速まりを時刻の 2.5 乗にする（いままでは 1 乗 = まっすぐ）。 ボスの直前（3:50）の速さは同じ
- 群れの始まりを遅らせる：ステージ 2 は 1:30 → 2:00、 ステージ 3 は 1:00 → 1:30

1 秒に湧く数（ふつうの湧き。 密度の補充・群れは別）：

| | v1.2 | SPEC-078 の 1:00 / 1:30 / 2:00 / 3:00 | SPEC-084 の 1:00 / 1:30 / 2:00 / 3:00 | 3:50 |
|---|---|---|---|---|
| ステージ 1 | 1.25 | 3.3 / 5.4 / 7.4 / 11.6 | 1.4 / 1.9 / 3.1 / 7.9 | 15.0 |
| ステージ 2 | 1.47 | 5.7 / 8.8 / 12.0 / 18.3 | 1.8 / 2.9 / 4.9 / 12.6 | 23.5 |
| ステージ 3 | 1.79（1:30 から最大 6 倍） | 8.9 / 13.6 / 18.4 / 27.8 | 2.5 / 4.2 / 7.4 / 19.3 | 35.7 |

### 2.2 密度の目標も、 はじめはゆるく（`DENSITY_POW`）

- 目標を時刻の 2.2 乗にする（いままでは 1.6 乗）。 ボスの直前の目標は同じ

### 2.3 寄せ直しはボスの前だけ（`recycleActive`・`RECYCLE_FROM`）

- 密度の目標が最大の半分を超えてから（どのステージも 2:50 ごろから）だけ寄せ直す
- それまでは、 逃げ回れば敵を置いていける（v1.2 と同じ）

## 3. 非ゴール

- ボスの直前の濃さ（SPEC-078 の目安 50% / 75% / 90%）は変えない
- 敵 1 体の強さ・大きさ（SPEC-077）は変えない

## 4. 受け入れ基準

- [x] 1:10 の湧きの速さが、 どのステージも 1.7 倍まで
- [x] 2:30 までは寄せ直さない。 3:50 には寄せ直す

## 5. テスト

- `node --test tests/horde.test.mjs`：速まりは、 はじめはゆるく、 ボスの前に急に（1:10 で 1.7 倍まで・3:30 で半分より上）。 `pow` がなければまっすぐ
- `node --test tests/density.test.mjs`：寄せ直すのはボスの前だけ。 目標は真ん中の時刻で 1/4 より低い
