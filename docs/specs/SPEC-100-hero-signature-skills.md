# SPEC-100 — 固有スキル：同じステージでも、ヒーローごとに「別ゲーム」に

- **Status**: Implementing（`js/battle/signature.js` と、そこを呼ぶ damage / hurt / player / gems / buffs / field / levelup / index / render。画面は `js/main.js`）
- **関連**: SPEC-097（10 人）・SPEC-099（チャートの横に名前と説明）・SPEC-101（LL）

## 1. 背景（作者の依頼 2026-10-19）

ヒーローの性能を工夫して、同じステージでも **別ゲーム** になるようにしたい。

ステータスの差（SPEC-097）は ±1 割に抑えるので、遊び方を変えるのは **ヒーローごとの固有スキル**（常に効いているパッシブ）に任せる。名前は MCH のパッシブスキル名そのもの（手で付けない）。

## 2. 固有スキル（案）

「何をすると強いか」が一言で言え、操作の仕方が変わるものにする。

| ヒーロー | 名前（MCH） | 効き目（案） | 遊び方がどう変わるか |
|---|---|---|---|
| MCHウォーリアー | クリプトスラッシュ | レベルアップのたびに、周りの敵をなぎ払う一撃 | 基本の型。囲まれたらレベルアップで抜ける |
| ビリー・ザ・キッド | ワンホールショット | 同じ敵に続けて当てるほど、ダメージが上がる（最大 ×2） | 1 体ずつ確実に落とす。ボスに強い |
| 霧隠才蔵 | 忍術・毒霧 | 走った跡に毒の霧が残り、触れた敵にダメージ | **逃げ回るほど強い**。動き続ける遊びに |
| ジャックザリッパー | ランゲルライン | 近い敵ほど深く切れる（すぐそばで最大 ×1.8） | **懐に飛び込む**遊びに。HP は低め |
| ニコラ・テスラ | テスラコイル | 一定の間隔で、近くの敵 3 体に連鎖する雷 | 群れを散らす。速くて脆い |
| ピタゴラス | テトラクテュス | 4 回目ごとのレベルアップで、選んだものが 2 段上がる | 計画的に育てる。4 の倍数を狙う |
| 許褚 | 虎痴 | HP が減るほど、攻撃と速さが上がる（HP 3 割以下で最大 ×1.5） | **背水の陣**。わざと受けて押し返す |
| フランシス・ドレーク | 女王直属海賊 | CE を拾うと、少しのあいだ（1.5 秒）速くなり（×1.25）、拾える範囲も広がる（×1.5） | **拾い集めて駆け回る**遊びに。いちばん速い |
| アナスタシア | 幻の生存者 | 倒れるはずの一撃を、1 ステージに 1 回だけ耐えて数秒消える（無敵） | **ぎりぎりを渡る**。HP がいちばん低い |
| 大長今 | 李氏朝鮮、宮廷医女 | 時間とともに HP が少しずつ戻り、回復アイテムの効きが 2 倍 | **長く粘る**耐久の遊びに |

- 数値（間隔・倍率）は `js/battle/signature.js` の先頭にまとめた（クリプトスラッシュ 半径 150・30＋8×Lv／ワンホールショット 1 回 +10%・最大 ×2／毒霧 0.2 秒ごと・2.4 秒残る・0.4 秒ごとに 6＋Lv／ランゲルライン 160px 以内・最大 ×1.8／テスラコイル 2.2 秒ごと・最初 240px・次 160px・20＋4×Lv／虎痴 HP 7 割から・3 割で ×1.5／女王直属海賊 1.5 秒・速さ ×1.25・範囲 ×1.5／幻の生存者 3 秒消える／宮廷医女 毎秒 0.8・回復 ×2）
- 自動プレイの道具（`tools/sim`）はまだ手順の文書だけなので、いまは遊んで確かめる。NORMAL のクリアの割合が大きく外れるヒーローが出たら、ここの数値で直す
- 演出は短く（0.35 秒以内）

## 3. 画面

- ヒーローの選択画面：名前とステータスの下に「固有スキル：テスラコイル」と一行の説明
- レベルアップ：テトラクテュスで 2 段上がる回は、見出しの下が「テトラクテュス：このピックは 2 段上がる」になり、札の Lv も 2 段先を出す
- 戦闘中の HUD のアイコンは、まだ出していない（あとで）

## 4. テスト

- 固有スキルの計算は純関数（例：ワンホールショットの倍率、テトラクテュスの 4 回目の判定、浪切の当たり）
- 自動プレイで、10 人それぞれの NORMAL のクリアの割合（目標 60% の前後）
