# SPEC-135 — スキルツリーの画面の分け方（Workshop の作り）

## 1. 作者の依頼（2026-10-20）

MyCryptoWorkshop のスキルツリーの仕組み 4「画面の分け方」を持ち込む。

## 2. 変えたこと

- **分かれ目を 900px → 860px**（Workshop と同じ）。マインちゃんの吹き出しの幅の切り替えも同じ 860px に
- **PC**：左に木、右に詳しい欄と「いまの効果」（320px → **340px**）。「戻る」は右の列の手前
- **860px 以下**：上に木、下に欄（画面の高さの 46% まで）。詳しい欄を小さくした（絵 44px・名前 16px・説明 13px・ボタンを低く）。名前・効果・条件・解放のボタンがスクロールなしで入る
- **欄の先頭は選んだノードの詳しい欄**。選ぶたびに一番上へ戻す
- 「戻る」は木の右下（SPEC-132）なので、欄の下に余白は要らない（欄に隠れない）

### Workshop と変えたところ

- **道のタブは木の上の行のまま**（Workshop は木の上に重ねる）。木の左上にマインちゃん、右上に「いまの効果」の札があり、重ねるとぶつかるため
- **狭い画面でも「いまの効果」は隠さず、右上の札（押すと開く）のまま**。マインちゃんの案内（「効果は右の欄に表示されるよ」）がこの札を開いて見せるため
