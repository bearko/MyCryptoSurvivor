# SPEC-164 — EASY の導線のゲートと、 ステージ 2 のやさしさ

- **Status**: Done
- **関連**: SPEC-147 / 154（EASY とレッスン）・SPEC-155（REVIVE のおすすめ）・SPEC-157（木の一括解放）・SPEC-163（バランス調整）

## 1. 作者の指摘（2026-10-21）

1. CE のレッスンの黄色い枠が大きすぎて、 何を指しているか分からない。 CE はきれいに枠を付けるのが難しいので、 **枠は無しでよい**
2. 初めて倒れたときの REVIVE 画面では **「スキルツリーへ」を押してもらう**。 ボタンを目立たせ、 ランキング送信とタイトルに戻るは押せなくする
3. 初めてスキルツリーを開いたときも、 **真ん中の「サバイバーの覚醒」を押すまでは ほかのボタンを押せなくする**。 「復活する」が目立つので、 強化せずにそのまま復活してしまいそうだった
4. 被ダメが大きく、 不慣れな人は強化しても EASY のステージ 2 が難しい。 **覚醒を取ったら、 雑魚はほぼ動かなくても倒れないくらいの被ダメに**。 ボスは攻撃をあまり食らわない代わりに、 ふつうに攻撃していると倒せなくはないが時間がかかるくらいにし、 **雷鼓で一気に HP を削る体験**をさせたい

## 2. 直したこと

### 2.1 CE のレッスンにカーソルを当てない（`lesson.js`）

`s1.ce` の `_cursorTarget` は `null`。 輪も指も出さず、 マインちゃんの文だけ。 ほかのレッスン（店のゲージ・ボスの赤いエリア・レア・ギフト券・ミッション）のカーソルはそのまま。

### 2.2 根なしの REVIVE は「スキルツリーへ」だけ（`gameover.js`・`result-ui.css`）

`easyRetryGate()`（EASY で根を持っていないときだけ）が、 いままでの「復活する」を隠す・木のボタンを脈打たせる に加えて:

- モーダルに `gameover-modal--gate` を付け、 **「スキルツリーへ」を大きく**（文字 1.15rem・絵 26px・強い光）
- **ランキング送信・名前の欄・タイトルに戻る を `disabled`**（薄く・グレー）。 送信ボタンの disabled を API の有無で決めたあとに重ねる（順序の問題で効かなかった）

おすすめの強化（SPEC-155）は根なしでは元から出ないので、 押せるのは木のボタンだけになる。

### 2.3 木は根を取るまで ほかのボタンを押せない（`skill-tree.js`・`skill-tree.css`）

`rootGated(meta)`（= 根を持っていない）のあいだ、 画面に `gate` を付け、 **復活する／次のノードに挑む・戻る・道のボタン・一括解放** を `disabled`（薄く・押せない・脈打ちも止める）。 縮める・広げる・中心へ・全体・チャットの畳みは残す。 根の値段は 0 なので、 NORMAL で木を初めて開いた人も根を取れば抜けられる（SPEC-093 の案内「根を押す」と同じ段）。 `renderAll` の最後で毎回かけ直すので、 根を買った瞬間に外れる。

### 2.4 EASY のステージ 2（`easy.js`・`field.js`）

| | 旧（SPEC-163） | 新 |
|---|---|---|
| 根を取るまでのヒーロー（HP・攻撃） | ×0.6 | **×0.5**（覚醒の跳ね上がりを大きく） |
| 雑魚の攻撃 | ×1.7 | **×0.6**（基礎 10〜22 → 6〜13。 根あり HP 100 なら 8〜16 発） |
| 雑魚の HP | ×1.6 | ×1.6 |
| ボスの HP | 45,000 × 0.032 = 1,440 | **45,000 × 0.09 = 4,050**（根ありの DPS 150〜200 で 20〜27 秒） |
| ボスの攻撃 | ×0.6 | **×0.3**（接触 9・放射 4・叩きつけ 8） |
| 雷鼓のボスへの割合 | 20%（perks の値） | **50%**（`thunderBossRatio` を EASY のステージで上書き。 `field.js` が `easyStage()?.thunderBossRatio ?? thunderBossRatio()`） |

ボスが出た瞬間に落ちる雷鼓（SPEC-147）で HP の半分が飛び、 残り 2,000 を 10〜14 秒で削る。 ボス戦の宝箱からもう 1 本出れば そこで終わる。 **根なし（HP 50・攻撃 ×0.5）は、 雑魚に押されるかボス戦が長すぎて倒れる**（§3）。

ついでに直したこと: 雷鼓のレッスン `s2.thunder` の出る条件が `currentStageIdx === 2`（3 ステージ時代の値）のままで、 **SPEC-154 で 2 ステージになってから一度も出ていなかった**。 `=== 1` に。

## 3. 測った結果（自動プレイ EASY・根なしの 1 回目 → 根 ＋ 4 節の 2 回目）

| 腕（被ダメ） | 1 回目（根なし） | 2 回目（根あり） |
|---|---|---|
| 不慣れ ×0.5 | ステージ 2・ボス戦で倒れる（69 秒） | **クリア**（49 秒。 ボス戦 19 秒） |
| ふつう ×0.3 | ステージ 2・ボス戦で倒れる（41 秒） | **クリア**（43 秒） |
| 上手い ×0.15 | ステージ 2 をクリアしてしまう（50 秒） | クリア（57 秒） |

SPEC-163 では不慣れな人が根を取っても倒れていた（36〜45 秒）。 いまは不慣れ・ふつうのどちらも「根なしで倒れ、 根で勝つ」。 上手い人が根なしで勝ってしまうのは SPEC-163 のときと同じ（腕の幅に対して根の効きが足りないのは変わらない。 根なしの ×0.5 でも通る）。

ゲートは Playwright で画面を見て確かめた: 根なしの REVIVE で `gameover-modal--gate`・送信/名前/タイトル disabled・復活する hidden。 木で `gate`・復活する/戻る/道 6 つ/一括 disabled・縮めるは押せる。 根を 2 回押すと外れ、 「復活する」で戦闘へ戻る。

## 4. 作者に見てほしいところ

1. **レッスン `s2.start` の文が古い**: 「エクステンションは引き継がれないけど、 パッシブは引き継がれるよ」。 SPEC-162 で装備も CE も引き継がれるようになったので、 文と**録音済みのボイス**が事実と合わない。 文だけ直すと声とズレるので、 この SPEC では触っていない。 録り直すか、 文と声を両方そのままにするかの判断を。
2. 根の値段が 0 なので、 木のゲートは NORMAL の初回にも効く（根を取るまで戻れない）。 EASY だけに絞るなら `rootGated` に `isEasy()` を足す。
3. 上手い人は根なしでステージ 2 を勝ってしまう。 「必ず倒れる」にしたいなら、 根なしの倍率を ×0.5 → ×0.35 に（そのぶん覚醒の跳ね上がりも大きくなる）。
