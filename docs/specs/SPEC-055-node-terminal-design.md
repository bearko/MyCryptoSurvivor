# SPEC-055 — デザイン言語「ノード端末」：パネルの質感・止まらない背景・画面の切り替え

- **Status**: Done
- **関連**:
  - SPEC-043（UI の土台）・SPEC-044（演出を減らす）・SPEC-046（結果の見せ方）
  - DESIGN_CHARTER 14 章（この SPEC で新設）
- **シリーズ**：UI の見直し（作者の依頼 2026-10-17「参考作と同等まで」）の 1 本目。続きは SPEC-056（キャラと重なり）・SPEC-057（戦闘）・SPEC-058（結果とメニュー）

## 1. 背景

作者の依頼：エフェクトと UI をリッチにし、作者が挙げた参考作の UI の考え方（下）にならって、ゲームのデザインを全体的に見直す。

| 参考作の考え方 | この作品での読み替え |
|---|---|
| 世界観を UI の質感に落とす（テレビ・ガジェット） | MCH のブロックチェーンの世界・ステージ名「node : 〜」から、**ノードの端末**の質感にする |
| パネルの縁のハイライトで、現実のガジェットを触っている感じ | 角を切った筐体、縁は金 → シアンの金属の光、面に走査線 |
| UI を死なせない（どの画面でも何かが微かに動く） | 背景のブロックの格子が流れ、粒が漂い、パネルの縁を光が走る |
| ページめくりの快感（500〜700ms） | 画面の切り替えを、斜めの筐体が横切るワイプ（640ms）に |
| 色の優先度（UI をいちばん鮮やかに） | 憲章に決まりとして書く（戦場の彩度を下げるのは SPEC-057） |
| キャラと UI を重ねる・喋るキャラ | SPEC-056 |

作者の決定（2026-10-17）：美術の方向は「ノード端末」、案内役はナビのアイン、憲章は改めてよい、段階ごとにマージして報告。

いまの画面（v1.0）は、どのモーダルも「金の枠の角丸カード」で同じ見た目で、開いたあとは止まっている。

## 2. 仕様

### 2.1 憲章の改訂（`docs/charters/DESIGN_CHARTER.md`）

- 14 章「ノード端末」を新設（質感・生きている・色の優先度・キャラとの重なり・動き）
- 9 章に「画面の切り替え・ページ送り 500〜700ms」「常に動く演出 5〜30 秒の周期」と、「演出を減らす」の扱いを足す
- 6.2 に「Survivor は 14 章の外装を使う」と注記（テンプレートとしての角丸の既定値は残す）

### 2.2 外装の CSS（`css/node.css` 新規。最後に読む）

既存の部品の見た目だけを上書きする「皮」にする。1,600 行の `components.css` を書き換えないので、ほかの変更と衝突しにくい。

| 対象 | 外装 |
|---|---|
| パネル（ヒーロー選択・レベルアップ・ゲームオーバー系の全モーダル・遊び方・モード選択のカード） | 角を切った形（`clip-path`。14px）。縁は 2px の金 → シアン、切った斜めの辺にも光の線。面は筐体のグラデーション＋走査線＋上の光沢。縁を光が 5.5 秒ごとに流れる |
| 縁の色 | ゲームオーバーは赤、ステージクリア・活動レポート・メニュー・ランキング・設定は金、遊び方はシアン、ABSOLUTE は赤、RTA は紫 |
| ボタン（主） | 角を切ったキー（8px）。金の縦グラデーション＋上の光の線。触れる・フォーカスで光が横切る |
| ボタン（二次） | 暗い面に金の縁。切った斜めの辺にも線 |
| Press to Start | 見出しの書体・字間。3.2 秒ごとに光が走る（今の脈動はそのまま） |
| 閉じる × | 角を切った形 |
| モーダルの背景 | ブロックの格子（36px）が 26 秒で流れる。上に金、下にシアンの薄い光。粒（2 つの大きさ）が 18 秒で漂う |
| タイトル・モード選択 | 背景の写真の上に、格子と粒 |
| 見出し | 英字の小見出し `data-kicker`（MODE SELECT・SELECT HERO・LEVEL UP・NODE CLEAR・RESULT・ACTIVITY REPORT・PAUSE・SETTINGS・RANKING・HOW TO PLAY） |

縁と面は、背景の重ね（`background-clip: padding-box / border-box`）だけで作る。スクロールするカード（活動レポート・遊び方）でも崩れない。`clip-path` は影を切るので、影の代わりに背景の光で浮かせる。

### 2.3 画面の切り替え（`js/transition.js` 新規）

- `playWipe(onCovered, { label })`：斜めの筐体が左から横切って画面を覆い、**覆いきった 320ms で `onCovered()`** を呼んで画面を差し替え、右へ抜ける（全体 640ms）。先を細い光が走り、真ん中に端末の表示（例：`NODE // CONNECT`）
- 使うところ：

| 操作 | 表示 |
|---|---|
| タイトル → モード選択（Press to Start） | NODE // CONNECT |
| モード選択 → ヒーロー選択 | SELECT // HERO |
| モード選択 → タイトル（戻る） | （なし） |
| ヒーロー選択 → 戦闘（冒険を始める） | NODE // DEPLOY |

- 流れている間は画面全体を覆って押せないようにし、さらに途中で来た呼び出しは捨てる（二度押しでヒーロー選択が二重に開き、一時停止の数がずれるのを防ぐ）
- 動きを減らすとき（OS の設定か「演出を減らす」）は、流さずにすぐ差し替える
- pauseTime には触らない（画面の開閉がいつもどおり受け持つ）

### 2.4 「演出を減らす」を CSS にも（`js/motion.js`）

- `installReduceFxAttr()`：「演出を減らす」か `prefers-reduced-motion` のとき、`html` に `data-reduce-fx` を付ける（設定を変えるとすぐ反映）
- CSS は `:root[data-reduce-fx]` で、縁の光・格子・粒・Press to Start の光を止める（SPEC-044 の「揺れ・粒・画面の光を止める」と同じ考え）

## 3. 非ゴール（後の SPEC）

- ナビのアイン・ヒーローを大きく重ねる（SPEC-056）
- 戦闘の HUD・レベルアップのカードの中・ボスのカットイン・戦場の彩度（SPEC-057）
- 結果の画面の中の部品（ステージの枠・数字のタイルなど）・メニュー・設定の中身（SPEC-058）
- 色の値（`--accent` など）は変えない

## 4. 受け入れ基準

- [x] 全モーダル・モード選択のカードが角を切った筐体になり、縁が金 → シアン（ゲームオーバーは赤）
- [x] モーダルの背景で格子と粒が動き続け、パネルの縁を光が流れる
- [x] Press to Start・モード選択・冒険を始めるで、ワイプが流れて画面が切り替わる。二度押しで二重に開かない
- [x] 「演出を減らす」を ON にすると、常に動く演出とワイプが止まる
- [x] 二次ボタンの文字が読める（暗い面に金の縁）
- [x] 390×844 で崩れない。コンソールにエラーがない

## 5. テスト

- `node --test tests/transition.test.mjs`：ワイプの長さが 500〜700ms で覆うのが真ん中、画面がないときはすぐ差し替える、差し替えの中の失敗を外に出さない、「演出を減らす」の属性が画面なしでも例外を出さない
