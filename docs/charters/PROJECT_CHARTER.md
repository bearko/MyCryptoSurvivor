# プロジェクト憲章 — MyCryptoSurvivor

> このファイルが MyCryptoSurvivor のプロダクト目的を定義する。
> 2026-10-16 改訂：SPEC-005 で「雪山サバイバル＋資源管理」から **サバイバー系アクション** に転換したのに合わせ、
> 目的・スコープ・リリース計画を今のゲームに書き直した（旧版は git の履歴に残っている）。

## 1. プロジェクトの目的

MyCryptoSurvivor は MyCryptoHeroes（マイクリ）のヒーローとエクステンションで遊ぶ **サバイバー系アクション** のシングルプレイ web ゲーム。
プレイヤーは 10 名のヒーローから 1 名を選び、押し寄せる敵の中を動き回りながら、自動で撃つ武器（エクステンション）を
レベルアップのたびに選んで育て、**全 3 ステージ** のボスを倒すことを目指す。

- 1 ステージは最大 5 分。4 分でボスが出て、倒すか 5 分耐えるとクリア
- 3 ステージ通しで約 15 分。ヒーローの Lv は引き継ぎ、武器はステージごとに選び直す
- 結果は活動レポートのスコアとして、ゲーム内ランキングと bearko.games 共通基盤（トロフィー・RTA・総合スコア）に送る

> **位置付け**: `mycryptotemplate` 由来の最初の派生作品。開発作法はテンプレートを継承する。

## 2. スコープ (= 何を作るか)

### In Scope (= 作るもの)

- **タイトル → モード選択 → ヒーロー選択 → 戦闘** の流れ
- **戦闘** — 移動（ドラッグのスティック／WASD）だけを操作し、攻撃は自動。敵を倒すと出る経験値ジェムで Lv が上がる
- **レベルアップの選択** — エクステンション 17 系列 × 5 段階（武器・強化）から 1 つ。リロールあり
- **3 ステージ** — アバカス（ボス：ディープ・ヨシュカ）／ホレリス（覚醒魔王ファオ）／トロイ（yamap）
- **モード** — NORMAL、ABSOLUTE（4 軸の難易度を自分で決め、スコアに倍率）、RTA（bearko.games 共通基盤）
- **結果** — ゲームオーバー、活動レポート（ステージごとの記録とスコア）、ランキング（GAS）
- **bearko.games 共通基盤** — トロフィー・RTA・総合スコア（SPEC-039〜041）
- **i18n** — ja / en
- **設定** — 音量・ミュート・演出を減らす（v1.0 で追加）

### Out of Scope (= 作らないもの)

- マルチプレイ / オンライン同期
- ガチャ・課金導線
- ブロックチェーン / NFT トランザクション (= ヒーロー画像は CDN 参照のみ)
- 重い 3D / WebGL 演出
- Native アプリ化 (= 静的 web のみ)
- 途中のセーブ（1 回の挑戦は約 15 分で終わるため）

## 3. 成功基準

- ユーザーが **タイトル画面 → ヒーロー選択 → 戦闘開始** までを 30 秒以内に到達できる
- モバイル (= 320px 幅) でレイアウトが破綻しない。片手の縦持ちで操作できる
- ランキング送信エラー率 1% 以下 (= GAS タイムアウト含む)
- 1 プレイ（全 3 ステージ）の所要時間 15 分前後 (= スキマ時間に回せる)
- ja / en の 2 言語で UI 文字列が 100% カバーされる
- UI/UX が bearko.games の共通の基準（MyCryptoPortfolio `docs/ROADMAP.md` 3 章）を満たす

## 4. 制約

- **技術**: バニラ JS + 静的 host 限定 (= ビルドステップなし、 npm dependency なし)
- **アセット**: `bearko/mycryptoheroes` リポジトリの raw URL を参照 (= 本リポジトリにゲーム素材のバイナリは置かない。ロゴ・OGP 画像のみ例外)
- **多言語**: ja / en の 2 言語デフォルト
- **ターゲット**: PC ブラウザ + モバイル (= iOS Safari / Chrome Android)
- **localStorage prefix**: `mcs.*` で統一 (= 他派生作品と衝突しないこと)

## 5. 主要なペルソナ

- **コアプレイヤー** — MCH 経済圏のファン。ヒーローの個性（体力・速さ・開始武器）とエクステンションの組み合わせで
  ビルドを考えるのを楽しむ。1 プレイ短く、何度もリトライしたい。ABSOLUTE・RTA で腕を競う
- **ライト層** — 操作は移動だけなので、アクションが得意でなくても遊べることを期待。失敗してもすぐ次が始められる
- **モバイル層** — 通勤途中などで片手プレイ。縦持ち 320-420px 幅で破綻しない UI が必須
